    16｜M5-04I｜腐殖边缘换根植物候选｜审美与反同质化边界闸门

    版本：V0.7.58 正式通过检查点
    状态：完整正文／用户已确认通过
    对象：M5-04I 野生基础种
    归档性质：完整判断正文，不得以摘要替代

    一、审查目标

    确定 M5-04I 的美感如何直接来自“在富营养但低氧、有毒、病原密集的腐殖边缘，以分区、缓冲、牺牲和更新维持长期生存”的旗舰生命史，而不是依赖奇幻发光、透明膜、工业装置或病害猎奇。

    必须回答：

    • 它应给观者什么第一气质；
    • 鲜活地上叶冠与地下批次衰退如何形成统一审美；
    • 孔雀石青绿、蓝玉绿、乳金、浅琥珀和铜紫如何有层次而不魔法化；
    • 如何表现腐殖环境而不把整页变成泥褐色；
    • 如何表现电子缓冲鞘而不走向电路、机械或宝石；
    • 如何保持旗舰感，同时不靠巨大化、高耸化和神圣化；
    • 如何避免与 Project AE 既有植物和地球湿地植物同质化。

    二、原始设定

    旧“腐殖滤根植物”审美常见以下倾向：

    • 地下公共过滤装置；
    • 根刷、根帘和滤囊的工程化重复；
    • 大面积泥灰、腐褐和病态湿亮；
    • 透明膜、胶体和营养液；
    • 将植物塑造成帮助整个生态系统净化环境的服务型圣物。

    现行路线已改为自利性的动态边缘竞争者：

    • P2 以光合作用积累能量；
    • P4 使用容量有限的电子缓冲鞘延迟失效；
    • 根扇在受体耗竭和病原压力下被封闭牺牲；
    • P5 在新的氧化前沿重新建立根扇；
    • 整株通过分区失败而非完美防御维持长期存在。

    三、问题诊断

    1. “腐殖”容易被直接等同为褐色、腐烂和脏污；
    2. “电子缓冲”容易被画成蓝光、电线、芯片或能量罩；
    3. “换根”容易被画成高速移动、主动爬行或章鱼换触手；
    4. “旗舰”容易被误解为必须巨大、高耸、发光或覆盖环境；
    5. 大面积鲜绿若缺乏年龄层次，会像园艺温室植物；
    6. 大面积铜紫和灰褐若过多，会变成病害图或死亡标本；
    7. 根冠抬高若过整齐，会像人工底座、盆景或建筑平台；
    8. 根扇排列若过规律，会像涡轮、风扇、滤芯或线路板；
    9. 叶片若过圆整、光滑和对称，会像地球观赏莲座；
    10. 若强调湿润高光，会滑向水生植物、海洋生物或透明胶质；
    11. 若隐藏所有旧伤，会失去其真实的代价与动态协调平衡；
    12. 若旧伤过度突出，又会破坏 P2 健康主视觉。

    四、判断逻辑

    M5-04I 的核心审美张力应为：

    地上：明亮、舒展、稳定获取能量
地下：分批、克制、持续承担损耗
时间：新生与封闭并存，但不同时崩溃
空间：个体边界清楚，根区向多方向试探
结果：鲜活不是无损，衰退也不是死亡主导

    因此其美感不是“完美净化”，而是：

    在湿润、富营养且不断失衡的边界上，以清醒的分区和更新保持生命力。

    五、优化方案

    1. 核心审美气质

    冻结核心气质：

    鲜活而克制，稳健而不断更新；地上清明舒展，地下沉着分批。

    辅助气质：

    • 不宏伟，但具有内部复杂度；
    • 不脆弱，但保留损伤和失败；
    • 不神圣，不承担公共服务叙事；
    • 不阴森，腐殖环境仍有明亮的活性层；
    • 不机械，所有重复均被自然偏差打破。

    2. P2 主综合色

    继续冻结已通过的综合色范围：

    • 清亮孔雀石青绿—鲜活蓝玉绿：约 68%—76%；
    • 暖乳金—浅琥珀米：约 12%—18%；
    • 珊瑚铜—梅铜紫：约 4%—8%；
    • 深色阴影、封闭旧根和病伤：原则上不超过约 8%。

    应用逻辑：

    • 健康叶板以孔雀石青绿—蓝玉绿为主；
    • 中央承力脊、叶柄转折和年轻冠区使用暖乳金—浅琥珀米；
    • 叶缘保护区、根冠旧连接痕和衰退根扇使用少量珊瑚铜—梅铜紫；
    • 综合色沿组织功能连续变化，不形成随机彩斑；
    • 地下背景以低饱和矿物灰褐衬托，但不得吞没活体综合色。

    3. P0—P5 审美节律

    P0｜收束与保留

    • 叶冠缩减但不整体腐败；
    • 根冠以暖砂金灰和象牙米为主；
    • 旧根扇暗铜褐，活跃组织比例降低；
    • 生命感来自核心根冠仍完整，而非枯死景观。

    P1｜分区恢复

    • 少数冠区先出现浅蓝玉绿新叶；
    • 新生根扇呈象牙青白—浅青瓷绿；
    • 恢复不齐步，不形成所有冠区同时爆发；
    • 暖乳金结构提亮最清楚。

    P2｜鲜活稳定

    • 作为标准主视觉；
    • 叶冠饱满但保留通风间隙；
    • 新生与成熟根扇占主导；
    • 可见少量衰退或封闭根扇，证明多年生和批次更新；
    • 不得使用灰雾滤镜削弱主色。

    P3｜营养脉冲与克制繁殖

    • 增加少量低位生殖轴；
    • 可使用乳金、浅琥珀、柔和珊瑚铜作花器与新果提亮；
    • 叶冠仍是主体，不变成花卉或果实展示植物；
    • 根扇病原压力可由局部颜色变化暗示，不表现大范围病害。

    P4｜缓冲、耗竭与牺牲

    • 低位旧根扇转向灰青褐、铜紫和暗铜褐；
    • 部分叶片略降饱和，但不允许异常艳丽；
    • 根冠高位核心仍保持暖象牙米和少量活性青绿；
    • P4 不能比 P2 更明亮、更繁茂或更“能量化”。

    P5｜重新氧化与谨慎重建

    • 新生根扇和少数新叶重新出现；
    • 旧根扇保持封闭并与新根空间错开；
    • 可见局部氧化损伤和修复痕，但不使用烧焦式大片黑斑；
    • 整体气质为谨慎恢复，不是爆发式复活。

    4. 地上—地下审美统一

    地上叶片与地下根扇共享：

    • 柔和的纵向纤维语言；
    • 由窄基向宽面的展开节奏；
    • 低反光、半哑光活体材质；
    • 青绿—乳金—铜紫的年龄与功能梯度。

    但二者功能分化清楚：

    • 叶片是宽而连续的光合面；
    • 根扇是扁平多级分枝的吸收面；
    • 不能让叶片像根扇，也不能让根扇像地下叶片或鳍。

    5. 根鞘审美

    根鞘的美感来自“微观精密但宏观克制”：

    • 近看有淡琥珀青灰的微孔与细纹；
    • 中景只表现为根扇表面的柔和综合色变化；
    • 远景不可形成光带或网络；
    • 破损处可出现铜紫和灰褐，但不渗出彩色液体；
    • 剖面应像可信的植物根表复合层，不像皮肤、金属涂层或电子元件。

    6. 野生感

    标准 P2 个体应保留：

    • 冠区高低与叶量不完全一致；
    • 一两片叶有轻微磨损或植食缺口；
    • 一个连接颈已封闭；
    • 一片衰退根扇的细分枝正在减少；
    • 结构根避开石粒、旧根和致密腐殖块；
    • 周围只有有限同种个体，不形成规则种植阵列；
    • 局部基质有落物、矿物粒和微生物膜，但不喧宾夺主。

    7. 旗舰感的来源

    M5-04I 的旗舰感必须来自：

    • 地上与地下结构的强因果一致性；
    • 同一植株内可见多个时间阶段；
    • 腐殖电子缓冲鞘的可信微观创新；
    • 分区根冠和狭窄连接颈体现真实风险管理；
    • P0—P5 形成可叙述的动态变化；
    • 与埃纳未来驯化具有清楚接口但不提前展示文明结果。

    不得依靠：

    • 巨型化；
    • 发光；
    • 高饱和霓虹；
    • 神殿式对称；
    • 环境中心化构图；
    • 所有其他物种围绕它服务。

    8. 反同质化边界

    不像地球莲座植物

    叶片不从一个完美中心放射，根冠由多个错位冠区构成；叶片不肥厚储水、不带硬刺。

    不像红树林与湿地树木

    无树干、无高大支柱根、无呼吸根森林；根冠只略高于湿面。

    不像蕨类与菌类

    无羽状叶、孢子囊群、菌盖、菌丝毯或地下菌网。

    不像海洋或水生生物

    无鳃、鳍、触手、海葵、珊瑚和水下漂浮膜；它属于含氧腐殖边缘而非永久水体。

    不像工业过滤装置

    根扇不规则、不等距、不形成滤芯、叶轮、管道和输出口。

    不像 M5-04C

    C 的核心是深裂季节叶束和分散纺锤储根；I 的核心是低弧完整宽叶、抬高分区根冠和批次换根扇。

    不像鲁拉纳 D

    D 是高覆盖、非密封的匍匐模块垫层；I 是边界清楚的稀疏抬冠个体。

    不像 H

    H 是洪退砾缝的多锚顺流柔叶植物；I 不随流线塑形，生境更稳定且地下换根更复杂。

    不像 K

    K 是根塔高位叠瓦附生植物；I 为地表腐殖边缘宽叶植物，无鳞叶、贴附短轴和高位风散形态。

    不像 M

    M 的第一特征是开放槽叶和叉形导滴尖；I 不形成深槽和导滴系统。

    不像 N

    N 是深阴二列错层鞍叶植物；I 叶片非二列、非宽鞍，且需较高 P2 光合收入。

    六、通过依据

    1. 综合色直接对应光合组织、结构组织、保护组织和根扇年龄；
    2. P2 生命力配色符合全植物覆盖规则；
    3. P4/P5 的局部暗化符合病原、耗竭与重新氧化成本；
    4. 非对称冠区和根扇对应分批运行及环境异质性；
    5. 旗舰感由机制可读性而非奇幻特效建立；
    6. 根鞘微观克制表达符合非网络化、非发光边界；
    7. 野生不完美对应植食、病原和多年生历史；
    8. 与现有物种的器官母型、层位、支撑和时间策略均有清楚差异。

    七、成本与代价

    • 鲜活主色和腐殖背景之间需要精准平衡，过亮会园艺化，过暗会病害化；
    • 四阶段根扇可能造成综合色复杂，必须限制每种颜色的面积；
    • 根鞘微纹需在特写中可见，主图中必须克制；
    • 保留旧伤会提高真实感，也增加模型误判为腐败主体的风险；
    • 低矮旗舰缺少巨大轮廓，必须依靠结构与时间层次建立视觉权重；
    • 图鉴若排版过密，可能削弱清明舒展的核心气质。

    八、外部依赖

    • 最终视觉身份闸门的器官尺度；
    • 科学图鉴准入闸门的版式和主次分配；
    • 正式命名与中文标注；
    • 后续埃纳驯化专项的人工型综合色边界；
    • 实际生成模型对中文文字、综合色比例和根扇阶段的稳定性。

    九、拟冻结项

    1. 核心审美气质为“鲜活而克制，稳健而不断更新”；
    2. P2 必须是健康、明亮、有生命力的第一标准形象；
    3. P2 主色以孔雀石青绿—鲜活蓝玉绿为绝对主体；
    4. 暖乳金—浅琥珀米用于结构提亮；
    5. 珊瑚铜—梅铜紫只作局部保护、衰退和年龄色；
    6. 大面积灰褐、暗橄榄、枯黄和低对比综合色直接失败；
    7. 根鞘不发光、不金属化、不透明胶化、不晶体化；
    8. 同一植株允许新生、成熟、衰退、封闭四阶段并存；
    9. P2 健康组织必须明显多于病伤和旧根；
    10. 腐殖环境不等于整页泥褐和腐烂；
    11. 旗舰感来自机制复杂度、时间层次和结构因果；
    12. 不采用巨大化、高耸化、神圣化和环境中心化；
    13. 野生个体必须保留适量非对称、植食、旧伤和根区避障；
    14. 与 C、D、H、K、M、N 的视觉组合不得混淆；
    15. 埃纳驯化型不进入野生基础种标准图。

    十、未决项

    • P3 生殖结构的最终综合色和细部外形；
    • 不同地方生态型是否在蓝玉绿与孔雀石绿比例上存在稳定差异；
    • 根鞘近景是否需要加入可见微量矿物结合点；
    • 儿童绘本版本中根扇更新如何简化而不拟人化；
    • 驯化型是否会形成更规则、更同步但风险更高的综合色节律。

    十一、回退条件

    • P2 主图大面积灰褐、暗绿、枯黄或病态低对比；
    • 使用蓝白电流、发光纹路、金属网、透明胶膜或宝石颗粒；
    • 根扇形成机械对称、滤芯、叶轮、刷子或触手；
    • 地上轮廓被误读为普通莲座、凤梨、芋、蕉或红树林幼株；
    • 病斑和旧根成为主视觉，健康叶冠无法证明正收支；
    • 为突出旗舰地位而巨大化、高耸化或让其他生物围绕服务；
    • 与 M、N、C、D、H、K 任一物种的第一识别组合高度重复；
    • 综合色无法体现 P0—P5 的时间差异；
    • 全株过度完美、无年龄差和环境代价，呈现园艺塑料模型感。
