    17｜M5-04I｜腐殖边缘换根植物候选｜最终科学图鉴构图与 Prompt 准入闸门

    版本：V0.7.58 正式通过检查点
    状态：完整正文／用户已确认通过
    对象：M5-04I 野生基础种
    归档性质：出图前输出规范与准入判断；不得替代实际成图审核

    一、审查目标

    判断 M5-04I 野生基础种是否已经具备进入最终科学图鉴 Prompt 和候选图生成的完整条件，并冻结首张图鉴必须证明的主视图、地下剖面、器官特写、P0—P5、生命周期、综合色、尺度和禁区。

    必须明确：

    • 正式名称尚未冻结时采用何种安全标题；
    • 首张图鉴以哪个阶段和生态场景为主；
    • 地上叶冠、抬高根冠和地下换根扇如何保持空间连续；
    • 腐殖电子缓冲鞘需要展示到什么程度；
    • 病原、迁移和地方生态型信息如何进入但不喧宾夺主；
    • “可被埃纳驯化”如何标记而不提前展示栽培型；
    • 最终图鉴为何采用带中文说明的终稿路线；
    • 哪些失败条件会阻止候选图归档。

    二、原始设定

    Project AE 早期曾使用“无字底图＋后期标注”流程。现行植物系统覆盖规则已更新为：

    后续生物图像默认直接生成最终科学图鉴式图文页，采用清楚中文标题、结构说明和 P0—P5，不使用春夏秋冬；图像生成文字若存在错误，必须在实际成图审核中校正或重新生成。

    M5-04I 的历史旧图和旧 Prompt 仍属于“腐殖滤根植物”路线，包含滤根、根刷、菌膜界面和营养输出等内容，不得沿用。

    当前正式名称尚未冻结，旧名“莫菲纳 / Morfelna”只保留在历史层。

    三、问题诊断

    1. 只展示地上叶冠，无法证明换根旗舰机制；
    2. 只展示地下结构，会像根系工程图而失去活体生态状态；
    3. 将全部根扇完整摊平，容易形成机械风扇或滤网；
    4. 将根鞘放大过度，容易变成电路、晶体或透明膜；
    5. P0—P5 若全部画成大图，会压缩主物种结构空间；
    6. 病原与免疫若直接画微生物怪物，会破坏科学性与审美；
    7. 迁移若画成大面积连续群落，会违反稀疏源—汇斑块；
    8. 将埃纳、农田、工具或栽培型加入首张图，会提前冻结文明接口；
    9. 图像模型直接生成中文可能产生错字、伪文字和不准确标签；
    10. 正式名未定时若强行使用旧名，会造成历史回退；
    11. 腐殖背景过暗会吞没 P2 生命力配色；
    12. 地上与地下剖面若缺乏对应，会像多个个体拼贴。

    四、判断逻辑

    首张最终图鉴应优先证明野生物种自身成立，并让旗舰创新在生态环境中可读。

    采用：

    P2 成熟野生个体的地表—地下连续生态剖切主图＋右侧器官与根扇阶段特写＋下方 P0—P5 与生命周期压缩条。

    其中：

    • P2 主图承担约一半以上视觉面积；
    • P4/P5 主要通过根扇阶段和小型状态条表达；
    • 病原只表现为局部组织结果和简化显微界面，不塑造怪物；
    • 埃纳驯化只以文字状态标记“已触发、另行审核”，不画文明场景。

    五、优化方案

    1. 图鉴标题与命名

    在正式命名专项完成前，图内标题仅使用：

    M5-04I｜腐殖边缘换根植物候选

    允许副标题：

    野生旗舰基础种｜可驯化标记已触发

    不得使用：

    • 莫菲纳 / Morfelna；
    • 伪拉丁学名；
    • 未冻结的埃纳语名；
    • 将“电子缓冲鞘”写成“生物电池”“电根”或“地下电网”。

    2. 版式

    建议采用横向宽幅科学图鉴页，比例约 16:9 或 3:2，最高可用分辨率，整体为浅米灰—暖灰米色博物学图鉴背景。

    A. 中央—左侧主生态图：约 52%—60%

    采用三分之二斜俯视与局部地表剖切结合：

    • 一个 P2 成熟野生个体；
    • 根冠略高于湿润腐殖面；
    • 3—8 个不规则冠区和错层低弧宽叶；
    • 多方向结构根进入矿物—腐殖混合层；
    • 2—4 个主要换根扇在剖切面中清楚可见；
    • 至少包含新生、成熟和一片衰退或封闭根扇；
    • 每个根扇与对应冠区通过狭窄连接颈连续相连；
    • 周围环境显示微隆起、落物、矿物粒、湿润腐殖边界和有限邻近植物，但不形成连续同种覆盖；
    • 地表与地下必须属于同一植株、同一尺度、同一空间。

    B. 右侧器官与机制特写：约 25%—30%

    至少包含：

    1. 单片成熟低弧宽叶正面或三分之二视图；
    2. 抬高分区根冠与冠区连接关系；
    3. 狭窄连接颈正常、封闭和牺牲状态；
    4. 新生—成熟—衰退—封闭四阶段换根扇并列；
    5. 换根扇横剖或局部放大：薄型电子缓冲鞘、活性皮层、输导组织；
    6. 低位生殖轴、小型花器、干果和扁楔形粗糙种子。

    根鞘特写必须明确写为：

    “有限容量的根界氧化还原缓冲聚合物层；非发光、非电网、不能永久耐无氧。”

    C. 下方 P0—P5 状态条：约 10%—15%

    必须使用 P0—P5，不得使用春夏秋冬：

    • P0：低资源收束；
    • P1：分区恢复与新根生成；
    • P2：稳定光合和根鞘充备；
    • P3：营养脉冲与条件繁殖；
    • P4：低氧缓冲、受体耗竭与根扇牺牲；
    • P5：重新氧化、抗氧化修复与换根。

    各阶段以小型同源个体或局部器官状态表达，不得把六阶段画成六个不同物种。

    D. 生命周期压缩区：约 10%—15%

    至少包含：

    1. 扁楔形粗糙种子；
    2. 简单幼叶与普通初生根；
    3. 单冠幼体；
    4. 初级短寿命根簇；
    5. 低容量初级根鞘；
    6. 分区根冠亚成体；
    7. 成熟换根个体；
    8. 极低频完整子冠分离。

    必须标注：普通叶片、结构根和换根扇碎片不能再生。

    3. 主图必须证明的内容

    最终候选图必须可验证：

    1. 地上为低位但光合面积充足的健康叶冠；
    2. 叶片是低弧完整宽叶，不是槽叶、鞍叶、裂叶或鳞叶；
    3. 根冠略高于湿润腐殖面；
    4. 根冠由多个有限连通冠区构成；
    5. 结构根负责长期锚定；
    6. 换根扇通过狭窄连接颈接入冠区；
    7. 换根扇扁平多级分枝且边界清楚；
    8. 同一植株存在不同根扇阶段；
    9. 根鞘是薄型半哑光根表层；
    10. 根鞘不发光、不形成远程电子网络；
    11. P2 健康组织占主导，旧根和病伤仅局部出现；
    12. 个体生长于含氧—氧化腐殖边缘，不是永久无氧泥层；
    13. 同种个体稀疏、斑块化；
    14. 生命周期从有性种子开始；
    15. 可驯化只是后续接口，不是野生物种成立条件。

    4. 综合色与光照

    采用 K 型恒星暖光环境下的清晰博物学照明：

    地上 P2

    • 主体：清亮孔雀石青绿—鲜活蓝玉绿；
    • 结构提亮：暖乳金—浅琥珀米；
    • 局部保护与年龄色：珊瑚铜—梅铜紫；
    • 叶面低反光、半哑光，不油亮、不蜡塑料化。

    地下

    • 根冠：暖象牙米—浅砂金灰；
    • 新生根扇：象牙青白—浅青瓷绿；
    • 成熟根扇：浅青玉灰—柔和橄榄青；
    • 衰退根扇：灰青褐—柔和铜紫；
    • 封闭旧根扇：暗铜褐—灰紫褐；
    • 根鞘：淡琥珀青灰微纹，仅在特写中清楚。

    背景

    • 腐殖层为低饱和暖褐、矿物灰和局部湿暗色；
    • 背景综合色不得覆盖或污染活体主色；
    • 无统一蓝紫灰滤镜；
    • 无霓虹、荧光、虹彩、金属和宝石高光。

    5. 比例与尺度

    使用最终视觉身份闸门工作值：

    • 叶长 35—85 厘米；
    • 叶宽 16—38 厘米；
    • 叶冠高 40—85 厘米，局部可接近 100 厘米；
    • 冠幅 0.7—1.6 米；
    • 根冠直径 25—60 厘米；
    • 根冠高出常态湿面 8—24 厘米；
    • 单根扇长 25—80 厘米；
    • 单根扇最大宽 15—55 厘米；
    • 成年根区跨度 0.9—2.2 米；
    • 生殖轴总高 65—120 厘米。

    图鉴必须设置成年人手掌、标准尺或明确比例尺之一，但不得出现埃纳身体作为比例参照，以免提前冻结文明互动。

    6. 中文说明要求

    • 标题、P0—P5、核心结构名称和关键边界优先；
    • 文字短句化，避免大段伪科学文本；
    • 不使用英文标签、拉丁文和现代 UI；
    • 若生成模型出现错字、乱码或术语错误，该图不能直接归档；
    • 允许在后期排版中重建中文文字，但不得改变已审核的生物主体结构。

    建议核心标签：

    • 抬高分区根冠；
    • 长寿结构根；
    • 狭窄连接颈；
    • 新生换根扇；
    • 成熟换根扇；
    • 衰退换根扇；
    • 封闭旧根扇；
    • 腐殖电子缓冲鞘；

    7. 允许出现的环境

    允许：

    • Z5 湿润腐殖层上缘和侧缘；
    • 根塔支座下方有散射光和空气交换的腐殖土袋；
    • 老根、落物、矿物细土形成的微隆起；
    • P5 退水后重新氧化的边界；
    • 有限鲁拉纳接缝、N 或其他背景植物的远离局部，但不得融合；
    • 少量根际微生物膜和分解残体作为环境纹理。

    不允许：

    • 永久水下环境；
    • 深腐殖完全无光核心；
    • 连续洪流和砾滩；
    • 整齐农田、花盆、温室和人工排水设施；
    • 地下发光洞穴；
    • 跨植物根网和营养管道；
    • 大量同种植株连续覆盖。

    8. 跨物种与文明边界

    首张野生基础种图鉴不展示：

    • 埃纳采集、移栽、分株或使用场景；
    • 半管理型和成熟栽培品系；
    • 人工基质、沟渠、容器和工具；
    • 物种为其他植物主动净化或输送营养；
    • 专性不可替代微生物伙伴；
    • 病原怪物、拟人化免疫和地下通信网络。

    只允许文字标记：

    “可被埃纳驯化；文明干预与人工选择专项已触发，待野生基础种完成后单独审核。”
