    Project AE｜植物系统二次重构总规则 V0.1

    版本：V0.1
    状态：现行重构方法层／待用户最终冻结
    适用范围：M5 植物系统中除已最终确认的 M5-04A/B、M5-04D 外，所有尚未定稿植物；若未来用户明确重开 A/B 或 D，也必须遵守本规则。

    1. 重构原因

    旧植物系统在部分物种中仍存在以下方法问题：

    1. 先确定“雾帆、膜伞、输水藤、滤根”等视觉或功能母题，再补充生态理由；
    2. 把物种描述为水分、矿物和营养的公共基础设施，弱化了个体自身的适应收益；
    3. 不同植物被组织成过度顺滑的输入—缓冲—输送—储存网络，真实竞争、资源截留、失败和死亡不足；
    4. 多种植物重复使用透明膜、湿膜、根际网络、断片再生等相似语言，造成生态和视觉同质化；
    5. P2 常态生存能力不足，部分物种只在 P3—P4 特殊窗口中才成立；
    6. 形态异星化与祖先同源结构脱节，器官容易像人工装置。

    因此，尚未定稿植物全部撤回到“生态推演前”状态，不再沿旧物种顺序机械修补。

    2. 新的推导顺序

    所有新植物必须按以下顺序生成：

    区域物理环境
→ P0—P4 时间变化
→ 光、水、氧、矿物、腐殖、风和稳定附着面的梯度
→ 已有物种占位与竞争
→ 扰动、植食、病原、分解和演替
→ 尚未被充分利用的生态窗口
→ 候选祖先母型
→ 2—4 种可竞争的生存策略
→ 选择优势、代价和失败条件
→ 能量与物质收支
→ 器官、生理、繁殖和种群
→ 最后才推导综合色、材质和整体形态

    禁止从“希望画出什么样子”反向创造生态位。

    3. 物种成立前的生态推演卡

    任何候选在进入正式闸门前，必须先完成一张全文生态推演卡：

    项目 必须回答的问题
    微生境 它在 Z1—Z7 的什么位置实际建立？
    时间窗口 P0—P4 中何时生产、何时休眠、何时死亡风险最高？
    限制资源 最稀缺的是光、水、氧、矿物、空间还是安全繁殖点？
    已有竞争者 A/B、D 及未来其他植物怎样压制它？
    祖先母型 根、茎、叶、根冠、鳞芽、藤本或附生枝系从何而来？
    候选策略 至少比较两种能够独立成立的策略，不直接锁定第一想法。
    选择优势 为什么该策略能在局部提高后代成功率？
    核心代价 它因此失去了什么能力，在哪些环境中会失败？
    能量收支 P2 是否能长期正收支，P3 是否只是增益而非唯一生存条件？
    繁殖更新 如何进行遗传重组、传播和幼体建立？
    种群限制 为什么不能无限扩张或由单一克隆永久统治？
    视觉结果 外形必须由上述机制自然产生。

    推演卡未闭合，禁止进入科学图鉴 Prompt。

    4. “埃纳特色植物”的生物学语法

    4.1 节律适应

    植物必须对 P0—P4 产生真实且有成本的响应。不得把 P4 一律写成最旺盛阶段，也不得直接感知抽象阶段名称。

    4.2 分布式容错，但不统一模板化

    Project AE 可以保留多生长点、局部隔离、模块退出和分区更新等特征，但不同物种必须采用不同器官路线。不得把所有植物都做成垫层、网络或可断片再生模块。

    4.3 竞争优先于生态服务

    任何所谓“保水、固土、过滤、供食、改风、供氧”必须首先是该物种自身适应的副作用。植物不会为了维持群落平衡主动向竞争者输送关键资源。

    4.4 地球母型可追溯

    异星结构必须能追溯到已有植物器官的连续改造，如：

    • 根冠与储藏根；
    • 匍匐茎与短枝；
    • 叶片、叶柄和叶鞘；
    • 鳞芽和地下茎；
    • 藤本缠绕轴；
    • 附生根与短枝群；
    • 木质支撑轴和复叶系统。

    禁止以“异星组织”代替同源解释。

    4.5 视觉异星感的来源

    异星感来自器官组合、比例、组织分区、生命周期和生态位置，不依赖：

    • 主动发光；
    • 永久湿亮；
    • 透明果冻膜；
    • 金属皮肤；
    • 无机制虹彩；
    • 魔法雾气；
    • 无成本快速变形。

    5. 现行冻结与撤回边界

    保持冻结

    • M5-04A/B：根塔植物，同一物种的标准成年型与条件性超巨体型；
    • M5-04D：基生垫层植物｜鲁拉纳 / Rulana。

    全部撤回到历史层

    • M5-04C 的旧“储根丘 + 三层透明膜伞 + 繁殖灯囊”方案；
    • M5-04E 至 M5-04K 的旧形态、旧功能链和未确认图像；
    • 已写但未获用户批准的 M5-04E 三道闸门。

    撤回不等于删除。旧材料继续保存在历史目录，用于检查重复、冲突和可回收母题，但不再是现行底盘。

    6. 编号规则

    1. M5-04A/B 和 M5-04D 保持原编号；
    2. M5-04C 必须保留为独立待重构编号，不得遗漏、吞并或用重编号补洞；
    3. E—K 继续保留为开发槽位，但是否形成独立物种由生态推演决定；
    4. 若某一槽位最终不需要独立物种，标记为“保留空缺／未成立”，不得自动挪用后续编号；
    5. 旧中文名、埃纳语名和英文转写在重构阶段全部降为历史候选，除非用户再次确认。

    7. 新的开发阶段

    阶段一：区域生态底盘

    • 建立 M6-R01 生态位—资源—竞争矩阵；
    • 把 A/B、D 放回矩阵；
    • 标记空缺和冲突。

    阶段二：策略比较

    • 每个空缺提出 2—4 种策略；
    • 比较能量、竞争、繁殖、风险和视觉区分度；
    • 不先命名。

    阶段三：物种成立

    • 指定编号；
    • 完成生态推演卡；
    • 进入完整闸门；
    • 用户批准后全文落盘。

    阶段四：视觉生成

    • 先生成结构底图；
    • 实际成图经过视觉差异、审美、科学输出审核；
    • 只有用户确认图进入正式资产。

    8. 回退条件

    出现下列任一情况，候选必须退回生态推演：

    • P2 无法正收支；
    • 依赖另一个未成立物种无条件供水或供肥；
    • 只有生态服务，没有个体适应收益；
    • 没有直接竞争者和失败环境；
    • 祖先器官无法追溯；
    • 繁殖只剩断片复制，缺少遗传更新；
    • 视觉母题先于生理结构；
    • 与 A/B、D 或另一候选占据相同生态位且没有明确分化；
    • 需要永久湿膜、全年浓雾或魔法发光才能成立。

    9. 当前裁决

    本规则作为植物系统二次重构的现行方法层。从本版起，不再继续审核旧 M5-04E；下一项工作是基于区域矩阵优先重构 M5-04C。
