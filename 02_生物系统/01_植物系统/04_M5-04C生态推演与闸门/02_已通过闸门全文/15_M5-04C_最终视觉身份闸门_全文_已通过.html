    M5-04C｜最终视觉身份闸门

    版本：V0.7.34 工作检查点
    状态：完整正文／待用户审核
    对象：M5-04C 野生基础种
    归档性质：完整判断正文，不得以摘要替代

    一、审查目标

    本闸门判断 M5-04C 能否在不依赖文字说明的情况下，被识别为一种由其生态位、地下储能策略和季节生活史自然推导出的 Project AE 植物。

    必须同时解决：

    • 地上轮廓是否体现“多冠点、季节出叶、上部展开”；
    • 地下轮廓是否体现“分区根冠、分散储根、连接颈隔离”；
    • 叶片是否仍能追溯到普通宽叶，而不是人工折扇、草叶或膜帆；
    • 密能聚糖是否有可视结构证据，但不被宝石化、发光化或糖浆化；
    • 远景、中景、近景和剖面是否形成一致的同一物种；
    • 与 M5-04A/B 根塔和 M5-04D 鲁拉纳是否具有清楚差异；
    • 是否为后续野生型科学图鉴提供稳定视觉标准件。

    二、原始视觉设定

    历史 M5-04C 曾采用“储根丘、三层透明膜伞、繁殖灯囊、地下芽核”的视觉母题。其可保留的问题意识只有：

    • 地下储备是第一生态核心；
    • 地上器官具有明显季节性；
    • P1 快速展开、P0 地上退出；
    • 地下器官需要与普通浅根植物形成差异。

    以下旧视觉正式作废：

    • 地表泥丘或裸露块根；
    • 三层透明光合膜伞；
    • 发光或灯具式繁殖囊；
    • 中央单一巨型块根；
    • 向群落输送水肥的公共储库；
    • 晶体、宝石或透明糖液式密能物质。

    三、问题诊断

    1. 若只画季节叶束，容易退化为普通草丛、蕨类、棕榈幼株或观赏花叶植物；
    2. 若只强调深裂，容易成为规则折扇、羽状复叶或机械切割的带状叶；
    3. 若储根画得过圆，会像土豆、球根或成串果实；
    4. 若储根画得过长，会像触手、肠道或地下动物器官；
    5. 若密能颗粒过亮，会像发光晶体、蜂蜜或矿石；
    6. 若根冠过大，会恢复旧“单一储根丘”结构；
    7. 若多个冠点排列过整齐，会像人工种植的农作物；
    8. 若地上过于繁密，会违背稀疏中层生产者和地下高投资策略；
    9. 若地上过于稀弱，又无法证明 P2 可以偿还密能聚糖的高成本；
    10. 若只展示健康完整个体，会丢失连接颈牺牲、叶片退出和病害压力的真实生命史。

    四、判断逻辑

    M5-04C 的视觉必须由以下因果链直接产生：

    地下分散高能储备
→ 多冠区分批启动
→ 窄基折叠芽矛穿过低位覆盖
→ 离开地表边界层后形成宽薄光合面积
→ 叶片上部深裂以降低风载和撕裂
→ P2 恢复储备
→ P0 地上退出、地下保留

    因此，第一识别特征不能只是“有大根”或“有漂亮裂叶”，而必须同时出现：

    多个错位冠点抽出的窄基折叠叶束，在中层展开为纵向褶脊、上部深裂的宽薄叶；其下方是分区短缩根冠和向不同方向、不同深度分散的纺锤状密能储根。

    五、优化后的第一视觉身份

    冻结第一识别语句：

    地上轻盈分散、地下厚重分舱的季节性密能储根植物。

    更完整的视觉描述为：

    一个成熟野生个体不是单一莲座，而是由若干相互错位的小冠点组成松散叶束岛。每个冠点先抽出狭窄、纵向折叠的芽矛，随后在较高位置展开为一片不对称宽叶；叶片上部沿纵向深裂成数条长短不一的带状裂片，裂片之间仍保留清楚的共同叶基和主脉关系。地下则由紧凑而分区的短缩根冠连接多条不同方向、不同深度的纺锤状储根，每条储根通过狭窄连接颈独立接入。

    六、地上整体轮廓

    1. 冠点布局

    • 地上可见叶束来自多个冠点，不从一个完美中心放射；
    • 冠点之间有自然间距和高低差；
    • 常态 P2 只启动部分冠点，其余保持地下备用；
    • 整体轮廓为松散、不对称的弧形、折线形或小型岛状群；
    • 不形成整齐圆形莲座、规则扇面或人工行列。

    2. 叶束节奏

    同一个成熟个体应同时包含：

    • 少量仍折叠的芽矛；
    • 多数充分展开的成熟叶；
    • 一至数片受损或开始回收的老叶；
    • P3 时最多一至数根疏开的生殖轴。

    这样可证明分批启动和季节更新，而不是一次性长出完全同步的叶冠。

    七、单叶结构

    一片成熟叶必须保持“单一宽叶同源性”。

    冻结结构

    • 叶基狭窄并纵向折叠；
    • 下部保留连续叶板和清楚主脉；
    • 中上部逐渐展开；
    • 上部约四成至七成区域深裂；
    • 每片叶常见 3—7 条不等宽、不等长的带状裂片；
    • 裂片沿共同主轴分出，不从一点放射；
    • 裂片具有低幅度纵向褶脊和柔韧纤维脉；
    • 叶缘自然波动、轻度磨损，不能像机器切割。

    禁止形态

    • 普通禾草线叶；
    • 羽状复叶或典型蕨叶；
    • 棕榈扇叶；
    • 芭蕉或天堂鸟式完整巨叶；
    • 龙舌兰、多肉莲座和带刺剑叶；
    • 透明膜帆；
    • 螺旋机械折扇；
    • 海藻、海带和水下飘带。

    八、地下根冠与储根

    1. 分区短缩根冠

    • 根冠低矮、紧凑、略横向展开；
    • 具有 3—8 个可辨但连续的冠区；
    • 冠区通过较窄的组织桥连接；
    • 根冠不膨大成一个主块根；
    • 多方向锚定根进入稳定基质。

    2. 分散储根

    • 成年个体具有约 5—20 条储根；
    • 储根为长纺锤形、泪滴纺锤形或轻度弯曲纺锤形；
    • 两端逐渐收窄，不是球形、串珠形或香肠形；
    • 分布于不同方向、不同深度；
    • 彼此不融合，不构成连续地下层；
    • 每条通过短而窄的连接颈接入一个冠区；
    • 可见一条旧伤封闭或被牺牲的储根，但不能以腐烂为主视觉。

    3. 储根切面

    切面必须清楚表现：

    1. 矿土紫褐—灰铜色外部防护换气层；
    2. 暖象牙米—浅琥珀色活性代谢环；
    3. 蜂蜡金米—乳灰琥珀色密能颗粒区；
    4. 柔和铜褐—灰红铜色中央输导隔离轴。

    密能颗粒只表现为细密乳浊、粉蜡或细颗粒散射，不能出现肉眼晶簇。

    九、生殖结构

    P3 生殖轴应为：

    • 从少数成熟冠区伸出；
    • 高于主要叶束，但不形成高大树状结构；
    • 柔韧、疏分枝、空气可穿过；
    • 小型退化花器沿短侧枝错位排列；
    • 可见少量外露花药和分叉或丝状受粉结构；
    • 果实为小型干性分裂果或分节蒴果；
    • 综合色采用灰金绿、浅铜金、乳金和暖灰褐。

    禁止大型花瓣、灯笼果、发光花序、禾本科大穗和艳丽花海。

    十、幼体视觉序列

    图鉴必须证明幼体不会一开始就拥有成熟储根：

    1. 种子萌发与胚根；
    2. 一至两片简单幼叶；
    3. 单冠幼体与一条轻度增粗初级根；
    4. 多叶幼体，叶缘仅浅裂；
    5. 分区根冠亚成体，开始形成低水化颗粒；
    6. 多冠区成熟个体与分散密能储根；
    7. 少量合法子冠分离。

    普通储根碎片、叶片和吸收根不得画成独立新植株。

    十一、工作尺度

    为保证首轮图鉴具备稳定比例，提出以下工作尺度：

    • 成熟季节叶常见长度约 45—105 厘米；
    • 展开叶板最大宽度约 18—42 厘米；
    • 叶基折叠状态宽约 2—6 厘米；
    • 单片叶常见 3—7 条深裂带状裂片；
    • 常态叶束高度约 55—115 厘米，健壮个体局部可接近 130 厘米；
    • 一个活性冠点常见同时维持 1—3 片成熟叶；
    • P2 地上可见整体展开跨度约 0.6—1.5 米；
    • 生殖轴总高约 0.9—1.6 米；
    • 根冠主体埋深约 15—35 厘米；
    • 单条成熟储根长约 20—60 厘米，常见最大径约 5—15 厘米；
    • 健壮老储根局部最大径可接近 18 厘米；
    • 完整成年根区常见水平跨度约 0.6—1.4 米。

    这些是视觉和生态回算用的工作范围，不代表所有地区个体尺寸一致。地方生态型和未来驯化型必须另行审核。

    十二、与现行 Project AE 植物的差异

    与 M5-04A/B 根塔

    根塔是长期常驻的地貌级高层巨构；C 是季节性中层叶束，地下储备远大于地上持久结构。

    与 M5-04D 鲁拉纳

    鲁拉纳低伏、连续度高、由宽化匍匐模块组成；C 竖向、稀疏、由多个冠点抽出深裂宽叶，并在地下形成分散储根。

    与未来休眠或储备植物

    后续物种不得复制“多冠区＋分散密能储根＋P1 深裂季叶束”这一完整组合。即使也休眠或储能，也必须在器官母型、环境位置和时间策略上分化。

    十三、证据与成立依据

    • 地上多冠点对应已冻结的冠区自治和分批启动；
    • 窄基折叠对应穿过鲁拉纳接缝的机械需求；
    • 上部宽薄深裂对应短叶期内快速获得叶面积、同时降低风载；
    • 分散纺锤储根对应掘食、根腐和单点失效压力；
    • 四区切面对应密能聚糖封装、氧化防护与连接颈隔离；
    • 稀疏中层轮廓对应高地下投资和有限光窗；
    • 局部伤痕对应病原专项和多年寿命，而非装饰性破损。

    十四、成本与视觉代价

    • 同时展示地上和地下结构，构图信息密度高；
    • 深裂叶稍有处理不当就会地球棕榈化或蕨类化；
    • 多储根稍有重复就会土豆堆或动物内脏化；
    • 叶束过疏会显得无法供能，过密会像热带观赏植物；
    • 密能颗粒太弱看不出特色，太强又会晶体化；
    • 旧伤必须真实但克制，避免腐败恐怖感。

    十五、外部依赖

    • M6-R01 土层深度和典型土袋剖面；
    • 后续具体掘食动物的体型与挖掘能力；
    • 共生星生化模块对密能聚糖精确结构的裁决；
    • 正式命名专项；
    • 图像生成模型对同一植株地上—地下连续结构的保持能力。

    十六、冻结项

    1. 第一识别核心为“地上轻盈分散、地下厚重分舱”；
    2. 地上由多个错位冠点形成松散叶束岛；
    3. 单叶是窄基折叠、下部连续、中上部深裂的同源宽叶；
    4. 每片叶常见 3—7 条不等带状裂片；
    5. 叶片具有纵向褶脊，但不是折扇或膜帆；
    6. 根冠紧凑分区，不形成主块根；
    7. 储根为不同深度分散的长纺锤体；
    8. 每条储根通过狭窄连接颈独立接入；
    9. 储根切面采用四区结构和已批准综合色；
    10. 密能颗粒非发光、非透明、非宝石；
    11. P3 生殖轴疏开、风媒化、无大型花瓣；
    12. 幼体从简单叶和普通储备逐步形成成熟结构；
    13. 采用本闸门的工作尺度范围；
    14. 野生个体必须保留轻度年龄差、损伤和不同步性。

    十七、未决项

    • 单叶裂片最适数量与不对称程度；
    • 根冠冠区的最佳可视分界；
    • 生殖轴侧枝和果实精确形态；
    • 各地方生态型的尺度偏移；
    • 正式中文名、埃纳语名及英文转写；
    • 是否另制密能储根解剖标准件图。

    十八、回退条件

    • 地上被画成草丛、棕榈、蕨、龙舌兰、芭蕉或多肉莲座；
    • 深裂叶成为规则机械折扇或透明膜帆；
    • 冠点从一个完美中心放射；
    • 储根成为土豆堆、球根串、触手、肠道或动物卵；
    • 根冠膨大成单一巨型块根；
    • 密能颗粒成为发光晶体、蜂蜜、果冻或矿石；
    • 地上过度繁茂，像常绿热带作物；
    • 地下器官无连接颈、无分区或无不同深度；
    • 图像看不出幼体与成熟体的发育差异；
    • 视觉与鲁拉纳或根塔失去明确层级差异。

    十九、裁决

    最终视觉身份闸门：拟条件通过

    通过条件：后续候选图必须同时通过“多冠点季叶束、单叶同源深裂、分区根冠、分散纺锤储根、四区密能切面”五项核心识别；任何一项退化为地球常见作物、人工器官或幻想晶体，都必须返工。

    原始设定

    M5-04C 旧视觉曾采用储根丘、透明膜伞和灯囊式繁殖结构，且未明确地上叶面积与地下储备体量之间的对应关系。该旧视觉已被前序闸门废止，本闸门只依据现行分区根冠、分散储根和季节深裂宽叶体系建立视觉身份。

    优化方案

    以“地上轻盈分散、地下厚重分舱”为总视觉母题：地上采用多个错位冠点与宽叶同源的深裂褶带叶；地下采用分区短缩根冠、长纺锤储根、狭窄连接颈和四区切面；通过地表—地下连续剖切证明能量闭环。

    通过依据

    • 视觉结构与已通过的生理、生物力学、竞争、繁殖和病原机制一致；
    • 单叶、根冠、储根和连接颈均有明确祖先同源与功能来源；
    • 地上叶面积与地下储备尺度具有可视化对应；
    • 能与根塔、鲁拉纳及旧植物母题形成稳定差异。

    成本与代价

    • 多冠点和多储根会提高图像构图复杂度；
    • 深裂叶容易被误画成草、蕨、棕榈或人工折扇；
    • 储根易被误画成地球块根、动物内脏或晶体；
    • 地表—地下同图会压缩每个器官的展示空间。
