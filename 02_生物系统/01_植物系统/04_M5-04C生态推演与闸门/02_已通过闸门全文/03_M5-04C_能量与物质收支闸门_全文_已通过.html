    M5-04C｜能量与物质收支闸门

    版本：V0.2
    状态：完整正文／用户已确认通过（2026-07-11）
    核心修订：快速糖库＋密能聚糖长期储备

    一、审查目标

    证明 M5-04C 能够依靠季节叶束在 P2 偿还 P0 维护、P1 出叶、地下器官建设、防御、密能聚糖合成和 P3 有性繁殖成本；同时确认其高能储备不会成为免费能量、无限休眠或无成本农业资源。

    二、原始设定

    旧 C 同时拥有大型储根、多层膜伞、营养缓释和地下芽核，但没有能量来源和完整预算。V0.7.28 已建立“P0 保存—P1 出叶—P2 偿债—P3 繁殖—P4 局部牺牲”模型，储备仍按地球淀粉或果聚糖类处理。

    用户提出并批准：共生星的营养物质不必与地球完全相同，M5-04C 可合成高能量储能聚糖，并在未来被埃纳驯化改良。

    三、问题诊断

    1. 若密能聚糖只被描述为“更高能”，会违反能量来源与化学约束；
    2. 单一高能储备难以同时满足快速启动和长期保存；
    3. 高还原储备的合成需要更多还原力，不能忽略机会成本；
    4. 高能物质破损后的氧化、病原和植食风险必须进入预算；
    5. 高效动员通常依赖氧气，P4 根区低氧会限制实际可用能量；
    6. 埃纳未来选择高产性状不能被计入野生型收支；
    7. 叶面积若不足，任何高能储根都只是在延迟能量亏空。

    四、判断逻辑

    1. 能量来源

    密能聚糖的全部化学能来自季节叶束固定的碳和还原力。植物必须先制造糖类前体，再支付额外合成、脱水、封装和抗氧化成本。

    2. 能量密度边界

    现阶段只冻结“单位干重能量介于普通储能聚糖与脂质之间”。不冻结超过脂质的数值，也不定义不受氧化还原约束的异星键能。

    3. 双储备必要性

    • 快速糖库负责秒至日尺度的启动和修复；
    • 密能聚糖负责周至跨周期的长期储能；
    • 两者之间存在转化损耗，不能无损往返。

    4. 地下储藏需要组织化

    密能颗粒必须在专化细胞中低含水、半结晶封装，并由抗氧化物和隔离组织保护。不能以自由糖浆、油池或发光液体形式存在。

    5. 高价值储根会重塑生态

    更高单位干重能量提高了掘食收益，也要求更强防御和病原隔离。储能优势必须与更高生物风险同时存在。

    五、优化方案

    保留

    • P0 保存、P1 出叶、P2 偿债、P3 盈余繁殖、P4 局部牺牲的年度收支框架；
    • 季节叶束作为主要碳输入器官；
    • 分布式储根降低单点失效；
    • 资源不足时优先取消繁殖和子冠。

    废止

    • 以普通地球淀粉作为唯一储备解释；
    • 把储根本身当作能量制造器官；
    • 巨量自由糖浆、发光能量液或地下油池；
    • P4 水分越多、能量利用越强；
    • 储根受损后无氧化、病原和掘食代价；
    • 用未来埃纳管理补偿野生型负收支。

    新增

    • 快速可溶性糖库与密能聚糖库分工；
    • 糖源高还原聚合物的合成与封装成本；
    • 储根外防护、活性代谢、颗粒储藏和输导隔离四区；
    • P4 低氧对高能储备实际可用性的限制；
    • 专化掘食者与消化酶接口；
    • 野生型与未来驯化型分开的收支模型。

    六、优化后的双储备系统

    快速可溶性糖库

    主要分布在根冠、连接颈和活性代谢层，用于：

    • P0 最低代谢；
    • P1 芽点启动；
    • 伤口封闭；
    • 密能分解酶和输导系统启动；
    • 短时低温、缺氧或机械损伤响应。

    其储量受渗透压限制，不能承担长期大规模储能。

    密能聚糖库

    主要储存在储根专化细胞的半结晶颗粒中，用于：

    • 跨越 P0；
    • P1 持续出叶；
    • 大规模损伤后的重建；
    • P3 有性繁殖；
    • 连续不利周期的缓冲。

    动员顺序为表面颗粒优先、深层颗粒后用，避免一次性分解导致渗透和氧化负荷过高。

    七、储根组织与物质流

    1. 外部防护层

    • 降低失水和掘食；
    • 含收敛、苦味或消化抑制物；
    • 维持有限气体交换；
    • 不能厚到使储根内部长期缺氧。

    2. 活性代谢层

    • 接收叶片输出的可溶性前体；
    • 合成密能聚糖；
    • 产生抗氧化物；
    • 在 P1 动员储备；
    • 修复局部伤口。

    3. 密能颗粒区

    • 低含水；
    • 半结晶；
    • 小室化储藏；
    • 减少渗透压和酶失控；
    • 破损时局部氧化封闭。

    4. 中央输导—隔离轴

    • 与根冠交换糖、水和矿物；
    • 感知液压骤降和感染；
    • 形成封闭层；
    • 必要时牺牲整条储根。

    八、合成成本与机会成本

    密能聚糖合成需要：

    • 额外光合还原力；
    • ATP 或等效能量投入；
    • 专化合成酶；
    • 抗氧化和稳定化物质；
    • 氮、磷和微量元素支持酶系统；
    • 储藏细胞与颗粒封装结构。

    因此同样的光合盈余如果用于叶片、根系或种子，短期增长会更快。C 选择的是较慢增长、较高跨周期安全性，而不是最大即时生产率。

    九、碳与资源分配顺序

    1. 维持当前叶片、吸收根和活性冠区；
    2. 偿还 P1 出叶消耗；
    3. 恢复快速糖库；
    4. 修复掘食、叶损和根区损伤；
    5. 恢复最低安全密能储备；
    6. 更新老化储根和吸收根；
    7. 增加次生叶束；
    8. 有性繁殖；
    9. 形成子冠和额外储根。

    在资源不足时，子冠、额外储根和大规模繁殖最先取消。

    十、P0—P4 收支

    P0｜受控净消耗

    • 快速糖承担即时需求；
    • 密能聚糖缓慢分解；
    • 呼吸和抗病维护仍持续；
    • 储备不断下降；
    • 无法无限休眠。

    P1｜显著储备债务

    • 先用快速糖启动芽点；
    • 再调用密能聚糖支撑叶片展开；
    • 叶面形成前净收支为负；
    • 多冠点分批启动降低一次性峰值消耗。

    P2｜主要净正收支

    • 叶束固定碳并恢复快速糖；
    • 达到维护和偿债要求后才合成密能聚糖；
    • 良好根区供氧支持高效呼吸、运输和合成；
    • P2 若不能恢复安全储备，个体逐年衰退。

    P3｜盈余和繁殖竞争

    • 水、营养和光合产量可能提高；
    • 密能合成、有性繁殖和子冠争夺同一盈余；
    • 只有储备高于安全阈值的个体才繁殖；
    • 掘食、植食和病原同步增强。

    P4｜可用能量受限

    • 根区低氧抑制密能聚糖的高效氧化利用；
    • 局部发酵只能提供有限应急能量并产生代谢负担；
    • 关闭感染或缺氧储根；
    • 净收支可能严重为负；
    • 水多不等于能量可用。

    十一、水、矿物和氧预算

    水

    主要来自自身深浅吸收根。储根只保存有限结合水，不是水库。

    氮、磷和微量元素

    用于叶片、酶系统、输导和抗氧化物。密能聚糖本身可能主要由碳、氢、氧组成，但其合成和维护高度依赖含氮酶和矿物辅因子。

    氧

    • P2 根区需要维持足够氧气；
    • 密能储备高效动员依赖有氧代谢；
    • P4 低氧是核心限制；
    • 不能把高能储备理解为缺氧时仍可无限释放能量。

    十二、植食、氧化与病原预算

    掘食损失

    一条成熟储根被取食会同时损失：

    • 高密度碳储备；
    • 矿物和结构组织；
    • 多年建设投入；
    • 后续出叶和繁殖能力。

    氧化损失

    储藏细胞破裂后，密能物质可能快速氧化。植物通过小室化、抗氧化物和交联封闭限制损失，但无法完全避免。

    病原损失

    高能伤口为微生物提供优质底物。连接颈必须快速封闭；若失败，感染可能进入根冠并造成多冠区死亡。

    消化专化

    并非所有动物都能高效利用密能聚糖。专化掘食者可能拥有自身酶系或肠道微生物；非专化动物只能利用快速糖和部分外层组织。这一差异留给动物系统回填。

    十三、野生型与未来驯化型的收支边界

    野生型优先：

    • 分散风险；
    • 维持防御；
    • 保留成熟时间差；
    • 确保 P0 生存和有性更新。

    未来埃纳驯化可能选择：

    • 更高储根产量；
    • 更高可消化性；
    • 更低结晶度或防御物；
    • 更集中、同步的储根簇；
    • 更明确的采收脱离层。

    这些改良通常会增加病虫害、根腐、营养需求和人工管理依赖，不能写回野生型预算。

    十四、通过依据

    1. 密能聚糖的能量来源追溯到光合作用；
    2. 能量密度被限制在普通聚糖和脂质之间；
    3. 双储备系统解决快速启动与长期保存的冲突；
    4. P2 是主要净生产与密能合成阶段；
    5. P0、P1、P3、P4 均具有明确成本；
    6. 储根组织能够解释封装、动员和损伤隔离；
    7. 掘食、氧化、病原和低氧限制阻止高能储备成为全能优势；
    8. 驯化收益和代价被隔离到未来专项。

    十五、成本与代价

    1. 合成密能聚糖的转化损耗；
    2. 专化酶和抗氧化体系的氮磷成本；
    3. 储藏细胞和封装结构的建设成本；
    4. 动员速度慢于快速糖；
    5. 低氧环境下可用性下降；
    6. 高价值导致掘食压力增加；
    7. 破损后氧化和病原风险高；
    8. 分布式储根重复建设成本；
    9. 叶期不足时无法恢复储备；
    10. 繁殖与储能相互排斥。

    十六、依赖项

    • 共生星基础糖代谢和氧化还原体系；
    • 密能聚糖精确化学结构；
    • 单位叶面积净生产率；
    • 有效叶期；
    • P0 储备消耗速度；
    • P4 根区氧分压；
    • 掘食者消化系统；
    • 储根抗氧化和封闭速度；
    • 有性繁殖年度预算；
    • 埃纳加工和消化方式。

    十七、冻结项

    1. 主要碳输入来自季节叶束；
    2. 野生 C 采用快速糖库＋密能聚糖库；
    3. 密能聚糖为低含水、半结晶、高还原度糖源储能聚合物；
    4. 单位干重能量介于普通储能聚糖和脂质之间；
    5. 密能合成具有额外还原力、酶、矿物和封装成本；
    6. 快速糖负责即时启动，密能聚糖负责长期储备；
    7. P0 为受控净消耗；
    8. P1 形成显著储备债务；
    9. P2 必须偿债并恢复安全密能储备；
    10. P3 只有盈余时才能繁殖和形成子冠；
    11. P4 低氧会降低密能储备的实际可用性；
    12. 储根采用外防护、代谢层、颗粒区和输导隔离轴的功能分区；
    13. 掘食、氧化和病原造成真实高额损失；
    14. 不能多年无叶无限存活；
    15. 不主动向其他植物缓释关键储备；
    16. 未来驯化型的高产和易消化性不属于野生型自然预算。

    十八、未决项

    1. 密能聚糖精确化学结构和能量密度；
    2. 快速糖与密能聚糖的比例；
    3. 单条储根的安全储量；
    4. P0 可维持周期数；
    5. P1 出叶债务；
    6. P2 最低叶面积和有效叶期；
    7. P3 繁殖预算；
    8. P4 无氧应急代谢能力；
    9. 储根防御物质；
    10. 埃纳驯化后密能聚糖的可消化性和加工方式。

    十九、回退条件

    • 密能聚糖不需要光合投入；
    • 单位能量无限提高或超过脂质而无代价；
    • 只设长期高能库，不设快速启动库；
    • P2 无法恢复储备；
    • P4 缺氧时仍能最大功率动员；
    • 储根被取食后无真实损失；
    • 破损没有氧化和病原风险；
    • 极小叶面积支撑巨大储根簇；
    • 未来埃纳管理被用于补偿野生型负收支；
    • 主动向其他植物输出密能储备成为核心功能。

    二十、最终裁决

    能量与物质收支闸门：条件通过（用户确认）

    通过条件

    1. 后续生理闸门验证颗粒封装、输导、氧化封闭和低氧响应；
    2. 生物力学闸门确定储根外层、连接颈和叶束结构；
    3. 区域参数冻结后回算 P2 叶面积、有效叶期和 P0 消耗；
    4. 繁殖闸门证明有性投入不超过长期净盈余；
    5. 埃纳驯化专项必须另行建立农业收支模型。

    外部依赖

    • M6-R01 区域水文、光照、土层与 P0—P4 参数；
    • 鲁拉纳与根塔的现行冻结设定；
    • 后续繁殖、病原、生物地理与视觉闸门的回填结果；
    • 密能聚糖精确化学结构由共生星统一生化模块另行冻结。
