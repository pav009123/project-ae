    M5-04C｜科学图鉴构图与 Prompt 准入闸门

    版本：V0.7.34 工作检查点
    状态：完整正文／待用户审核
    对象：M5-04C 野生基础种
    归档性质：出图前输出规范与准入判断；不得替代实际成图审核

    一、审查目标

    本闸门判断 M5-04C 的野生基础种设定是否已经足以进入科学图鉴底图 Prompt 和候选图生成，并冻结首张图鉴必须证明的内容、版式、状态、尺度和禁区。

    必须明确：

    • 名称尚未冻结时如何安全进入底图阶段；
    • 首张图鉴以哪个 P 阶段为主；
    • 地上和地下结构如何在同一页建立连续关系；
    • 必须展示哪些器官、切面、繁殖和发育证据；
    • 鲁拉纳可以出现到什么程度；
    • 哪些动物、埃纳和驯化内容不得提前进入；
    • 实际候选图需要接受哪些复核；
    • 什么条件下才能进入确认视觉资产。

    二、原始输出规则

    Project AE 已冻结“双层科学图鉴工作流”：

    第一层：无文字或少文字的高质量视觉底图
第二层：确定性排版添加中文名、埃纳语名、英文转写、比例尺和结构说明

    因此，图像生成阶段禁止依赖模型直接生成准确标签。

    M5-04C 当前正式名称尚未确定，旧名“储根丘植物｜洛姆洛纳 / Lomlona”只保留在历史层，不得自动恢复。

    三、问题诊断

    1. 在名称未定时直接生成带标题图鉴，会错误冻结旧名或临时名；
    2. 只画地上叶束，无法证明密能储根这一物种核心；
    3. 只画地下剖面，会像农业块根解剖图而失去生态状态；
    4. 将地上和地下完整展开在主图中，容易造成比例不一致或断裂拼贴；
    5. 信息区过多会诱发伪文字、伪标签和结构错位；
    6. 鲁拉纳若占比过高，会遮蔽 C 并让二者看似专性互利；
    7. 加入掘食动物、埃纳采集或农田，会提前冻结未完成接口；
    8. 密能颗粒切面容易被模型画成发光晶体；
    9. 生命周期若从成熟块根开始，会遗漏有性种子和幼体高死亡逻辑；
    10. 若首张图只追求漂亮完整个体，会丢失野生不同步、旧伤和局部退出。

    四、判断逻辑

    首张标准图鉴必须优先证明物种自身成立，而不是展示完整食物网或文明利用。

    因此采用：

    P2 成熟野生个体为主体，局部展示 P1 折叠芽矛与 P3 生殖轴；主图使用地表—地下连续剖切视角，右侧和下方展示器官、切面与生命周期。

    P0 和 P4 只作为小型状态对照，不抢占主图。

    五、名称与文字处理

    底图阶段

    • 内部文件名使用“M5-04C 分布式密能储根季叶植物候选”；
    • 图像内不生成标题、中文、英文、编号、标注线、UI 或水印；
    • 预留清楚留白和分区，供后期确定性排版；
    • 不使用旧名“洛姆洛纳”。

    正式标注阶段

    必须在名称专项完成后使用：

    中文正式名＋埃纳语汉语音译＋英文转写

    不得使用拉丁双名法或伪拉丁学名。

    六、首张图鉴状态

    首张图鉴以 P2 稳定生产期 为核心，因为：

    • 叶束能够展示完整光合面积；
    • 地下安全储备正在恢复；
    • 根区含氧和四区储根最易解释；
    • 青瓷绿—雾金—铜紫综合色处于最佳状态；
    • 既不是 P0 的地上缺失，也不是 P4 的病害失衡。

    允许局部加入：

    • P1 尚未完全展开的芽矛；
    • P3 一根或少数生殖轴；
    • 一片进入草金—暖铜褐回收序列的老叶；
    • 一条已封闭旧伤储根。

    七、推荐版式

    采用横向宽屏科学图鉴底图，建议 16:9 或接近 16:9，最高可用分辨率。

    A. 中央—左侧主图：约 55%—65%

    采用斜俯视与局部地表剖切结合的连续生态视图：

    • 地上展示一个成熟野生遗传个体；
    • 2—5 个活性冠点错位分布；
    • 成熟叶、芽矛、老叶和少量生殖轴同时存在；
    • 地下剖切显示分区根冠、连接颈、5—20 条不同方向和深度的储根；
    • 根区穿过矿物—腐殖混合基质并避开石粒；
    • 地表可有有限鲁拉纳边缘，但不能覆盖主体；
    • 主图必须保持地上冠点与地下冠区的空间对应。

    B. 右侧结构特写区：约 25%—30%

    至少包含：

    1. 折叠芽矛到深裂成熟叶的展开序列；
    2. 成熟单叶正面、背面或三分之二视图；
    3. 储根纵剖与四区横剖；
    4. 连接颈正常、封闭和牺牲状态；
    5. 疏分枝生殖轴、小型花器、干果和种子。

    C. 下方生命周期区：约 15%—20%

    至少包含：

    1. 种子；
    2. 胚根和简单幼叶；
    3. 单冠幼体；
    4. 初级储根；
    5. 多冠区亚成体；
    6. 成熟密能储根个体；
    7. 少量合法子冠；
    8. P0 地上退出与下一周期恢复。

    D. 留白区

    预留后期添加：

    • 正式名称；
    • 比例尺；
    • P0—P4 状态说明；
    • 结构编号；
    • 野生型与驯化型边界备注。

    八、主图必须证明的内容

    首张候选图必须一眼或经合理观察证明：

    1. 一个遗传个体由多个冠点组成，而不是一株单茎或单莲座；
    2. 叶片窄基折叠、上部展开；
    3. 深裂仍属于一片连续宽叶；
    4. 地上叶束稀疏但具有足够光合面积；
    5. 根冠紧凑分区且不膨大成主块根；
    6. 储根分散于不同方向和深度；
    7. 每条储根具有狭窄连接颈；
    8. 切面存在四区结构；
    9. 密能颗粒为乳灰琥珀粉蜡组织，不是晶体；
    10. 植物处于排水、含氧的矿物—腐殖土袋；
    11. 与鲁拉纳是空间竞争关系，不是融合共生；
    12. 野生个体具有轻度不同步、旧伤和年龄差；
    13. 生殖结构小型、疏开、风媒化；
    14. 生命周期从有性种子开始。

    九、颜色与光照

    采用 K2V 晴天暖光谱模板。

    地上

    • 主体青瓷绿—橄榄青绿；
    • 主脉和褶脊雾金灰—浅橄榄金；
    • 叶缘和受压区少量铜紫—梅褐；
    • 老叶草金—暖铜褐；
    • P3 生殖轴灰金绿、浅铜金和乳金。

    地下

    • 外层矿土紫褐—灰铜；
    • 活性环暖象牙米—浅琥珀；
    • 密能区蜂蜡金米—乳灰琥珀；
    • 中央轴柔和铜褐—灰红铜。

    光学边界

    • 哑光至半哑光；
    • 不长期湿亮；
    • 不发光、不荧光、不虹彩；
    • 密能颗粒不产生晶体高光；
    • 不使用统一蓝紫灰滤镜；
    • 地下剖面应具有真实散射和组织湿度，但不流淌。

    十、比例与尺度

    图鉴采用视觉身份闸门的工作范围：

    • 叶长 45—105 厘米；
    • 展开叶宽 18—42 厘米；
    • 叶束高 55—115 厘米，局部不超过约 130 厘米；
    • 地上展开跨度 0.6—1.5 米；
    • 生殖轴总高 0.9—1.6 米；
    • 根冠埋深 15—35 厘米；
    • 储根长 20—60 厘米；
    • 储根常见最大径 5—15 厘米；
    • 成年根区水平跨度 0.6—1.4 米。

    主图和局部特写必须遵守同一比例体系，不得让储根比整株地上冠层更巨大。

    十一、允许出现的环境

    允许：

    • Z1 下缘、Z2 下坡或 Z3 高位边缘的排水土袋；
    • 矿物颗粒、浅腐殖层和天然石粒；
    • 斑驳暖日光；
    • 有限鲁拉纳接缝、老中心空缺或边缘；
    • 轻微落叶、旧根道和自然扰动；
    • 少量旧伤和封闭储根。

    不允许：

    • 永久积水、深泥沼和水下环境；
    • 连续浓雾；
    • 整齐农田、畦沟、花盆或温室；
    • 大规模根塔背景压过主体；
    • 地下发光洞穴；
    • 无边界地下根网。

    十二、跨物种与文明边界

    首张标准图鉴不展示：

    • 埃纳采集、烹饪或驯化；
    • 人工栽培品系；
    • 农具、容器或储藏设施；
    • 未完成审核的专化掘食动物；
    • 病原微观形象；
    • 动物帮助植物传播或保护的叙事；
    • 跨植物营养网络。

    鲁拉纳只可作为有限环境背景出现，不能与 C 根系融合、交换发光物质或形成共生器官。

    十三、Prompt 准入依据

    在本批获得用户批准后，M5-04C 野生基础种将具备：

    • 物种成立；
    • 环境与 P0—P4；
    • 能量与物质收支；
    • 生理与生物力学；
    • 竞争；
    • 演化；
    • 繁殖与发育；
    • 种群持续；
    • 感知与响应；
    • 生态网络；
    • 光学；
    • 条件专项判定；
    • 病原与免疫；
    • 迁移与生物地理；
    • 最终视觉身份；
    • 审美与反同质化边界。

    因此可以编写：

    M5-04C 野生基础种科学图鉴视觉底图 Prompt V0.1

    但不得在实际候选图尚未生成和审核前宣称最终图鉴通过。

    十四、实际成图审核清单

    候选图生成后必须逐项检查：

    • 是否仍像草、棕榈、蕨、芭蕉、龙舌兰或园艺观叶植物；
    • 多冠点是否清楚且不规则；
    • 单叶连续性与深裂关系是否成立；
    • 地上叶面积是否足以支持地下储备；
    • 根冠是否分区而非单一巨根；
    • 储根是否长纺锤、分散且处于不同深度；
    • 连接颈是否清楚；
    • 四区切面是否正确；
    • 密能区是否晶体化、糖浆化或食品化；
    • 地上与地下是否属于同一植株；
    • 鲁拉纳是否仅为有限竞争背景；
    • 生殖轴是否过高、过艳或禾本科化；
    • 生命周期是否从种子和简单幼体开始；
    • 是否误加入埃纳、农田、动物共生或公共营养网络；
    • 色彩是否符合功能分区；
    • P2 是否健康但不完美；
    • 比例是否在工作范围内；
    • 是否生成文字、伪字、编号或 UI；
    • 整体是否符合“隐忍蓄势、季节舒展；地上轻盈、地下厚重”。

    任何核心项失败，都不能进入确认视觉资产目录。

    十五、证据与判断依据

    • 双层工作流解决名称未定和模型伪文字问题；
    • 地表—地下连续剖切能同时证明光合和储能闭环；
    • P2 主状态最能展示偿债、增储与成熟综合色；
    • P1 和 P3 局部状态证明分批出叶和条件繁殖；
    • 生命周期从种子开始可防止把无性储根误写为唯一更新方式；
    • 不展示埃纳和农田可保持野生型与驯化型边界；
    • 有限鲁拉纳背景可证明生态位置，但不建立虚假互利。

    十六、成本与风险

    • 地上—地下连续主图对图像模型的一致性要求高；
    • 一页包含叶片、储根、繁殖和生命周期，信息密度较高；
    • 深裂叶容易地球植物化；
    • 储根剖面容易食品化和晶体化；
    • 模型可能把多个冠点误画成多个独立植株；
    • 模型可能把鲁拉纳画成草坪或把 C 画成农作物；
    • 无文字底图需要后期确定性排版；
    • 正式名称尚未完成，不能直接制作终稿标题。

    十七、外部依赖

    • 用户对三道输出准备闸门的裁决；
    • 正式命名专项；
    • 图像模型生成能力；
    • 用户对第一版候选图的结构和审美裁决；
    • 后续确定性图鉴排版工具；
    • 埃纳人工选择与驯化专项的独立开发。

    十八、冻结项

    1. 首张标准图鉴为无文字视觉底图；
    2. 正式名称未定前不使用旧名或临时名作为图内标题；
    3. 主状态为 P2，局部展示 P1 和 P3；
    4. 采用横向宽屏科学图鉴版式；
    5. 主图使用地表—地下连续剖切视角；
    6. 地上必须显示多个错位冠点、折叠芽矛、成熟深裂叶和少量老叶；
    7. 地下必须显示分区根冠、连接颈和不同深度储根；
    8. 右侧必须包括单叶展开、储根四区切面、连接颈和繁殖结构；
    9. 下方生命周期必须从有性种子开始；
    10. 使用已批准配色和工作尺度；
    11. 鲁拉纳只能作为有限背景；
    12. 不展示埃纳、农田、驯化型和未确认动物；
    13. 图像中禁止文字、字母、编号、UI、标注线和水印；
    14. 实际候选图通过完整审核并获用户确认后才能正式归档。

    十九、未决项

    • 正式名称；
    • 最终 Prompt 的具体措辞和权重；
    • 主图地表剖切角度；
    • 右侧特写数量；
    • P0/P4 是否进入首张底图；
    • 是否需要第二张纯地下解剖标准件；
    • 后期标注版的中文术语和比例尺样式。

    二十、回退条件

    • 在实际成图前宣称最终图鉴已经通过；
    • 名称未定却在图内冻结旧名；
    • 主图只展示漂亮叶丛而无地下储根；
    • 主图只展示块根切面而无完整生态个体；
    • 多冠点被画成多个无关植株；
    • 地上和地下比例冲突；
    • 密能颗粒发光、晶体化或流淌；
    • 生命周期删除有性种子；
    • 加入埃纳采集、农田或驯化性状；
    • 鲁拉纳与 C 形成虚假融合网络；
    • 图像含大量伪文字、UI 或错误标注；
    • 未通过审核的图像进入确认资产目录。

    二十一、优化方案补充

    采用双层科学图鉴工作流解决名称未定、伪文字和结构错标问题；采用地表—地下连续剖切主图解决光合器官与密能储根割裂问题；将 P2 作为主状态，并以 P1、P3 局部特写和从种子开始的生命周期补足时间闭环。首轮只生成野生型无文字底图，文明与驯化内容延后。

    二十二、裁决

    科学图鉴构图与 Prompt 准入闸门：拟出图前条件通过

    本裁决仅表示：若本批三道闸门获得用户批准，M5-04C 野生基础种已具备编写无文字科学图鉴底图 Prompt V0.1 和生成候选图的条件。实际图鉴必须在候选图生成后接受第十四节完整审核，并由用户明确确认，才能进入正式视觉资产。

    用户裁决记录

    • 裁决：通过
    • 状态：转入已通过闸门全文目录。
    • 说明：保留正文中的“拟条件通过/拟出图前条件通过”作为审核时原始裁决逻辑，以本用户裁决记录作为最终状态。

    原始设定

    此前尚无符合现行二次重构路线的 M5-04C 科学图鉴构图。旧储根丘、膜伞、灯囊及带名称标题的图鉴方案均不得继续沿用。

    通过依据

    • 十六道前置闸门已提供完整生态、生理、繁殖、种群、病原、生物地理和视觉约束；
    • 地表—地下连续剖切可同时证明叶面积、根冠分区和储根体量；
    • 右侧特写与下方生命周期可以覆盖关键器官和有性更新；
    • 无文字底图规避正式名称尚未冻结和生成文字失真的风险。

    成本与代价

    • 首张图鉴信息密度较高，必须控制版面拥挤；
    • 生成模型可能混淆多个冠点与多个遗传个体；
    • 多个局部特写可能出现器官形态不一致；
    • 无文字底图需要后期确定性排版才能形成最终出版图鉴。

    最终裁决

    科学图鉴构图与 Prompt 准入闸门：用户确认出图前通过
