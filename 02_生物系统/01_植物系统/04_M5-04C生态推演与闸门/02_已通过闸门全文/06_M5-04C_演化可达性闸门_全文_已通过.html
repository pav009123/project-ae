    M5-04C｜演化可达性闸门

    版本：V0.1
    状态：完整正文／用户已确认通过（2026-07-11）
    对象：野生基础种；不包含埃纳人工选择阶段

    一、审查目标

    判断 M5-04C 的分区根冠、多冠点、分散密能储根、连接颈断路、双储备体系和深裂褶带季节叶，是否能够从较普通的多年生维管植物祖先，通过连续、每一步均有即时适应收益的演化阶段形成。

    同时必须解释：

    • 密能聚糖如何从普通糖类储备逐步演化；
    • 为什么没有演化成单一巨大块根、地下超级网络或纯脂质储备；
    • 为什么叶片不是常绿大叶或普通草叶；
    • 埃纳后续驯化为何属于第二层人工选择，而非自然物种起源。

    二、原始设定

    旧 C 的储根丘、透明膜伞、繁殖灯囊和公共资源缓释没有祖先母型和连续中间阶段，属于视觉母题直接成型。

    现行设定已经要求所有器官可追溯到：

    • 地下短缩茎或根冠；
    • 不定根和储藏根；
    • 受保护芽点；
    • 季节性宽叶；
    • 普通糖类储备与植物储藏细胞。

    三、问题诊断

    1. 分区根冠、多储根、密能聚糖和复杂叶片不能一次突变同时出现；
    2. “高还原聚糖”若没有普通糖代谢前体，会像独立魔法生化；
    3. 半结晶颗粒和抗氧化体系必须逐步形成；
    4. 中间祖先必须在没有完整密能体系时也能生存和繁殖；
    5. 分布式储根必须有早于专化掘食者的基础收益；
    6. 深裂折叠叶必须由普通叶板连续变化，而不是新造器官；
    7. 有性繁殖必须从祖先保留，不能在末期重新出现；
    8. 驯化型的大根、高产和低防御不能反向成为野生祖先特征。

    四、判断逻辑

    本闸门采用四项判断原则：

    1. 所有现行器官必须来自祖先已有的根冠、不定根、芽点、宽叶和糖储藏系统；
    2. 每项性状必须通过多个小幅变异逐步形成，不能依赖一次性复杂突变；
    3. 每个中间阶段必须在尚未具备最终密能聚糖和完整分区结构时，仍能独立生存并完成有性繁殖；
    4. 性状组合必须保留机会成本，使单一巨根、地下网络、纯脂质和常绿大叶在特定压力下不如现行折中。

    五、祖先谱系

    合理祖先为：

    具有地下短缩根冠、季节性宽叶、多个不定根和普通储能聚糖的中小型多年生维管植物。

    祖先已具有：

    • P0 或不利季节叶片衰退；
    • P1 从地下芽点恢复；
    • 若干增粗不定根；
    • 普通糖类储备；
    • 完整有性繁殖；
    • 在排水良好的根脊土袋中生长；
    • 基础的伤口封闭和根腐防御。

    它尚不具有密能聚糖、明显分区冠区或深裂褶带叶。

    六、连续演化阶段

    阶段 0｜普通季节性根冠植物

    特征：

    • 一个短缩地下轴；
    • 少量芽点；
    • 多条普通不定根；
    • 宽而较完整的季节叶；
    • 普通储能聚糖。

    即时收益：地下芽点可跨越短期干燥或地表扰动。

    阶段 1｜多芽点与多根储备

    地表损伤和叶期波动选择：

    • 多个芽点；
    • 数条轻度增粗根；
    • 储备分散到多个器官。

    即时收益：单叶、单芽或单根损失不再等于整株死亡。

    此阶段尚无复杂根冠分区。

    阶段 2｜冠区偏向与扇区化输导

    不同芽点逐渐与附近根和叶形成更强的局部输导对应。选择压力来自：

    • 局部根腐；
    • 掘食；
    • 土层斑块化；
    • 不同出叶孔的光窗差异。

    即时收益：资源可优先投入高收益冠区，局部损伤不必牵连全部个体。

    阶段 3｜储根连接颈与局部脱离

    增粗根与根冠之间的过渡区逐渐变窄并加强封闭能力。

    即时收益：

    • 被拉扯的根可以在外围断开；
    • 感染更容易隔离；
    • 老化储根可以退出；
    • 不需要完整成熟密能聚糖即可获益。

    阶段 4｜折叠出土的宽叶

    随着鲁拉纳类低位覆盖层和落叶层增加，祖先中：

    • 叶基更窄；
    • 幼叶纵向折叠；
    • 叶片展开位置上移；
    • 叶缘切裂逐渐加深。

    即时收益：

    • 更容易通过狭缝出土；
    • 展开后仍保持较大光合面积；
    • 深裂降低风载和撕裂传播；
    • 不必等待最终复杂叶形才有优势。

    阶段 5｜普通聚糖的低水化封装

    长期 P0 选择更稳定、较少吸水和较低渗透压的储备颗粒。普通储能聚糖逐步出现：

    • 更高聚合度；
    • 更低溶解度；
    • 更紧密颗粒；
    • 专化储藏细胞；
    • 分批动员酶。

    即时收益：相同储根体积可保存更多干物质，并降低自由糖造成的渗透压力。

    阶段 6｜高还原单体比例和密能聚糖

    糖代谢网络中的变异逐步提高：

    • 去氧糖、糖醇样单体或功能相近低氧化单元的比例；
    • 聚合物的高还原度；
    • 颗粒稳定化和抗氧化能力；
    • 合成酶和分解酶的专化。

    具体单体和键型暂不冻结，但每一步只需提供小幅能量密度或储藏稳定性收益。

    代价同步增加：合成更昂贵、动员更慢、氧化风险更高。

    阶段 7｜快速糖库与长期密能库分工

    单一密能库无法快速启动 P1。选择出：

    • 根冠和连接颈保留较多可溶性快速糖；
    • 储根深部集中密能颗粒；
    • 两套酶系统在不同时间启动。

    即时收益：兼顾快速萌发和长期保存。

    阶段 8｜现行 M5-04C

    最终形成：

    • 分区根冠和多冠区；
    • 多条不同深度的密能储根；
    • 可封闭连接颈；
    • 双储备体系；
    • 折叠出土、上部深裂褶带叶；
    • P0—P4 的局部牺牲和恢复；
    • 完整有性繁殖仍然保留。

    七、密能聚糖的遗传与生化可达性

    密能聚糖不由单一“超级基因”产生，而需要多个已有代谢模块逐步变化：

    • 糖单体合成比例；
    • 去氧或还原反应；
    • 聚合酶底物偏好；
    • 颗粒成核和支化；
    • 储藏小体形成；
    • 分解酶调控；
    • 抗氧化物合成；
    • 不同组织的表达位置。

    这些变化可以先提高储藏稳定性，再逐步提高单位干重能量，不需要一次出现完整新代谢途径。

    精确化学必须在共生星统一生化模块中裁决；当前只冻结演化路径，不冻结分子式。

    八、发育同源关系

    分区根冠

    来源于地下短缩轴的多个腋芽区和扇区化维管束。

    储藏根

    来源于不定根的次生增粗和储藏薄壁组织扩展，不是块茎、果实或动物器官。

    连接颈

    来源于根基部的狭窄过渡区和伤口封闭能力加强。

    深裂褶带叶

    来源于普通宽叶：幼叶卷折增强、叶基缩窄、叶缘深裂和纵向主脉加强。

    储藏颗粒

    来源于祖先质体、液泡或功能相近储藏结构中的普通聚糖颗粒。

    所有器官均有明确同源来源。

    九、主要选择压力

    1. P0 长期地表不利阶段；
    2. P1 短暂且不稳定的恢复窗口；
    3. P2 必须快速回本并保存跨周期能量；
    4. P4 局部低氧和根腐；
    5. 鲁拉纳及落叶层形成的狭窄出叶通道；
    6. 地下掘食与地上植食；
    7. 土袋和光窗空间异质性；
    8. 病原对高密度、高能组织的追踪；
    9. 有性繁殖与储备安全之间的资源冲突。

    十、为什么没有演化成其他方案

    为什么不是单一巨型块根

    • 掘食和根腐形成单点失效；
    • 土层异质性不允许统一大器官；
    • 分散储根更容易局部更新和牺牲。

    为什么不是地下超级网络

    • 维护距离和输导成本增加；
    • 病原传播更快；
    • 不同微地形收益差异大；
    • 有性个体边界和局部自治更有利。

    为什么不是纯脂质储备

    • 脂质虽然密度高，但 P1 快速动员和水溶性运输更困难；
    • 密能聚糖可从既有糖代谢渐进演化；
    • 双糖库更适合快速萌发与长期保存的组合。

    为什么不是常绿大叶

    • P0 维护和失水成本过高；
    • 地表扰动和植食风险大；
    • 季节退出能回收营养并保护地下投资。

    为什么不是普通草叶

    • 草叶束虽然易出土，但在短叶期内难以提供足够光合面积；
    • 深裂宽叶兼顾狭缝出土和展开后的大面积生产。

    十一、埃纳驯化的演化位置

    埃纳人工选择发生在现行野生型完成之后。可能被放大的性状包括：

    • 密能聚糖含量；
    • 储根集中度；
    • 低防御和易消化性；
    • 同步出叶和成熟；
    • 易采收连接层；
    • 无性扩繁能力。

    这些变化会降低病害、掘食和环境波动下的野外适应度，因此不能被写回野生物种的自然演化路径。

    十二、优化方案

    保留

    • 地下储备生态位；
    • 分布式储根；
    • 双储备系统；
    • 季节叶束；
    • 未来埃纳驯化。

    废止

    • 储根丘、透明膜伞和繁殖灯囊突然出现；
    • 单一突变创造密能聚糖；
    • 所有新器官同步形成；
    • 完全无有性繁殖的长期克隆；
    • 用驯化品系解释野生祖先。

    新增

    • 普通根冠祖先；
    • 八阶段连续演化路径；
    • 密能聚糖的渐进低水化—高还原路线；
    • 器官同源和发育来源；
    • 每阶段即时收益与代价；
    • 不继续极端化的选择边界。

    十三、通过依据

    1. 祖先谱系明确且为普通多年生维管植物；
    2. 现行每个器官均可追溯到祖先结构；
    3. 多冠区、连接颈、叶裂和储藏颗粒均可渐进形成；
    4. 密能聚糖先提高稳定性，再提高还原度，不要求突然新化学；
    5. 每个中间阶段均能独立生存和有性繁殖；
    6. 优势始终伴随合成、维护、低氧、掘食和病原代价；
    7. 现行结构没有被写成全能最优；
    8. 埃纳驯化与自然演化层次清楚分开。

    十四、成本与代价

    1. 多冠区和多储根发育调控复杂；
    2. 颗粒封装和抗氧化系统需要额外基因与矿物投入；
    3. 密能聚糖提高单位储能，也提高消费者收益；
    4. 深裂宽叶建设成本高于普通草叶；
    5. 季节退出造成每年重建叶片的债务；
    6. 分区连接降低病原传播，也限制远距离资源共享；
    7. 双储备系统需要两套调控和酶系统；
    8. 专化于 P0—P4 周期后，对长期常湿或稳定深阴环境适应较差；
    9. 成熟个体建立慢，幼体阶段脆弱；
    10. 驯化选择高产后可能迅速损失野外稳定性。

    十五、依赖项

    • 共生星基础糖代谢和密能聚糖统一生化模块；
    • 祖先谱系的有性繁殖母型；
    • 区域地质和 P0—P4 时间尺度；
    • 地下掘食动物的后续演化；
    • M5-04J 的重构边界；
    • 病原与免疫专项；
    • 人工选择与驯化专项。

    十六、冻结项

    1. C 来源于具有地下短缩根冠、季节宽叶、不定根和普通储能聚糖的多年生维管植物祖先；
    2. 多芽点、多储根先于密能聚糖出现；
    3. 冠区扇区化来自芽点、根区和维管束的局部对应；
    4. 连接颈来自根基部过渡区和伤口封闭能力加强；
    5. 深裂褶带叶由普通宽叶的折叠、窄基、深裂和纵脉加强逐步形成；
    6. 密能聚糖由普通储能聚糖经历低水化封装和高还原单体比例增加而来；
    7. 精确单体和键型暂不冻结；
    8. 快速糖库与密能库的分工晚于密能颗粒的初步形成；
    9. 每个中间阶段均可独立生存和进行有性繁殖；
    10. 单一巨根、地下超级网络、纯脂质和常绿大叶均因明确代价未成为主路线；
    11. 有性繁殖从祖先延续至现行物种；
    12. 埃纳驯化属于现行野生型之后的人工选择层，不属于自然物种起源。

    十七、未决项

    1. 密能聚糖具体单体与键型；
    2. 祖先叶形和繁殖器官；
    3. 各阶段发生的地质时间尺度；
    4. 最早专化掘食者出现时间；
    5. C 的近缘种和生态型；
    6. 冠区分化是否形成可见发育序列；
    7. 密能聚糖是否在其他植物中有低含量同源物；
    8. 驯化历史与地方品系分化。

    十八、回退条件

    以下情况出现时必须回退：

    • 完整现行结构由一次突变产生；
    • 密能聚糖没有普通糖代谢前体；
    • 中间阶段不能独立存活或繁殖；
    • 所有性状由单一万能基因控制；
    • 储根改成块茎、果实、动物器官或无边界网络；
    • 深裂叶没有普通叶板同源来源；
    • 完全失去有性繁殖但遗传多样性不下降；
    • 密能聚糖只有优势、没有合成和生态代价；
    • 把埃纳栽培型高产性状写成野生祖先特征。

    十九、最终裁决

    演化可达性闸门：条件通过（用户确认）

    通过条件

    1. 共生星生化模块后续确认密能聚糖的可行化学范围；
    2. 繁殖与发育闸门必须符合地下芽—折叠叶—成熟储根的同源发育顺序；
    3. 种群闸门证明有性补充足以维持遗传多样性；
    4. 人工选择专项不得反向修改野生型自然演化路径。

    外部依赖

    • M6-R01 区域水文、光照、土层与 P0—P4 参数；
    • 鲁拉纳与根塔的现行冻结设定；
    • 后续繁殖、病原、生物地理与视觉闸门的回填结果；
    • 密能聚糖精确化学结构由共生星统一生化模块另行冻结。
