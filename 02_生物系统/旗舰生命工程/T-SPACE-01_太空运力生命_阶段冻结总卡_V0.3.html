    T-SPACE-01 太空运力生命｜阶段冻结总卡 V0.3

    0. 文件地位与版本覆盖

    • 开发线：旗舰生命 / 早期航天体系。
    • 所属时代：共生星晚期—前母花早期轨道时代。
    • 起源：埃纳主动创造的完整主体生命；不是自然物种，不存在需要补写的自然祖先。
    • 技术边界：成熟通用航天已经存在；第一座母花尚未出现；完整主体造生须跨过 K5→K6 专项门槛。
    • 当前阶段：起源、主体、任务、推进、承力、迁育腔、轨道家庭、生命周期与持续升级框架已经形成；T13—T16 物理、生理和资源账本未完成；视觉未启动。
    • 本轮用户纠偏：家庭、妊育、出生、成长、社会、恢复和晚年以轨道为主；地面不是长期栖息地，而是短时任务港；后续技术变化通过持续遗传—发育改造吸收，不按固定型号淘汰处理。
    • 覆盖关系：V0.3 覆盖 V0.2 中“地面家庭、地面妊育、地面长期栖息、三域并列生活”和“技术过时后安置”的冲突表述；V0.2 其余非冲突内容完整继承。V0.1、V0.2 仅用于历史追溯。

    状态词：

    • 硬约束：用户已明确确认，后续不得擅自改写；
    • 阶段冻结：当前模块正式基线，但可被后续物理矛盾触发复审；
    • 候选：方向成立，具体机制或参数尚未冻结；
    • 待算：必须进入 T13—T16 定量账本。

    1. 文明定位

    埃纳没有把早期轨道文明完全建立在“持续发射成品钢铁设施”的工业路径上。机械航天先建立轨道平台、能源、通信、救援和育生基础；随后，埃纳把可继续发育的生命胚体、微生态、生长基质和接口送入轨道，使轨道设施能够在当地生长、修复和形成生态网络。

    T-SPACE-01 承担的不是普通货运，而是迁育 / 轨道播种：

    把一套能够在新环境中重新建立生命循环的最小完整系统，安全送入轨道，并确认其开始自主生长。

    机械系统继续承担：

    • 惰性大宗材料；
    • 高风险试验；
    • 紧急救援；
    • 时间高度敏感的任务；
    • 不值得主体承担的危险运输；
    • T-SPACE-01 不适用的轨道和目的地。

    T-SPACE-01 的成立不要求它在所有指标上击败机械火箭。它的独特价值在于：运输者的身体、迁育腔、感觉、判断、任务经验和对迁育对象的照护形成一个连续生命闭环。

    2. 起源、行为—奖励架构与主体边界

    2.1 文明造物起源

    T-SPACE-01 没有自然祖先。“迁徙、携育、播种、归巢、群体伴飞和亲代引航”属于埃纳创造该谱系时采用的机制参考和行为—奖励架构，不是自然演化遗留，也不是血缘来源。

    2.2 开放奖励架构

    阶段冻结的奖励维度包括：

    • 轨道运动、轨迹掌握和身体控制；
    • 携育、保护、照护和救援；
    • 对家庭轨道、熟悉节点和同类关系的归巢依恋；
    • 配偶、亲子、同类与跨物种伙伴关系；
    • 探索、学习、路线经验和空间天气观察；
    • 群体协同、教学、公共贡献与事故复盘；
    • 身体舒适、休息、恢复、成长和自我保护；
    • 选择、拒绝、暂停、转向和重新加入；
    • 对自身身体升级与谱系发展的参与。

    轨道迁育只能是多维生活中的一种社会角色，不能成为唯一奖励入口、出生义务、永久任务绑定或社会价值来源。

    2.3 主体与文明分层

    • 个体按其体验、利益、自我连续性、关系、拒绝和未来偏好，属于完整主体生命；
    • 个体智慧、个体主体性、种群文化和独立文明自组织必须分别判断；
    • 早期种群可先嵌入埃纳—轨道生态共同体，但不得通过设计压制抽象、组织、自治、迁移或文明形成能力；
    • 若种群后续形成独立文明需求，必须被承认，不得作为设计故障修复；
    • 设计目的不产生所有权，也不构成终身运输义务。

    3. 空间生态结构：轨道是家，地面是港

    3.1 轨道主生活域｜硬约束

    轨道承担：

    • 家庭、配偶和亲子生活；
    • 求偶、受精、妊育、出生和育幼；
    • 日常营养、休息和自由运动；
    • 教育、文化、公共记忆和政治表达；
    • 任务后恢复、长期医疗和慢速组织重构；
    • 残障生活、晚年和临终照护；
    • 同类群体与其他轨道生命的长期共居。

    其常态环境为轨道低重力—微重力环境；妊育、发育和负荷训练可使用可调离心、轴向加载或局部人工重力设施，但不把地表重力设为日常身体基准。

    3.2 大气过渡域｜阶段冻结

    大气层承担：

    • 空载或低载下降；
    • 再入热防护和气动减速；
    • 姿态控制；
    • 高空化学—电热续推；
    • 中止、救援和应急返回。

    大气层是高能、高风险任务环境，不是家庭生活区，也不把高空飞行写成低成本日常散步。

    3.3 地面任务终端｜硬约束

    地面承担：

    • 再入承接和全身检查；
    • 热盾、轴芯、循环和推进器官大修；
    • 体细胞遗传编辑、组织再生和大型器官重构；
    • 高密度任务反应物、工作介质和冷却资源装载；
    • 迁育载荷装载；
    • 与电磁脊道对接、发射前生理预紧和再发射；
    • 少量必须在地表完成的紧急医疗。

    百米级成年个体不要求、也不应被设计为能够在地表自由行走。地表姿态与位移由以下设施共同完成：

    • 深水或高密度柔性介质浮托；
    • 分布式腹侧承托膜；
    • 与中央承力轴耦合的磁性支撑；
    • 可移动生物船坞、轨道车或水道；
    • 与发射脊道直接连接的装载槽；
    • 低压迫、可分区卸载的医疗和改造环境。

    个体只需进行局部姿态调整、循环协调和主动配合，不承担“自己走到发射场”的要求。地面停留应尽可能短，最长时长进入 T13—T16 校核。

    3.4 归巢含义｜硬约束

    地面停留不是回家。回到家庭轨道、熟悉节点和同类关系才是归巢。

    4. 技术总架构

    采用“轨道常住 + 空载下降 + 地面长距离电磁加速 + 活体自主续推 + 轨道返回”的混合体系。

    4.1 地面电磁脊道

    • 建设于适宜纬度、高海拔和顺自转方向的长距离发射廊道；
    • 采用多级线圈加速，不采用短轨道炮式瞬时冲击；
    • 提供主要初始动能，但不直接把生命打入稳定轨道；
    • 发射系统与个体电生理节律、承力轴预紧和迁育腔状态主动同步；
    • 具备分段降场、柔性制动和多个可安全中止窗口。

    4.2 磁耦合脊环

    • 沿中央承力轴分布；
    • 主动调整磁响应，使线圈推力分布到全身；
    • 与迁育腔之间设置承力、电生理和热隔离层；
    • 生命体是发射系统的主动协同成员，不是被动弹丸。

    4.3 三级推进

    1. 电磁脊道：提供初始速度；
    2. 高空化学—电热喷流：快速穿越大气并补足主要速度增量；
    3. 轨道磁浆推进：完成轨道圆化、交会、姿态控制、轨道内转移和返回家庭轨道。

    禁止无反作用质量的信息场推进。轨道磁浆推进必须有真实反作用质量、功率密度和散热账本。

    5. 标准任务循环

    5.1 现行循环｜硬约束

    轨道家庭与日常生活
→ 个体获得任务信息并自愿接受
→ 空载或低载离开家庭轨道
→ 降轨、再入、气动减速和低空控制
→ 地面全分布式承接
→ 检查、修复、可选升级、反应物与迁育载荷装载
→ 发射前生理预紧
→ 电磁脊道加速
→ 高空化学—电热续推
→ 轨道磁浆推进完成圆化与交会
→ 释放迁育单元并确认生命循环建立
→ 返回家庭轨道
→ 长期恢复、家庭重聚与任务复盘

    5.2 任务优先级

    • 第一代和早期成熟期优先重型迁育，不以载人旅游为主要用途；
    • 空载或低载下降优先于携带高价值载荷再入；
    • 迁育对象异常、个体疼痛、循环不稳、恐惧复发或家庭紧急情况均可触发中止；
    • 一次任务完成后不立即再次下降，必须回到轨道完成恢复。

    6. 标准载荷与迁育腔

    6.1 载荷类型

    • 轨道实验生命胚体；
    • 接驳节点幼体；
    • 光能采集膜胚体；
    • 微重力培养生命；
    • 配套微生态；
    • 生长基质、水、矿物和结构前体；
    • 修复组织与发育信号；
    • 轨道着床接口；
    • 少量精密非生命核心。

    6.2 完整迁育单元

    主胚体 + 配套微生态 + 初期营养 + 发育信号 + 修复组织 + 轨道着床接口。

    6.3 多囊式迁育腔

    • 中央主育囊位于质心附近；
    • 环形伴生囊储存微生态、基质和辅助胚体；
    • 高黏弹性缓冲液与可变压囊隔离冲击；
    • 导电等势包络与主动反相信号降低电磁脉冲影响；
    • 异常囊室可独立关闭；
    • 迁育腔与任务反应物、喷流高温区和主要承力峰值隔离；
    • 个体能够感知各囊室状态，并拥有以迁育腔安全为优先的中止权。

    6.4 初步运力｜量级测试，未冻结

    • 轻型：5—15 吨；
    • 标准型：20—50 吨；
    • 重型：80—150 吨，限后期或专用亚型。

    20—50 吨仍作为当前标准型测试范围，等待共生星重力、大气、自转、空载下降质量和载货上升质量分数共同校核。

    7. 总体体型与承力结构

    7.1 轴芯—环腹型｜阶段冻结

    • 中央活体承力轴贯穿头尾；
    • 迁育腔环绕质心附近轴芯布置；
    • 尾部形成多喷口推进簇；
    • 钝圆头部与前腹侧承担主要再入载荷；
    • 无传统大型固定翼，仅有可收拢姿态膜、归巢膜和轨道散热膜；
    • 环腹结构提供迁育、缓冲、循环和地面分布式承托界面。

    7.2 承力路径

    • 电磁发射：线圈 → 磁耦合脊环 → 中央轴芯 → 分节支撑环 → 全身；
    • 高空续推：尾部喷流簇 → 推力汇合区 → 中央轴芯 → 全身；
    • 再入：头部 / 前腹气动载荷 → 放射状骨束 → 中央轴芯；
    • 地面短驻：外部承托系统 → 腹侧承托界面 / 磁性轴芯接口 → 全身分散卸载。

    7.3 抗过载

    • 发射前进入迁育收束态；
    • 纵向肌束预紧、体液回流和内脏固定；
    • 胚体在黏弹性液体中悬浮；
    • 分节轴芯允许可控微屈服；
    • 黏弹软骨、液压阻尼和主动反相收缩抑制振动；
    • 幼体通过离心、轴向加载和人工重力逐级建立短时负荷能力。

    7.4 初步尺度｜候选

    • 总长：约 80—120 米；
    • 最大体宽：总长 18%—24%；
    • 迁育腹体：总长 35%—45%；
    • 尾部推进区：总长 20%—25%。

    这些是物理与视觉的初始测试边界，最终必须接受质量、热、结构、发育和轨道生活校核。

    8. 返回、热防护与地面短驻

    8.1 再入与减速

    • 钝体升力再入；
    • 外层可牺牲角质层主动碳化、蒸发和脱落；
    • 蒸发冷却层 + 碳化隔热层 + 再生基底层；
    • 低速阶段展开多片主动姿态 / 归巢膜；
    • 低空短时喷流、腹侧缓冲囊与外部柔性承接共同减速；
    • 优先进入专用水域、浮托槽或柔性生物承接区。

    8.2 地面停留

    每次任务后至少检查：

    • 热盾烧蚀和再生基底；
    • 中央轴芯及磁耦合脊环；
    • 迁育腔与电生理隔离；
    • 推进器官和反应物通道；
    • 循环、神经和微生态；
    • 地表承托造成的压迫伤。

    地面完成快速大修和高质量资源装载；轨道完成慢速组织恢复、神经恢复和家庭支持。不得因港口排班延长地表停留。

    9. 智慧、认知与协作接口

    9.1 能力

    • 理解多阶段复杂任务；
    • 长期记忆路线、天气、节点和异常案例；
    • 进行经验性创新和风险判断；
    • 学习和使用符号语言；
    • 形成连续自我、家庭、依恋和长期伙伴关系；
    • 表达疼痛、兴趣、拒绝、创伤和未来偏好；
    • 参与栖息地、任务规则、事故审查和后代设计治理；
    • 在导航、磁场判断、巨大身体状态整合和路线记忆上形成专长。

    9.2 与埃纳和同类的接口基础

    T-SPACE-01 并非自然高级共生类的直接后裔，但其协作层与共生类上位规则兼容：

    • 电生理是近距状态信号主干；
    • 具有可与埃纳及同类相互识别的共生激素场兼容层；
    • 生命接口遵守双方许可、可拒绝和低带宽原则；
    • 接口服务于育幼、医疗、状态校验和高信任协作；
    • 不读心，不传输完整知识，不取消个体边界。

    10. 家庭、繁殖与育幼

    10.1 轨道家庭｜硬约束

    • 家庭中心位于轨道，不围绕地面发射港建立；
    • 配偶通过长期伴飞、共生场相容、电生理节律和共同生活形成关系；
    • 一名亲代下降时，另一名原则上留在轨道家庭；
    • 年长个体可以协助育幼，但不能取代亲代核心责任；
    • 任务机构不得按运力、遗传指标或排班强制配对。

    10.2 轨道受精、妊育和出生｜阶段冻结方向

    • 内部受精继续作为候选；
    • 求偶与受精在轨道低重力环境中完成；
    • 妊育个体留在轨道，不执行再入和高过载发射；
    • 普通后代在轨道妊育、出生和成长；
    • 单胎或极少胎、长妊育周期和长繁殖间隔继续作为候选；
    • 新生幼体远小于成体；
    • 轨道育生设施提供压力、营养、免疫、微生态和紧急医疗支持，但不替代家庭。

    10.3 双亲共生抚育

    • 共生激素场传递安全、疼痛、饥饿、警觉和亲近状态；
    • 电生理同步帮助校准睡眠、循环、方向感和应激恢复；
    • 生命接口可移交营养、微生态、免疫因子和低层行为节律；
    • 亲代可以传递状态模板和注意模式，但不能直接下载完整航线、理论或人格；
    • 幼体必须通过伴飞、模仿、游戏和实际经验成长。

    10.4 生殖自主与升级治理

    • 生育不是种群运力扩张义务；
    • 个体可拒绝配偶、受精、妊育和特定后代改版；
    • 创始群体和后代设计必须保持多谱系起点，避免单一模板锁定；
    • 涉及后代的遗传—发育调整须同时接受主体风险、遗传多样性、长期生态和同类治理审查。

    11. 生命周期与训练

    以下顺序冻结逻辑，不冻结年数：

    1. 早期胚体由常规机械航天送入轨道；
    2. 轨道胚育和主体形成；
    3. 轨道依附幼体期；
    4. 轨道自由运动、同伴游戏和身体图式形成；
    5. 低功率轨道移动和导航学习；
    6. 离心、轴向承力和惯性训练；
    7. 大气过渡模拟与学徒期；
    8. 首次自愿空载下降—全承托短驻—无关键载荷再发射；
    9. 初次低风险迁育；
    10. 成熟轨道生活：家庭、迁育、探索、研究、救援、教学或非任务生活；
    11. 引航、公共经验或完全退出任务；
    12. 轨道晚年、临终和死亡。

    11.1 幼体不是缩小版成体

    器官成熟建议顺序：

    基础循环与感觉
→ 家庭接口与轨道姿态控制
→ 低功率轨道移动
→ 轴向承力与离心负荷适应
→ 热防护和大气感知
→ 高温喷流与任务反应物储存
→ 磁浆推进与成熟迁育腔

    任务级喷流、危险反应物、大面积热盾和高功率推进延迟成熟，避免幼体天然携带完整高风险系统。

    11.2 成年与任务资格分离

    首次地表往返不是普遍成年礼。个体可以成年、形成家庭、参与轨道社会并终身不下降地面。任务资格是后续自愿技能资格，不是主体成年条件。

    11.3 晚年

    年长个体可以自愿承担幼体照护、路径记忆传递、伴飞、事故审查或低负荷轨道角色，也可以完全退出公共角色。不得以“发挥剩余价值”定义晚年。

    12. 持续生物升级｜硬约束方向

    T-SPACE-01 不是一次定型的生物硬件，而是能够跨技术世代持续改造的生命平台。

    项目内“基因改造”采用更稳妥的现行术语：遗传—发育改造。它可以包括与地球基因编辑功能等价的遗传控制，但具体分子载体仍属于生命信息论 Reserved，不提前冻结为 DNA、链数或特定机制。

    12.1 现存个体升级

    通过分区体细胞遗传编辑、组织换代、再生和器官重构，可逐步更新：

    • 承力纤维和轴芯材料；
    • 热防护和再生层；
    • 推进器官、工作介质处理和散热；
    • 辐射防护与损伤修复；
    • 感知、导航和生命接口兼容；
    • 代谢、免疫和微生态；
    • 迁育腔与载荷接口。

    大型改造不是瞬时变形，而是持续数月或数年的分区重构，可在轨道家园与地面任务终端分阶段完成。

    12.2 可替换 / 可附加模块

    部分推进、散热、储能、微生态、感知和接口组织可被设计为可再生、可替换或可附加模块，使小幅更新不必改写全身。

    12.3 后续世代升级

    结构性变化进入后续胚体的遗传—发育方案，可形成：

    • 不同身体比例；
    • 不同轨道和辐射环境适应；
    • 更高效推进、热管理和迁育腔；
    • 轨道内运输、救援、探索、育生或其他亚型；
    • 面向神族路线的高性能分支。

    未来世代不是用于“替换旧一代”，而是谱系在共同治理下继续分化。

    12.4 主体连续性

    • 升级不等于人格重置；
    • 神经连续性、记忆、关系和法律身份必须保持；
    • 成年个体参与选择升级内容；
    • 拒绝升级不构成故障，不降低基本资源、社会地位或家庭权利；
    • 新旧亚型的生殖、接口和社会兼容性必须长期管理。

    因此，“技术过时”不作为本模块的核心生存危机。真正需要计算的是升级速度、资源、风险、兼容性和谱系分化。

    13. 能量、物质与恢复

    13.1 两套资源账本

    日常生命代谢：循环、神经、成长、妊育、育幼、低功率轨道移动、组织修复和热管理。

    任务推进系统：高空喷流、轨道圆化、强热管理、反应物和工作介质。

    二者必须结构隔离。不得以削减家庭、妊育、幼体营养或日常生存资源换取任务性能。

    13.2 轨道日常供给

    轨道生长节点、补能生命和机械设施提供营养、水、矿物、气体、微生态、辐射屏蔽和低功率移动资源。

    13.3 地面装载

    地面终端主要装载高密度反应物、工作介质、冷却资源和迁育载荷。装载不是“喂食”，任务资源不得与日常生存奖励混为一体。

    13.4 双域修复

    • 地面：再入后快速大修、热盾重建、器官升级和高质量资源装载；
    • 轨道：慢速组织更新、睡眠、神经恢复、家庭同步和长期医疗。

    13.5 废物与隔离

    轨道家园独立处理代谢废物、蜕落组织、病原和微生态循环；地面终端处理推进污染、烧蚀层和高风险组织。轨道—地表之间建立严格生物隔离。

    14. 社会、文化、角色与运力组织

    14.1 三级社会结构

    1. 轨道家庭单元；
    2. 轨道邻域、育生节点与公共生活共同体；
    3. 迁育群和跨轨道区域网络。

    迁育群是熟悉彼此节律、路线和中止信号的协作网络，不是永久劳动编制或军队。地面港口是基础设施，不是社会中心。

    14.2 文化与公共记忆

    种群可形成：

    • 名字、故事、仪式和哀悼；
    • 伴飞礼仪；
    • 家庭与幼体照护传统；
    • 对不同港口、路线和节点的信任评价；
    • 事故纪念和公共审查；
    • 同类代表、协商和政治立场；
    • 对自身起源与升级方向的历史叙事。

    文化不自动等于独立文明，但也不得因尚未形成独立文明而被压制。

    14.3 多元成年角色

    • 地表—轨道迁育；
    • 轨道内运输与接驳；
    • 救援、伴飞和路线引航；
    • 幼体照护与教学；
    • 轨道生态维护和研究；
    • 空间天气观察；
    • 艺术、历史、治理或完全非任务生活。

    14.4 任务排班

    综合：

    • 轨道窗口；
    • 身体与升级状态；
    • 家庭和妊育周期；
    • 路线熟悉度；
    • 同类协同；
    • 恐惧和创伤史；
    • 个体真实同意。

    14.5 初步周转｜量级测试

    • 主力个体每年约 2—6 次重型地表往返任务；
    • 运力依靠种群规模、多脊道并行和轨道胚体生长倍率，而非单体无限周转；
    • 旧示例“300 只成年、55% 主力、平均 4 次 / 年、35 吨 / 次 ≈ 2.31 万吨 / 年”仅保留量级测试意义，必须按空载下降—载货上升—回家恢复的新循环重算。

    15. 奖励、任务同意与创造者责任

    15.1 三项最低测试

    1. 永不下降测试：终身不去地面的健康个体是否仍能完整生活；
    2. 任务减少测试：迁育需求下降 50%、90% 或长期转型时，轨道家庭、社会和资源是否仍稳定；
    3. 升级拒绝测试：拒绝某次身体改造的个体是否仍拥有基本资源、地位、关系和未来。

    15.2 持续同意与最终中止权

    个体可在以下节点撤回：

    • 接受任务前；
    • 离开家庭轨道前；
    • 再入前；
    • 抵达地面终端后；
    • 遗传或器官改造前；
    • 反应物和载荷装载前后；
    • 进入脊道前；
    • 脊道安全制动窗口；
    • 高空续推和轨道注入前。

    个体对自身疼痛、循环、恐惧、迁育腔异常和整体状态拥有最终证据优势。地面系统、任务机构和埃纳不能以计划、成本或权威覆盖安全中止。

    15.3 埃纳的长期责任

    • 提供轨道栖息、营养、医疗、家庭和非任务生活；
    • 保障多港口、机械替代和资源冗余，避免单点胁迫；
    • 对第一代设计失败、创伤和无法承担任务的个体负责；
    • 允许种群参与升级、后代设计和公共制度；
    • 原任务消失后继续承担不可撤销的生活保障；
    • 不因创造者身份拥有所有权或人格解释权。

    16. 主流路线与神族路线

    16.1 主流埃纳

    保留开放奖励、家庭、恢复、育幼、感知、安全、拒绝、非任务生活和共同治理。通过持续升级提高性能，但不把效率设为唯一价值。

    16.2 神族埃纳｜候选比较

    神族可能：

    • 压缩恢复期；
    • 降低家庭投入；
    • 强化任务奖励；
    • 提高器官模块化与改造频率；
    • 建立更高性能、更高度专用的亚型。

    这类差距来自文明选择而不只是技术代差。神族性能不能成为主流剥夺主体开放未来的理由；主流体系也不能被写成低效到无法完成轨道工业化。

    17. 安全与失效模式

    17.1 工程失效

    • 发射脊道失配：分段降场和柔性制动；
    • 高空续推不足：优先中止，不强行入轨；
    • 迁育腔异常：分囊隔离并优先保护迁育单元；
    • 轨道导航错误：轨道规划 + 个体路径记忆 + 接驳节点三层协同；
    • 热防护不足：调整迎角、牺牲外周组织、转入备用承接区；
    • 地表承托失配：立即分区卸载、转入浮托和循环救援；
    • 反应物泄漏：与日常代谢隔离、主动抛弃或封闭；
    • 遗传编辑脱靶 / 器官升级不兼容：分区停用、回退和长期医疗；
    • 轨道育生、营养、辐射或病原系统失效：多节点疏散和机械救援。

    17.2 心理、家庭与制度失效

    • 对下降、地面承托、脊道或特定港口产生恐惧；
    • 任务事故后的幸存者负担；
    • 配偶关系中断、幼体死亡和家庭长期分离；
    • 对自身被设计目的、升级方向或创造者产生愤怒；
    • 升级资源被机构垄断；
    • 只有任务成功者获得社会价值。

    这些不是简单性能故障。处置目标首先是减轻痛苦、恢复选择和关系，而不是尽快恢复运力。

    17.3 事故史原型｜保留

    早期一次任务中，地面系统判断仍可继续入轨，但个体主动中止并保护迁育腔。该事件推动“身体状态最终证据优势、迁育腔优先和个体最终中止权”制度形成。具体人物、地点、损失和年代未冻结。

    18. 衰老、死亡与原用途变化

    • “退役”只描述停止某类任务，不描述生命价值；
    • 年长个体可继续家庭、轨道旅行、教学、艺术、治理或完全私人生活；
    • 不以高维护成本缩短其生命；
    • 临终原则上在轨道家园完成，也可由本人选择其他熟悉地点；
    • 遗体处理依本人意愿和家庭文化，不自动作为高价值材料回收；
    • 若机械或新谱系减少原迁育需求，T-SPACE-01 可转向轨道内运输、救援、探索、育生、生态维护或纯生活，不存在“无用即淘汰”。

    19. 种群、承载力与持续演化

    种群成立需要：

    • 足够遗传多样性和多个创始谱系；
    • 多个轨道育生、营养、医疗和辐射防护节点；
    • 家庭和幼体长期存活；
    • 多个地面终端与机械替代，避免单点控制；
    • 同类参与遗传升级、栖息地和任务治理；
    • 可持续公共记忆与文化。

    承载力由以下共同限制：

    • 轨道安全空间和碰撞管理；
    • 育生巢容量；
    • 营养、能量、水、矿物和散热；
    • 辐射防护和医疗；
    • 家庭照护；
    • 地面港口和电磁脊道吞吐；
    • 任务反应物；
    • 升级设施；
    • 轨道生态总体承载力。

    创造后同时存在自然重组、突变、发育差异、文化差异和主动遗传—发育改造。稳定不等于冻结，升级也不等于统一。

    20. 与当前地球航天的暂定比较

    • 单次标准迁育质量暂按与地球现役重型火箭同一量级测试；
    • 单体周转低于高度工业化可复用火箭的理想目标；
    • 成熟种群、多脊道和轨道生长倍率可形成更高区域年迁育量；
    • 真正优势是载荷可在轨继续生长，地面上行质量不等于最终轨道设施质量；
    • 主要劣势是固定脊道依赖、空载下降和再入成本、恢复期长、个体差异大、紧急响应与任意轨道灵活性低；
    • 最终定位不是一只超过一切机械火箭的“生物火箭”，而是行星级生命播种体系中的主体型迁育节点。
