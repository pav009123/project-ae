    AE 科技成熟度矩阵 K0—K8 V1.0

    状态：现行科技发展阶段映射规则（S4）。

    适用范围：埃纳文明全部基础科学、通用工程、生命工程、文明器官、轨道生命、星际技术及文明治理。本文与《AE 文明科技树总纲 V1.0》《AE 文明技术图谱 V1.0》配套使用。

    一、矩阵用途

    本矩阵解决三个问题：

    1. 某项技术最早在哪个阶段出现；
    2. 它在哪个阶段从知识、实验和原型转化为稳定工程；
    3. 它何时可以成为文明基础设施，而不再只是研究项目。

    任何新增技术必须同时标注：

    • 横向门类；
    • 首次理论出现阶段；
    • 首次实验验证阶段；
    • 首次工程原型阶段；
    • 首次规模化应用阶段；
    • 首次文明级集成阶段；
    • 主要失败方式和治理门槛。

    二、成熟度符号

    符号 含义
    — 尚未形成独立知识或工程能力
    O 观察与经验积累
    T 可表达、可计算的理论形成
    X 可重复实验验证
    P 受控工程原型
    E 稳定工程化应用
    I 基础设施化、制度化或跨系统集成
    C 文明级、行星级或星际级能力

    同一门类可在一个阶段同时存在多个层级。例如，K5 的发育工程可同时具有成熟的组织再生 E、受限生命设计 P 和文明器官研究 X。

    四、K0—K8 阶段剖面

    K0 生态观察时代

    核心能力：记录、比较、辨认周期和建立经验因果。

    主要成果：

    • 生态节律、天气、脉潮、生命状态和材料行为的长期观察；
    • 早期工具、火、栖居、食物保存和共居经验；
    • 对共生激素场、生物电和生命接口的经验性感知，但没有理论机制；
    • 初步医疗、培育和生态管理；
    • 权利与禁忌主要依赖习俗，而非正式法律。

    禁止倒置：K0 不得出现稳定基因设计、神经解码、轨道工程或文明器官。

    K1 计量与局地测量时代

    核心能力：统一单位、重复测量、建立局地模型。

    主要成果：

    • 数学、几何、统计和误差观念形成；
    • 局地电、磁、热、光、力和生命状态测量；
    • 材料分类、化学反应和药理经验系统化；
    • 早期生理、电生理和生态网络模型；
    • 形成工程责任、实验许可和危险物质管理雏形。

    K2 生态传感与低扰动材料时代

    核心能力：由仪器和材料构成可维护工程原型。

    主要成果：

    • 低扰动生态传感器、离子导体、活体材料和复合结构；
    • 反馈控制、标准接口、旁路和撤除机制；
    • 早期计算、通信和仿真；
    • 工业化制造、质量控制和基础设施扩展；
    • 航空、火箭、轨道观测和非生命航天原型可在本阶段后期出现；
    • 生命工程以再生、组织培养和定向驯化为主，不能直接创造完整文明生命。

    K3 生物电与神经理解时代

    核心能力：理解生命内部快速控制网络。

    主要成果：

    • 神经信号、生物电场、感受器和免疫机制得到实验验证；
    • 神经接口、组织状态诊断、精确再生和器官培育工程化；
    • 分布式控制、人工智能和复杂系统仿真成熟；
    • 共生激素场被确立为电生理—化学—机械耦合系统；
    • 稳定航空航天和轨道基础设施形成；
    • 发育工程仍以局部组织和受限功能体为主。

    K4 公共协作与共思协议时代

    核心能力：把高带宽生命信息交换纳入公共制度。

    主要成果：

    • 共思协议、身份认证、许可、退出、审计和隐私制度；
    • 生物计算与非生命计算形成混合架构；
    • 复杂自动化、量子信息、聚变研究和轨道工业发展；
    • 大型封闭生态和长期航天验证；
    • 受限生命设计开始工程化，但完整主体的创造仍受严格限制；
    • 生命伦理由习俗进入成文法律和工程认证。

    K5 发育工程与文明生命时代

    核心能力：稳定、可重复、可回退地设计复杂生命系统。

    主要成果：

    • 多器官功能体、模块化生命、人工生命周期和受限主体研究；
    • 生命制造工业、培育基地和大型活体材料工程；
    • 聚变、核电推进、太空栖居、轨道制造和长期闭环生态；
    • 第一代文明生命原型、母花前体和轨道活体舱段；
    • 反物质仅限微量科学和催化研究；
    • 任何文明生命必须有独立关闭、维护、拒绝和退役机制。

    K6 文明器官与生态工程时代

    核心能力：把多个生命、材料和控制系统整合为长期文明基础设施。

    主要成果：

    • 母花、母林、母港等文明器官进入稳定应用；
    • 活体城市、轨道生命空间站、区域生态调节和文明生命网络；
    • 太空电梯、轨道环、质量驱动器和戴森群前期节点；
    • 受限繁殖探测器和远航文明生命原型；
    • 行星防御、文明器官安全和共思网络防御成为独立学科；
    • 文明器官不等于工具，必须建立主体性与权利分类。

    K7 星际生态工程时代

    核心能力：在光速限制下维持跨行星、跨恒星的生命与文明连续性。

    主要成果：

    • 聚变远航、激光帆、磁帆、世代生命和低代谢远航；
    • 完整轨道生命城市群、戴森群、恒星系资源网络；
    • 跨恒星生态库、文化传承和延迟治理；
    • 局部行星改造、生态恢复和原生生命隔离；
    • 反物质催化推进可少量应用，宏量反物质仍是战略级设施；
    • 曲率、虫洞、人工场重力和微型黑洞只进入高风险研究，不自动成为交通基础设施。

    K8 银河级生态协作时代

    核心能力：处理跨文明、跨星系和百万年尺度的责任。

    主要成果：

    • 银河通信中继、跨文明生态协议和长期文明器官网络；
    • 黑洞取能、恒星举升、恒星寿命管理等超级工程；
    • 固定虫洞、亚光速曲率构型等仅在完成新物理验证后进入有限工程；
    • 超光速曲率泡仍可保持为极限候选，而非默认能力；
    • 银河工程必须接受原生生态权、因果安全和可撤回原则；
    • 技术强度不等于治理正当性。

    五、关键技术的阶段链

    5.1 活体空间站

    K2：非生命航天器、轨道传感和活体材料样件
→ K3：长期轨道平台、再生组织和闭环生态原型
→ K4：大型旋转栖居、自动维护和轨道培育实验
→ K5：可替换活体舱段、轨道培育基地和受限神经控制
→ K6：完整空间站生命与多主体轨道共同体
→ K7：轨道生命城市群和远航生命

    5.2 母花与造生母花

    K2：组织培养和生长环境控制
→ K3：器官诱导和发育状态测量
→ K4：复杂发育模型、许可和安全协议
→ K5：大型培育平台与受限功能生命制造
→ K6：文明器官级母花
→ K7：轨道、行星外和远航母花体系

    5.3 共思

    K0：接触中的自然状态感应
→ K1：现象测量和行为记录
→ K2：生命接口的低带宽传感
→ K3：神经同步与电生理机制
→ K4：可许可、可退出、可审计的公共共思协议
→ K5—K8：受限多主体协作和跨文明模型交换

    5.4 反物质

    K5：微量制造、测量和基础粒子研究
→ K6：极少量储存与反应控制
→ K7：反物质催化推进、战略级实验设施
→ K8：宏量系统仍只限极端任务；不成为日常能源

    5.5 曲率与虫洞

    K6：相对论、高能物理和量子场论达到文明级实验能力
→ K7：极端引力、真空态和负能量约束研究
→ K8：先验证新物理，再决定亚光速曲率壳层或固定虫洞是否进入有限工程

    不得把数学解直接跳写为工程成品。

    六、阶段跃迁的最低准入条件

    K4 → K5

    必须同时具备：

    • 可验证的发育模型；
    • 组织级和器官级可回退控制；
    • 生物安全与癌变监测；
    • 主体性判定程序；
    • 工程责任和退役制度。

    K5 → K6

    必须同时具备：

    • 十年以上大型生命运行数据；
    • 多重控制、独立关闭和人工旁路；
    • 大型生命维护与局部截除能力；
    • 文明器官权利与拒绝机制；
    • 城市级能源、散热、物质循环和生态冗余。

    K6 → K7

    必须同时具备：

    • 长期封闭生态；
    • 跨代遗传和文化连续性；
    • 光速延迟下的自治治理；
    • 行星外生命培育能力；
    • 星际航行的推进、辐射、散热和维修闭环。

    K7 → K8

    必须同时具备：

    • 可实验证伪的新基础物理；
    • 跨文明准入和因果审计；
    • 百万年尺度维护模型；
    • 原生生命和生态权利框架；
    • 超级工程失效不会导致不可逆银河级灾难的隔离设计。

    七、使用规则

    1. 任何技术卡不得只写“属于 K7”而不列出 K2—K6 的依赖链。
    2. 某项基础科学达到 C，不代表所有应用自动达到 C。
    3. 生物系统的自修复、适应和繁殖属于能力，也属于新增失效模式。
    4. 文明级技术必须有物理、材料、生命、控制、生态、可靠性、主体性和文明成本八项账本。
    5. 技术跨阶段提前出现时，只能作为事故、孤立原型、外来遗物或未能复制的异常，不得反向改变整体现有科技水平。
    6. 后续文明史编写应以本矩阵为约束，将标志性实验、事故、计划和制度变迁映射到具体阶段。
