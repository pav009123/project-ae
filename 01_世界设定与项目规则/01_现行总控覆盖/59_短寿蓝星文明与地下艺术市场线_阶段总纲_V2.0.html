    59｜短寿蓝星文明、洛维附属与原栖撤离线｜阶段总纲 V2.0

    状态：用户批准 / 现行总控覆盖
    版本归属：Project AE V1.4.9
    层级：Level 3 故事线冻结；不改变 Level 2 总路线。
    覆盖：V1.4.8 59_短寿蓝星文明与地下艺术市场线_阶段总纲_V1.0.md 中与本文件冲突的早期母型。

    核心命题：一个诞生于短寿高质量蓝白恒星下的原生 P–N–S 非水生命文明，在母恒星自然寿命结束前向宇宙求救。地下艺术商人型成熟埃纳洛维最先听见，却为维持“未接触文明”独占资产长期封锁求援，同时秘密延长苍阳寿命。数千年后，整颗母世界的秘密无伤迁移被洛维主动放弃；他最终选择回应求救、主动邀请迭生文明成为自己的附属，并完成整个文明主体的迁移。苍阳最终核心坍缩，原栖星毁灭，但迭生文明延续。

    1. 正式工作名

    • 智慧物种：迭生者
    • 文明：迭生文明
    • 母行星：原栖星
    • 母恒星：苍阳
    • 第一发现者 / 地下埃纳：洛维 / Lovi

    以上为中文开发标准名；迭生者自身原生语言名称尚未开发。

    2. 苍阳与原栖星物理基线

    苍阳

    • 约 9–10 M☉ 高质量 B 型蓝白主序星；
    • 主序寿命为数千万年尺度；
    • 后期演化为巨星 / 超巨星方向，最终核心坍缩；
    • 不得把其整个生命史笼统称为“蓝巨星”；
    • 洛维发现时，自然剩余可用时间约 1000–2000 年；
    • 若无洛维干预，苍阳在当前第一次正式接触时间点之前数千年就已经完成终末爆发；
    • 洛维将发现后的实际稳定窗口延长到约 4000–5000 年。

    原栖星

    • 高密度岩质超级地球：约 3.5–4.0 M⊕；
    • 半径约 1.45–1.50 R⊕；
    • 表面重力约 1.65–1.8 g；
    • 逃逸速度约 17–18.5 km/s；
    • 厚大气约 4–8 bar，N₂ 为主，强硫化学、SO₂ / 硫氧化物、硫酸气溶胶等活跃；
    • 平均表面温度约 35–45℃，主要复杂生态可分布在约 25–55℃；
    • 开放液体不是水海洋，而以浓硫酸—硫酸氢盐—金属盐体系为主；
    • 酸液覆盖率 30–50% 为现行测试区间，不冻结精确值；
    • 轨道约 50–70 AU；一年超过 100 个地球年；
    • 自转候选 18–30 小时；
    • 长期存在相对强磁层，其来源必须归因于金属核、热流、对流与旋转，不得简单写成“质量大所以磁场强”。

    系统位置

    • 苍阳系统在早期从恒星诞生星团 / 聚集区被动力学抛射，位于相对孤立、稀疏、远离常用文明路线的区域；
    • 迭生文明的求救信号物理上能传播出去，但在有限时间内很可能没有合适接收者；
    • 洛维因私人地下路线接近该区域，并拥有成熟埃纳探测能力，成为第一个有效高级接收主体。

    3. 迭生生命底层：P–N–S 非水生命

    现行冻结为高约束硬科幻外推： - 主溶剂：浓硫酸 / 硫酸盐流体； - 主结构 / 遗传骨架：磷—氮杂聚物； - 硫与金属配位承担氧化还原、电子传递、催化和部分结构功能； - 碳可以存在但不是主长链骨架； - 不走“纯硅生命”； - 最小生命单位为开发意义上的酸性微反应腔体，边界由耐酸动态选择界面 + 矿物 / P–N–S 支撑网构成； - 遗传复制依赖 P–N 模板、金属配位和几何互补； - 能量不使用 ATP / 蛋白质体系，而采用硫氧化还原、金属价态与电化学势； - 强 UV 主要损伤 P–N 信息链，因此演化出高修复、多模板校验和共享育殖。

    4. 多细胞与身体底层

    • 多细胞体由大量酸腔细胞嵌入连续三维矿物—P–N–S 活体晶格形成；
    • 体内存在慢速物质 / 废物 / 热循环与快速电化学 / 电子 / 金属价态网络；
    • 神经为离子—电子—金属价态混合电化学系统，采用中心高阶节点 + 局部神经节的分布式架构；
    • 运动组织通过可逆金属配位与聚合物构象变化产生伸缩；
    • 外部支撑为持续更新的矿物—聚合物复合支撑板，不进行整体现代节肢动物式蜕壳；
    • 个体宏观形态可差异巨大，甚至远看似不同物种；共同性来自深层生命架构，不来自统一外形模板；
    • “像蜈蚣 / 螃蟹”的旧讨论只表示避免人形，不是视觉定型；宏观视觉设计仍未开始。

    5. 感觉系统

    四个主要通道： 1. 偏振—光谱视觉：可见光 + 近紫外 + 强偏振分辨； 2. 电场感觉：被动生物电感知，可发展主动近场电定位； 3. 振动感觉：空气、地面和固体结构传播； 4. 化学势感觉：酸活度、硫氧化态、金属离子和氧化还原环境。

    这使迭生者与埃纳生命接口在低层电化学 / 电磁状态上具有偶然的物理兼容性，但不代表天然读心或原生共思。跨物种高层接口仍需翻译 / 共生接口系统。

    6. 共享育殖巢

    共享育殖是原栖星上广泛存在的宏观繁殖策略，迭生者采用成熟的群体育殖巢版本： - 无固定生物性别； - 参与者自愿共同建立蜂窝状活体育殖结构； - 各参与者向共享遗传池贡献信息材料； - 共享池进行混合、重组、错误校验和质量过滤； - 再分配到独立巢格； - 每格从全能原始生命单位发展为胚胎 / 幼体； - 幼体最终“破格出生”； - 单一幼体不是所有参与者完整基因的总和，而是从共享池中形成的稳定随机组合。

    演化根因优先解释为高辐射下的多模板纠错和繁殖可靠性；多样性加速是副作用，不是文明主动设计目标。

    育殖生态必须包含：遗传身份防火墙、寄生压力、育殖共生体、育殖位竞争、巢体回收等完整生态。

    7. 生命周期与代际

    冻结参数： - 育殖巢发育：0.4–0.7 年； - 快速塑形：约至 2 年； - 基本独立活动：约 1.5–2 年； - 高阶认知成熟：约 2–5 年； - 生物繁殖成熟：约 4 年； - 完整文明成熟：约 6–7 年； - 主要高功能成年期：约 6–25 年； - 约 25 年后协调性老化更明显； - 典型自然寿命：约 30–35 年，少数接近 40； - 有效世代间隔约 5 年，社会为异步多代群并存。

    它们在接触埃纳前不认为自己“短命”；30–35 年就是正常完整生命。它们知道苍阳本身在恒星中异常短寿。

    8. 情感与社会

    不得套用人类“性别—婚姻—父母—血缘继承”结构。

    主要底层情感： - 同一育殖巢 / 同代群强烈的代群依恋； - 对新代群的群体守护，而非“我的孩子”； - 与特定个体 / 小群体形成非繁殖绑定的深度关系； - 强烈的“接续”需求：希望工作、知识、关系和文明能够被下一代继续。

    遗传贡献者不自动等于抚育者，也不天然产生政治 / 财产继承权。

    9. 教育、知识与文明连续

    • 六七岁“文明成熟”不等于专家完成训练；专家教育仍可持续多年；
    • 文明依赖高密度群体照护、项目接续和高度外置化知识；
    • 记录必须包含实验、失败、未解问题和项目历史，不只保存结论；
    • 因身体和感官世代漂移，信息系统高度强调跨感官语义抽象和重新映射；
    • 最严重的文明灾难之一是“接续链断裂”：当前专家 + 记录 + 培训链同时丢失；
    • 冗余文明记忆节点因此很早成为基础安全设施。

    10. 生态与食物网

    • 不存在地球式植物—氧气—碳食物网；
    • 初级生产将无机 P / N / S / 金属转换成高能、可利用的 P–N–S 前体；
    • 表层生产依靠苍阳驱动的光化学；地下 / 深酸环境依靠地球化学硫—金属氧化还原；
    • 消费者获取已经处理的 P–N/S 前体、高能硫态、金属催化中心和功能聚合物；
    • 回流 / 分解生态负责释放磷、改变硫价态、回收金属；
    • 磷可能是关键限制性资源；
    • 大型生命广泛采用摄食 + 共生生产混合模式；
    • 迭生者目前冻结为高机会主义广食性消费者谱系，精确摄食器官尚未视觉化。

    11. 文明发展与技术时间窗

    核心原则：不是“进化速度简单乘 200”，而是绕过地球生命史若干独特瓶颈： - 生命起源极早； - 无全球氧化等待； - 无必须经历真核 / 线粒体单点跃迁； - 多腔体复杂化连续； - 共享模板与育殖池扩大搜索； - 核心高保真 + 外围高变异； - 强辐射提供变异输入，高修复控制灾难性错误。

    关键技术时间基线： - 洛维发现时苍阳自然仅余约 1000–2000 年； - 若无洛维，苍阳自然终末时，迭生文明大致处于现代人类综合技术水平：成熟科学、全球信息网络、卫星 / 载人空间、无人深空探测、早期轨道工业； - 洛维额外延长数千年后，迭生文明发展为成熟早期恒星系文明：大型轨道工业、多天体节点、小行星资源、长期空间栖居、育殖巢离星实验、先进深空推进、星际探测甚至少量个体级远行； - 仍无法在苍阳终末前独立建立一个能长期维持完整迭生人口、育殖生态、工业和文明接续的他星系节点。

    12. 洛维如何发现迭生文明

    迭生文明在确认苍阳自然寿命只剩约 1000–2000 年、且自身无法完成文明迁移后，主动发射文明级星际求救信号，包含： - 坐标； - 苍阳模型和剩余寿命； - 原栖星环境； - 生命化学； - 技术水平； - 无法迁移的现实； - 数学 / 物理译码； - 请求任何智慧主体建立联系。

    洛维在地下私人路线附近首先有效接收到该信号。

    他最初没有回应。

    当确认该文明的长期文化与艺术价值后，他把“发现”转变成“独占资产”，并主动在苍阳系统外围对外发求援和可识别技术信号实施吸收、散射、重编码和伪装，使迭生文明从自身观测看信号已正常发出，但外界难以据此定位和接触。

    关键伦理事实：

    迭生文明明确向宇宙请求联系；洛维听见后，仍主动阻止其他答案。

    13. 洛维人物与四埃纳核心圈

    洛维：男性成熟埃纳文明核心，长期地下文化 / 艺术交易者。主体 / 神族路线倾向仍未冻结。

    人物要点： - 极重来源链、原作、关系因果和真实性； - 真正热爱艺术，也擅长把主体与文明资产化； - 社交性强，会做生意，不阴郁； - 深信任关系可共思，但保留强私人边界； - 计算型赌徒：模型认为可控时敢下重注；长期成功强化其“下一个问题也能解决”的信心； - 不反共同体，地下是职业 / 关系选择； - 讨厌伪造来源、毁掉复制品抬价、杀死创作者制造“绝笔”等行为； - 能同时真心珍爱文化与长期阻断其文明主体的对外关系。

    核心埃纳只保留四人，不再为技术模块新增埃纳角色： - 洛维：项目核心、总决策、文明资源与地下关系； - A：地下路线、贸易、资源和隐蔽物流老友； - B：高等级工程老友，后期参与苍阳维护与迁移系统； - C：正式文化 / 历史 / 文明研究老友，认识洛维很早，理解迭生文化最深。

    四人都是独立成熟埃纳文明核心，不是洛维下属。

    14. 苍阳维护

    洛维最初独立完成苍阳工程建模和早期干预，持续数百年后仍真实有效。

    他并非因为“不会恒星工程”才找 B，而是项目逐渐变成： - 恒星寿命； - 原栖生态阈值； - 可观察外观； - 技术痕迹； - 信号保密； - 未来迁移；

    多目标耦合。B 在这一阶段加入。

    洛维的干预确实把苍阳的可用寿命延长数千年。当前正式接触时，没有洛维的自然时间线早已完成核心坍缩，因此迭生文明当前整个时代本身就是“额外获得”的历史时间。

    15. 四条关系线如何相互发现

    A、B、C 不组成正式调查小组。

    冻结关系节点： - A 与 B 因一次秘密设备运输接口问题第一次确认自己参与的是同一个苍阳项目；A知道艺术市场、路线和迁移物资，B知道恒星与生命行星工程； - A 与 C 因洛维转交少数未出售原作而第一次把“持续艺术生产”“外发求救”“大规模迁移物流”拼到同一项目； - C 通过迭生作品和文明历史看出它是一个持续回应自己历史、不断变化的活文明，而非死文明遗产； - 三人的信息长期分区，彼此只逐步交叉，且仍尊重成熟埃纳私人边界。

    对话标准：表层事实说清楚，深层情绪留白。不得以谜语式模糊代词代替关键剧情信息。

    16. 整颗原栖星秘密无伤迁移：提出、认识极限、主动放弃

    洛维曾认真评估“整颗原栖星 + 主要卫星 + 大气 / 酸海 / 地质 / 磁层 / 生态 / 文明连续性”整体迁移。

    单纯移动行星不是成熟埃纳的核心难点。真正难点是：

    在秘密、无感、无伤条件下保持一整个未知生命世界的连续运行。

    模拟逐渐发现：只维持已知状态参数不足以保证几百代以后仍然存在的低频生态、地质—化学—育殖因果关系。

    “保持过程连续，而不是只复制状态”作为该项目产生的重要工程思想保留。

    但当洛维确认要真正实现整星无伤秘密迁移，必须不断扩大专业能力、数据和完整知情圈时，他没有继续招募更多埃纳，而是主动止损放弃整星方案。

    这是现行剧情硬约束： - 不新增“生命世界连续性专家”等专门埃纳； - 四名埃纳足以完成后续文明抢救； - 具体执行优先调用洛维自身文明体系内的附属文明、智慧生命、AI、工程生命与文明器官。

    17. 救援目标降级：从母星连续到文明—生态连续

    整星方案放弃后，洛维的目标变为：

    让迭生文明本身作为真实、自我繁殖、自我生产、自主发展的文明继续存在。

    救援对象包括： 1. 全部现存迭生人口（默认纳入，不预先按精英筛选）； 2. 正在形成的新代群； 3. 完整育殖巢与育殖共生网络； 4. 多套完整 P–N–S 生态闭环； 5. 足以恢复自主生产的工业体系； 6. 完整公共文明记忆； 7. 自愿保存的个体、地方、文化记录； 8. 在生命与生态之后尽量保存城市结构、原作、日常物、地质样本等母星实物。

    核心问题是“怎样尽量少失去”，而不是“谁值得被救”。

    18. 第一次正式回应

    当撤离模型必须处理“个体迁移意愿”时，洛维确认：如果目标是保存文明而不是生命样本，就不能在迭生文明完全不知情的状态下强行迁移。

    他不伪装成“刚刚收到”。

    迭生文明经多阵列验证，将跨越数千年的记录：

    “外部智慧回应：未确认”

    第一次改成：

    “外部智慧回应：已确认”。

    其第一项关键问题不是求救细节，而是：

    “请告知：你最早在什么时候接收到我们的信号？”

    19. 求援封锁真相

    洛维对“是否持续收到”“是否包括后续求援”“是否主动处理 / 阻止外发信号”等直接问题均不撒谎，明确承认。

    20. 苍阳真相的重量

    迭生文明独立重算洛维提供的自然演化模型后确认：

    如果没有洛维，苍阳早在数千年前已经核心坍缩，原栖星也早已毁灭。

    21. 先了解埃纳，再谈长期关系

    正式长期关系谈判前，迭生文明必须先理解： - 埃纳是智慧种族 / 文明共同体； - 成熟埃纳通常也是高度自治的个体文明核心； - 洛维代表自己及其文明体系，不代表全部埃纳； - A、B、C 是独立埃纳，不是洛维下属； - 埃纳共同体是有限制度化公共共同体，不是银河中央政府； - 银河存在其他高等级文明和顶级战略主体； - 与洛维达成关系不等于与全部埃纳达成关系。

    22. 洛维主动提出附属邀请

    在整星方案失败后，洛维本可以： - 止损离场； - 只保存资料； - 保存有限生命； - 保存少量迭生者； - 不承担后续银河长期责任。

    23. 附属资格的认知反转

    迭生文明通过公开接口独立核验： - 埃纳标准附属协议； - 历史修订链； - 其他现存附属文明； - 附属申请机制； - 准入门槛； - 长期发展与脱附记录。

    它们逐渐发现： - 大量低等级乃至已有相当星际能力的文明会主动申请成为成熟埃纳的附属； - 申请不一定获批； - 附属不天然被视为等待摆脱的临时低级状态； - 加入成熟埃纳文明核心意味着直接接入文明级安全、跨星际交通、高阶基础设施、银河风险网络和发展体系。

    因此迭生文明的问题发生变化：

    从：

    “为什么要接受这种不平等关系？”

    变成：

    “为什么你愿意给我们这个资格？”

    洛维明确回答：他真正看好迭生文明的生命体系、科学潜力、文化、文明接续能力、韧性与未来价值；最初曾把它们视为资产，但后续已经希望“一个还能继续发展的迭生文明”长期留在自己的文明体系里。

    24. 附属关系正式建立

    迭生文明最终正式确认：

    接受洛维提供的附属资格。

    并愿依现行埃纳标准附属协议进入洛维文明体系。

    洛维正式确认接受迭生文明成为自己的附属文明。

    附属核心规则由 60_埃纳附属文明标准协议框架_V1.0.md 裁决，不由洛维与迭生文明临时重写。

    迁移不是附属资格的“救命收费”。附属资格本身就是洛维主动提供的高价值长期文明关系；具体救援和接入只通过实施附件细化。

    25. 原栖星撤离原则

    附属关系成立后，双方共同制定撤离实施附件。

    首要原则： - 默认目标为全体现存迭生人口 + 正在形成新代群全部撤离； - 不预先按职业、艺术、科学或“价值”筛选精英； - 若真实工程窗口后期迫使缩减，才重新决策； - 育殖生态必须持续运行； - 生态迁移按完整循环而非物种清单； - 工业必须足以让迭生文明逐步摆脱对洛维日常供养； - 文明记忆包括公共档案以及个体自愿保存的私人 / 地方 / 文化记录； - 母星实物位于生命、生态和工业之后，但尽可能带走。

    最终迁移成功完成：最后一批不是被遗弃者，而是主动留下完成设施关闭、记录确认、生态 / 工业收尾和最终观测的主体。

    26. 终局：最后一批迭生者目睹苍阳死亡

    大撤离持续到苍阳最终阶段。

    最终冻结： - 原栖星智慧人口降为零； - 最后一批收尾迭生者已经离开行星，位于苍阳系外围最后迁移节点； - B 确认苍阳核心坍缩开始； - 最后一批迭生者主动要求留下短暂观测窗口，“想看到最后”； - 在安全迁移节点中，他们亲眼见证苍阳终末爆发； - 他们不是陪葬者，确认记录完整后立即离开； - 自动中继继续记录爆发抵达原栖星后的辐射、大气 / 化学失稳、轨道设施失效，直至记录中断； - 原栖星最终毁灭； - 整个迭生文明主体、育殖链、关键生态、工业与文明记忆已转移并持续运行。

    终局命题：

    世界死了，文明没有。

    28. 写作方法冻结

    本线进入文学场景时必须： - 表层信息说清楚，真正留白的是情绪、动机和关系判断； - 禁止把长期熟人的对话写成设定演讲； - 也禁止矫枉过正成大量“你懂 / 别装 / 哪个 / 没什么”式谜语对话； - 角色首先是人物，不是路线 / 伦理命题的发言器； - 技术模块不等于人物模块，后续不得为每个工程问题创造一个新埃纳专家。
