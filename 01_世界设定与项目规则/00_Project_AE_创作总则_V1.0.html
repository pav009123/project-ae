    Project AE｜创作总则 V1.0

    适用范围：Project AE 全部人物、文明、历史线、战争线、生命设计与叙事开发。 优先级：总则级硬约束。任何人物卡、支线总纲、文明设定或后续叙事不得与本文件冲突；若冲突，必须先显式提出并取得用户批准后才能修改本总则。

    1. 核心原则：复杂不等于可原谅，解释不等于辩护

    Project AE 禁止把“人物/文明写得复杂”自动等同于“必须给其寻找可同情理由、苦衷或道德正当性”。

    必须严格区分：

    • 因果解释：说明一个主体为什么形成当前奖励结构、目标、行为习惯、权力方式和风险偏好；
    • 道德辩护：据此降低其伤害行为的恶性，或把主动选择改写成“其实不得已”。

    前者可以且应当充分；后者不得自动发生。

    能解释一个反派为什么如此，不代表要替它证明“其实也有道理”。

    2. AE宇宙允许真正的纯恶主体与恶性文明

    AE宇宙中可以且应当存在真正意义上的恶人、恶性文明与不可调和的恶意主体。

    这类主体可以：

    • 清楚理解其他生命具有主体性；
    • 清楚知道对方会痛苦、恐惧、失去未来；
    • 拥有停止或选择其他方案的能力；
    • 仍然主动选择支配、奴役、掠夺、折磨、操纵、毁灭或否定他者主体性。

    其恶性不要求由无知、误会、精神失常、童年创伤、资源匮乏或文明安全困境来解释。

    高级、理性、长寿、科学发达，不自动推出伦理成熟：

    技术等级 ≠ 道德等级。

    CL6、CL7、CL8主体同样可能清醒而主动地作恶。

    3. 反派三分法：不得默认向“其实有苦衷”收敛

    设计敌对主体或文明时，先判断其属于哪一类；不得自动把第三类改写成前两类。

    A. 悲剧型对手

    • 冲突来自资源、安全困境、历史链条、误判或不可兼容的生存条件；
    • 对方可能造成巨大伤害，但不以伤害本身为目的；
    • 存在结构性原因和可能的第三解。

    B. 异质型对手

    • 其主体结构、价值体系或文明逻辑与埃纳显著不同；
    • 不必是善，也不必是恶；
    • 冲突可能源自真实不可通约性，但不能因此自动宣称“双方都有同等道理”。

    C. 纯恶型反派

    • 明知他者是主体，仍把他者当工具、猎物、体验材料或服从对象；
    • 伤害、支配、折磨、占有、毁灭本身可以成为稳定奖励来源或长期目标；
    • 不需要提供可同情背景，不需要让其行为具有道德对称性；
    • 可以非常理性、极具自制力、长期规划严密、社会表现正常。

    纯恶并不等于浅薄。 纯恶角色仍必须有稳定动机、能力来源、行为逻辑、风险策略、隐藏机制和历史因果。

    4. 禁止“反派自动洗白”

    后续创作中禁止以下自动行为：

    1. 看到反派能力高、文明高级，就自动补充“其实只是价值观不同”；
    2. 看到其有创伤史，就自动把主动恶行解释成创伤的被动结果；
    3. 为了体现“深度”，强行把双方写成道德对称；
    4. 把明确的支配欲、享乐性伤害、主体剥夺重新包装成单纯秩序追求；
    5. 当用户已经批准某主体为恶性主体后，未经批准擅自增加足以改变道德性质的洗白设定；
    6. 用“高级文明不会这么做”否定恶意——高级文明只意味着它会把恶做得更系统、更隐蔽或更高效。

    5. 埃纳内部必须允许真正的恶人存在

    埃纳文明不能被写成“主体伦理成熟，因此内部不存在真正恶人”的乌托邦。

    埃纳内部可存在：

    • 纯恶个体；
    • 长期价值漂移后的恶性主体；
    • 清醒理解主体伦理、仍故意违反它的人；
    • 把他者自由当作可牺牲变量的人；
    • 以支配、占有、操纵、折磨或体验他者屈服为奖励来源的人；
    • 隐藏极深、数万年至数百万年不暴露真实奖励结构的高能力个体。

    这类主体尤其危险，因为它们熟悉埃纳文明正常制度，并可能利用：

    • 个人自主；
    • 研究自由；
    • 私人文明边界；
    • 异质价值容忍；
    • 奖励空间工程；
    • 自愿协议；
    • 主体退出规则；
    • 高度分散的个人文明结构；

    来掩护真正的恶意与长期计划。

    因此，“形式自愿”“合法研究”“个人选择”本身不能自动证明没有主体伤害。

    6. 隐藏恶人的写法

    真正高级的恶人通常不会公开宣告自己邪恶。

    允许其：

    • 保持长期正常社会关系；
    • 真诚喜欢科学、艺术、朋友或某些生命；
    • 在多数场景中遵守规则；
    • 只在特定奖励结构或权力关系上表现出极端恶性；
    • 有意识地控制证据、受害者叙事和外部观察；
    • 通过制度语言、专业术语与形式授权掩护伤害。

    局部善意不自动抵消核心恶性。

    一个主体可以爱朋友、保护宠物、热爱科学，同时仍然对某类主体实施清醒、长期、系统性的恶。

    7. 人物既定设定不得被本总则反向篡改

    本总则只规定“允许什么、禁止自动做什么”，不自动重新分类既有人物。

    特别是：

    • 玛娜；
    • G03/地球线相关埃纳；
    • 瓦赫相关危险主体；
    • 黑化埃纳；
    • 未来新增反派文明；

    其究竟属于悲剧型、异质型、纯恶型或混合型，必须依据各自已经冻结的设定与用户后续批准判断。

    不得因为本总则存在，就擅自把既有人物改成纯恶；同样不得再自动把其洗成“其实只是误会”。

    8. 高级文明的恶必须体现高级性

    若高文明被设定为恶性，其恶不能只表现为低级冲动。

    应考虑：

    • 长期隐藏；
    • 风险控制；
    • 代理行为；
    • 主体心理工程；
    • 制度利用；
    • 信息不对称；
    • 合法外观；
    • 奖励空间塑形；
    • 记忆、认知与关系操控；
    • 把受害者的反抗提前纳入模型。

    高级纯恶最危险之处不是“更疯狂”，而是：

    它完全知道自己在做什么，而且能做得极其稳定。

    9. 创作审计硬清单

    每次设计反派、敌对文明或重大冲突，在冻结前必须检查：

    1. 我是否因为“想写复杂”而给反派强行添加苦衷？
    2. 我是否把主动伤害改写成了误会、安全困境或不得已？
    3. 我是否无理由把双方做成道德对称？
    4. 该主体是否知道他者是主体？
    5. 它是否知道自己的行为会造成什么？
    6. 它是否拥有不这么做的能力？
    7. 如果前三问皆“是”，它仍选择继续——是否应允许它就是恶，而不是继续找借口？
    8. 如果已批准为纯恶型，后续新增背景是否在偷偷洗白？
    9. 如果是悲剧型/异质型，是否又反过来把它简单妖魔化？
    10. 角色/文明的能力、隐藏方式、资源、制度位置是否足以支撑其行为，而不是只靠作者宣告？

    未通过以上审计，不得冻结重大反派设定。

    10. 总冻结句

    Project AE 不要求所有冲突都有双方可理解、可同情、可调和的理由。宇宙中允许存在清醒、理性、强大且真正恶意的主体。理解其形成机制不等于为其辩护；复杂性来自稳定动机、能力、选择与后果，而不是强行洗白。
