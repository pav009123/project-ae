    M5-04E｜能量与物质收支闸门｜全文待审核

    版本：V0.1
    状态：待用户裁决

    一、审查目标

    判断一个拥有 1—4 米竖向多孔叶帆、支撑轴、根冠和导水结构的植物，能否在多数时间无雾的 P2 中维持正收支，并在 P3 雾期获得真实但有限的额外收益。

    重点检查：

    • 光合作用面积是否足够；
    • 半透明和多孔是否会过度降低光合效率；
    • 雾水相对于根系供水的比例；
    • 大气氮和风尘矿物能否真正贡献营养；
    • 竖向结构、修复和储备成本；
    • P0—P4 各阶段的碳、水和矿物预算；
    • 是否存在向其他物种无成本供水供肥的目的论。

    二、基础收支原则

    M5-04E 采用：

    根系供水和矿物吸收维持常态，竖向叶帆光合作用提供主要能量，雾滴与气溶胶捕获在特定窗口提供补充。

    其收支不能反转为“靠捕雾养活自身，顺便光合作用”。

    三、光合作用面积

    1. 主要光合器官

    主要光合面积来自：

    • 窄长竖向叶帆的两侧表面；
    • 纵向褶皱增加的有效表面积；
    • 支撑轴外侧光合皮层；
    • 少量根冠上方的低位光合组织。

    叶帆数量和间距必须避免严重自遮阴。

    2. 多孔结构的影响

    开放狭缝会减少连续组织面积，但带来：

    • 空气穿透；
    • 更低风载；
    • 内外两侧均可受光；
    • 雾滴接触边缘增加；
    • 表面更易干燥；
    • 热量和气体交换改善。

    孔隙率不能高到像人工网，也不能低到像整块布膜。精确范围留给生物力学和视觉闸门。

    3. 半透明边界

    历史“半透明”应解释为：

    • 年轻或较薄叶帆局部透光；
    • 成熟组织具有散射光能力；
    • 导水区和纤维肋综合色较浅；
    • 不表现为玻璃、塑料或透明湿膜。

    成熟叶帆仍必须含有足够光合色素，不能为了视觉透明度牺牲主要能量来源。

    四、雾滴捕获与导水成本

    1. 捕获机制

    叶帆表面由微尺度结构分工：

    • 凸起雾滴截留脊提高碰撞和合并概率；
    • 纵向亲水导流带使水滴向下移动；
    • 邻近低黏附或蜡质区域避免整面水膜；
    • 纤维肋阻止裂口扩展并维持导水方向。

    这些差异来自表皮微结构和蜡质分布，而不是机械管线。

    2. 水的优先级

    截获水按以下顺序使用：

    1. 补充叶帆自身水合；
    2. 沿导水沟进入支撑轴；
    3. 进入根冠附近短期储水组织和根区；
    4. 超出吸收能力后渗入周围基质。

    第四项是有限外溢，不是主动向 D/H/I 输送。

    3. 雾水不能替代根系

    原因包括：

    • P2 雾事件不稳定；
    • 雾滴量受风和地形限制；
    • P0 可能连续缺雾；
    • 叶帆损伤会显著降低捕获；
    • 污染和盐尘会限制直接吸收。

    因此根系和土壤水仍是年度主水源。

    五、矿物和气溶胶预算

    1. 可利用输入

    叶帆可截留：

    • 少量可溶含氮化合物；
    • 含磷和含钾矿物粉尘；
    • 铁、镁及微量元素；
    • 少量有机微粒。

    这些物质经雾滴溶解或冲洗后进入导水领和根际，再由根系选择性吸收。

    2. 为什么不能直接全部叶面吸收

    直接高比例叶面吸收会增加：

    • 盐毒；
    • 气孔堵塞；
    • 病原进入；
    • 光合表面遮挡；
    • 有害金属累积。

    因此叶帆更接近“截留与初步汇集界面”，真正筛选主要发生在表皮和根际。

    3. 清洁和排毒

    M5-04E 需要：

    • P3 雨滴冲洗；
    • 表层极薄老化层脱落；
    • 导水低点排出高盐浓缩液；
    • 根系选择性排斥；
    • 对高污染叶帆进行提前脱落。

    这些机制都有碳和矿物成本。

    六、根冠与储备

    根冠承担：

    • 多支撑轴的机械连接；
    • 碳水化合物储备；
    • 有限结合态水分储备；
    • 新支撑轴和新叶帆萌发；
    • P0 维持；
    • 风暴后替换器官。

    根冠不能演化成巨大多汁水囊，否则会增加腐烂、动物取食和机械不稳定风险。

    储备量应足以支持：

    • 数日至较长 P0 的低活性维持；
    • 失去部分叶帆后的重建；
    • P1 恢复；
    • P3 繁殖投入。

    精确持续时间待种群和发育闸门回算。

    七、结构材料预算

    支撑轴

    需要投入：

    • 多方向韧性纤维；
    • 抗疲劳组织；
    • 输导束；
    • 局部光合皮层；
    • 基部加粗和根冠锚定。

    叶帆

    需要投入：

    • 薄而韧的光合组织；
    • 纵向纤维肋；
    • 微脊和导水沟；
    • 可控脱落区；
    • 表面防病和防污染化合物。

    1—4 米高度之所以可能成立，是因为叶帆：

    • 窄长；
    • 多孔；
    • 可顺风弯曲；
    • 可单片脱落；
    • 不构成连续巨大迎风面。

    少数近 5 米个体必须具有更强基部、较窄叶帆或更受保护地形，不能简单等比例放大。

    八、碳分配顺序

    P2 常态下，同化碳优先用于：

    1. 维持根冠、根系和现有叶帆；
    2. 修复微小撕裂和导水表面；
    3. 补充储备；
    4. 替换老化叶帆；
    5. 建立新支撑轴；
    6. 有性繁殖。

    资源不足时最先削减：

    • 新轴形成；
    • 叶帆总面积增加；
    • 繁殖；
    • 对严重污染或低收益叶帆的维护。

    九、P0—P4 收支

    P0

    • 叶帆收拢；
    • 蒸腾和光合作用下降；
    • 使用根冠储备；
    • 停止新轴和繁殖；
    • 必要时脱落高成本老叶帆。

    目标是低水平平衡，不是继续高产。

    P1

    • 根区吸水恢复；
    • 修复输导和叶帆；
    • 先补储备；
    • 不立即最大化展开和繁殖。

    P2

    • 根系供水和矿物吸收维持；
    • 叶帆实现稳定净光合；
    • 表面日间干燥降低病原；
    • 进行慢速更新和储备积累。

    P2 必须是年度正收支基础。

    P3

    • 雾滴和湿风提供额外水分；
    • 营养颗粒输入增加；
    • 叶帆水合改善；
    • 可增加新轴、修复和繁殖投入；
    • 同时增加表面清洁、防病和风载成本。

    P4

    • 光照可能因云雨下降；
    • 叶帆长期湿润增加呼吸和病原成本；
    • 根区缺氧降低矿物吸收；
    • 强风和暴雨造成机械损失；
    • 植物可能主动降低展开面积。

    因此 P4 的水多不保证净收益最大。

    十、为什么不能无限向周围输出

    植物截获的水和矿物首先用于自身：

    • 光合作用与蒸腾；
    • 组织维护；
    • 储备；
    • 生长；
    • 繁殖；
    • 排毒和修复。

    只有在 P3 输入超过短期需求、根区已接近适宜水势且导水领仍有余量时，才会出现有限渗漏。长期大量输出会降低自身适合度，因此不可能被自然选择固定为无成本公共泵。

    十一、通过依据

    1. P2 收支由光合作用、根系水和根系矿物支撑；
    2. 叶帆双面、褶皱和支撑轴提供足够潜在光合面积；
    3. 多孔结构的面积损失由低风载、双面受光和气体交换收益补偿；
    4. 雾水和大气颗粒只作为 P3 条件性加成；
    5. 根冠提供有限储备和器官替换能力；
    6. 污染、盐分、病原和机械损伤均有真实成本；
    7. 没有免费供水、无限凝结或大气营养万能化。

    十二、成本与代价

    • 纤维支撑和根冠储备消耗大量碳；
    • 多孔和狭缝减少连续光合面积；
    • 竖向结构增加风害；
    • 捕尘降低表面光合效率；
    • 表面清洁和脱落造成材料损失；
    • 叶帆较薄，寿命可能短于支撑轴；
    • P0 收拢降低产量；
    • P4 防御和修复消耗资源；
    • 近 5 米个体需要更长成熟时间和更安全地形。

    十三、外部依赖

    • K2V 光谱和叶帆色素效率；
    • 单株叶帆总面积；
    • 孔隙率与风载；
    • 根系深度和 P2 土壤水；
    • 雾水捕获量；
    • 气溶胶营养浓度与污染物；
    • 叶帆寿命和替换速度；
    • 根冠储备规模；
    • 繁殖年度成本。

    十四、拟冻结项

    1. 主要能量来自叶帆与支撑轴光合作用；
    2. P2 主要水源和矿物来源来自根系；
    3. 雾水和气溶胶营养是条件性补充；
    4. 叶帆双面、纵向褶皱和多片分布提供主要光合面积；
    5. 成熟叶帆只能局部和轻度半透明，不能透明化到失去光合能力；
    6. 表面使用截留微脊、导水带和低黏附区域协同，不形成整面水膜；
    7. 捕获水优先用于自身，过量才外溢；
    8. 根冠储备碳水和有限结合水，但不是巨大多汁水囊；
    9. 叶帆可独立脱落和替换；
    10. P2 必须维持稳定正收支；
    11. P3 是额外水分、修复、增长和繁殖窗口；
    12. P4 可能因低光、缺氧、病原和机械损伤使净收益下降；
    13. 大气颗粒不能替代根际营养循环；
    14. 向其他物种的水和营养输入只属于有限外溢副作用。

    十五、未决项

    • 单株总光合面积；
    • 叶帆孔隙率；
    • 成熟叶帆含水量；
    • 根冠储备支持时长；
    • 雾水占年度水预算比例；
    • 大气氮占年度氮预算比例；
    • 叶帆平均寿命；
    • 近 5 米个体的额外结构成本；
    • 表面排盐和脱落频率；
    • 繁殖投入占比。

    十六、回退条件

    • 无雾 P2 无法维持正收支；
    • 主要水源被改成全年雾水；
    • 叶帆为了透明视觉而几乎没有光合色素；
    • 大气尘埃提供全部营养；
    • 捕获水在自身缺水时仍优先供给其他物种；
    • 根冠成为无腐烂风险的巨大水箱；
    • 叶帆不可替换且整面撕裂不影响个体；
    • P4 水越多产量永远越高；
    • 结构材料和修复没有成本；
    • 近 5 米高度无需额外代价。

    十七、裁决

    能量与物质收支闸门：拟条件通过

    通过条件：

    1. 生理与生物力学闸门回算叶帆总面积、孔隙率、支撑轴强度和根冠锚定；
    2. 繁殖闸门证明年度繁殖投入不超过 P2—P3 净盈余；
    3. F 和区域风场冻结后重新验证叶帆面积与维护成本；
    4. 最终图鉴不得把 E 表现为透明无叶绿素的人工集雾装置。
