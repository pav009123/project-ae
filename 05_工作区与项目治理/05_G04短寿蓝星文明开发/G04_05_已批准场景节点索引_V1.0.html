    G04-05｜已批准场景节点索引 V1.0

    状态：用于文学开发追溯；正式事实以 59 V2.0 / G04-04 为准

    本文件记录用户已明确批准的主要场景节点。中途被后续纠偏覆盖的探索不作为现行场景。

    S01｜A–B 第一次确认同一苍阳项目

    • 由秘密设备运输接口不兼容触发。
    • A 直接说自己给洛维向苍阳运了几百年东西；B 确认恒星 / 生命行星工程。
    • 两人拼出蓝星艺术与恒星维护属于同一项目。
    • 关键对话标准：不哑谜，直接说“苍阳 / 生命行星 / 艺术 / 迁移设备”。

    S02｜A–C 第一次拼出大规模迁移轮廓

    • 洛维托 A 给 C 送一件不愿卖的迭生原作。
    • C 通过作品知道迭生文明在轨道育殖、持续创作和向外求救。
    • A 知道洛维正在调动迁移设备和路线。
    • 两人第一次意识到洛维可能在准备把一个仍不知情的活文明整体带走。

    S03｜洛维确认整星秘密迁移超出可控范围

    • 行星本身能搬；生命连续性无法靠已知状态参数完全保证。
    • 继续做会要求不断扩大知情圈和专业能力。
    • 后续纠偏冻结：洛维不继续加埃纳，而是主动放弃整星方案。

    S04｜洛维第一次回应求救

    核心短信： - 已接收到你们的信号； - 确认苍阳进入不可逆终末阶段； - 具备协助建立长期生存环境和迁移体系的能力； - 无法保证保存母行星； - 如果愿意建立联系，请回应； - 署名：洛维。

    迭生文明第一问：

    请告知：你最早在什么时候接收到我们的信号？

    S05｜求援封锁真相

    迭生文明逐步问清： - 是否持续收到？——是。 - 是否包括后续求援？——包括。 - 是否主动处理 / 阻断外讯？——是。 - 阻断谁？——任何可能通过这些信号定位并接触它们的外部文明。

    迭生文明决定继续接触，但以后每项重要信息都要验证。

    S06｜苍阳本来早已死去

    后续时间线纠偏： - 当前不是“宜居窗口本来已结束”，而是苍阳在无洛维自然时间线里早已完成核心坍缩。 - 迭生文明当前整个时代都是洛维延寿带来的额外历史。

    S07｜原则上接受迁移合作

    迭生文明不把判断权交给洛维： - 独立验证； - 自己制定迁移规则； - 保持外讯开放； - 继续寻找其他外部关系； - 先发现不构成所有权。

    S08｜第一次系统理解埃纳

    迭生文明通过问答理解： - 洛维代表自己； - 成熟埃纳是文明核心； - A/B/C 不是下属； - 共同体不是银河中央政府； - 银河有其他顶层文明； - 没有自动救援一切濒危文明的普遍义务。

    S09｜洛维主动提出附属

    • 不是迭生文明先申请。
    • 不是“救命费用”。
    • 洛维明确自己本可止损，只做有限保存后离开。

    S10｜迭生文明对附属价值发生认知反转

    初始：只看见主权让渡。
    核验后：发现大量低级文明主动申请，且未必获准。

    关键问题变为：

    为什么你愿意给我们？

    洛维最终直接承认：

    因为我认为你们以后会很有用。
    ……而且我喜欢这个。
    ——你们。

    S11｜正式接受附属资格

    迭生文明正式文本：

    迭生文明接受洛维提供的附属资格。
    迭生文明愿依现行埃纳标准附属协议，进入洛维文明体系。

    洛维：

    确认。
    我接受迭生文明成为我的附属文明。

    S12｜第一次撤离实施讨论

    迭生文明先交“最低连续性保存方案”。

    洛维拒绝把“最低还能叫文明”当默认目标：

    我没让你们算最低能活多少。
    先按全部人口算。

    核心原则：

    先把整个文明写进撤离名单，再让真实工程极限告诉双方最终确实带不走什么。

    S13｜最后一批迭生者目睹苍阳爆发

    • 最后一批是主动收尾人员，不是被遗弃者；
    • 原栖星智慧人口已为零；
    • 位于苍阳系外围迁移节点；
    • B 确认核心坍缩；
    • 迭生者请求短暂等待：“因为我们想看到最后。”
    • 亲眼观测终末爆发后撤离；
    • 自动中继继续记录原栖星毁灭直到失效；
    • 新世界已有大量迭生者、运行育殖巢、新代群和逐步自主的工业。

    明确废止的中途场景方向

    • 不再新增“生命世界连续性专家”或“行星生态工程专家”进入核心故事；
    • 其后伦理冲突场景全部撤销；
    • 不再写迭生文明以近似同级文明姿态围绕利润率强势压价；
    • 不再写双方临时重新设计一个特殊迭生版附属宪制；
    • 附属核心制度使用标准模板。
