    B4-01 植物十六种光合生理与色彩机制复核 V1.0

    状态：通过。复核对象为 16 个正式植物代表类群；本文件统一颜色、取光、物质收支与脉潮边界，不替代各物种的完整闸门或视觉资产。

    一、共同结论

    1. 共生星植物允许青、蓝、黄、紫、红等综合色，但颜色必须由光合主/辅助色素、光保护色素、组织散射、矿化或繁殖组织承载；K 型恒星环境不指定单一“应有颜色”。
    2. 光合作用只覆盖基础代谢、组织维护和缓慢生长；储能、结果、根系扩张、脱根迁移及快速修复均依赖前期储备，并受水、氮、磷、限制元素、散热和运输能力限制。
    3. 蓝绿、青白、银白与珠光通常来自蜡质、空气微腔、水合胶层或纤维/矿化结构的散射与反射，不能直接等同于更高光合效率；琥珀、铜紫、珊瑚和紫红多是繁殖、成熟、抗氧化或矿物/氧化状态的局部功能色。
    4. 脉潮 P1—P4 是补水、扩张、捕光与繁殖的主要窗口；P5 必须以收拢冠面、降低导度、根段撤资、储能缓释、休眠或耐受结构度过。任何“全周期高功率捕光”均不成立。

    二、逐种审计

    代表类群 环境与取光策略 综合色及组织载体 主要收支与限制 P5/失败边界 结论
    露玛 Luma 开阔高辐照地的多层冠盘定向捕光；冠盘角度用于避热与分时取光 蓝绿—深青冠盘来自多色素吸收与蜡质表层；银青为散热脊/蜡质散射；琥珀为储能结节与成熟组织 冠盘维护、储能与根际投资消耗大量水、矿物和运输能力；高光不是无限能源 强热、长期干旱、水膜断裂、矿物受体钝化或根际竞争时撤资/缩盘 通过；B4-02 再审根际与瑟穆耦合
    奥兰 Oran 高位冠层争夺斑光；分枝与根塔将捕光、承力、供水分开 翡翠绿为主光合层；青白新纤维散射；青铜根塔为木质矿化与老化组织；金黄只限繁殖/成熟点 巨体高度受水柱、机械承力、氮磷与根塔矿物限制 风折、根塔失水、冠层遮蔽或繁殖季储备不足会降低冠层更新 通过
    塔鲁 Taru 季节性湿地的短窗口高效捕光与地下储根再生 柠黄—黄绿为辅助色素占比提高的薄叶；雾金为蜡质纤维散射；铜紫局限于储根氧化保护层 快速长叶与地下储根均需水、碳和矿物；不能长期维持高叶面积 P5 转入储根维持；涝害、地下啃食或储备耗尽会使次期再生失败 通过
    鲁玛里 Lumari 温润垫层的低矮广铺取光，利用近地散射光与短时湿润窗口 青绿胶质表皮承载光合层；乳白来自水合胶层散射；珊瑚红限繁殖/成熟边缘 垫层保水、修复与扩展依赖稳定水分和细粒养分 长期干裂、遮蔽、强踩踏或冲刷会破坏连续表皮 通过
    萨维林 Savelin 林缘斑光下以可调整冠面分批取光，避免一次暴露过热 翡翠—蓝绿主冠；银青为低色素叶脉和表层散射；铜玫限老叶缘/繁殖结构 冠面切换和光保护需要水分、修复材料与氮投入 强遮蔽、连续强光或根区干燥均会导致换冠失败 通过
    瓦鲁诺 Varuno 迎风、偏旱根脊的低冠捕光，减少蒸散与风蚀 银青—蓝灰由厚蜡层和空气微腔散射形成；珍珠白为干态反射；赤陶橙仅见矿化根鞘 反射/蜡质降低过热但也减少有效吸收；根鞘矿化消耗限制元素 长期缺水、根鞘裂损、盐/矿物失衡或强风剥离会削弱定植 通过
    卡雷迪 Karedi 矿岩裂隙中的低面积、分时取光；以楔根获得水与元素 蓝紫—青绿来自保护色素与纤维散射叠加；石英白为矿化/纤维反射；铜紫为应激或成熟局部色 裂隙水、根系空间与矿物可用性是主瓶颈；颜色不能替代光能 裂隙干涸、落石、盐害或根系被挤压时进入低代谢 通过
    霍拉伦 Holaren 洪退后短周期快速生产与锚定扩展 明黄绿为高速新叶的辅助色素配置；湿白为绒层散射；玫铜限成熟根带 迅速建叶和锚定均消耗储备，依赖洪退后水分与沉积养分 强流回灌、沉积掩埋、根带来不及成熟时会整片淘汰 通过
    梅拉苏 Merasu 腐殖边缘的低光取光与换根，避开病原/缺氧热点 深青绿为遮阴厚叶；青白为换根绒层散射；紫红限隔离根与应激成熟组织 换根、隔离壁和病原防御的碳氮成本高；腐殖并非无限肥源 缺氧、病原突破、持续阴湿或根际竞争会触发根段淘汰 通过
    阿雷 Alei 游生期利用水面/浅水开阔光，定植后转为稳定基质取光 湖蓝绿来自水合幼体的色素与散射；乳银为表层微结构；琥珀限传播结节 变态、漂移、定植和再建根系均消耗储能；游生期不能高速移动 水网断连、定植底物不足、强流损伤或储备耗尽会使世代中断 通过
    诺沙里 Noshari 高位风湿环境的叠瓦冠面分层截光与导水 孔雀蓝绿为主光合/光保护层；银青为蜡质叠瓦反射；铜金限孢子成熟缘 高位供水、抗风与孢子成熟对水分、承力纤维和矿物投入敏感 干风、冠面破裂、导流失败或孢子期缺水会降低繁殖成功 通过
    拉维 Ravel 高空藤冠沿多锚点争取开阔光；承力纤维与冠面分工 翡翠—青绿为光合藤冠；浅金为老化承力纤维/低角散射；琥珀为果实传播信号 伸长、跨空承力与果实生产依赖锚点、水运和矿物；不能无支撑无限延展 锚点损失、风剪、干期供水不足或果实成本过高时回缩枝段 通过
    穆伦 Muren 汇雾地带以槽叶收集散射光并导流至根部 湖蓝—青绿来自水合叶面色素；珍珠白为槽叶微结构散射；暖金限导流叶尖成熟区 水膜导流可减水损，但槽叶维护与矿化导流面有材料成本 雾期缩短、槽道堵塞、强日灼或根区排水失败会降低光合与补水 通过
    杜纳里 Dunari 深阴环境利用低光与漫反射，扩大而非增强单位光功率 深靛青为低光光捕获和叶背保护的综合色；冷青白为薄层散射；梅铜为老叶/成熟局部色 低光捕获需要更多色素和较薄的光合组织，易受突发强光与病原损伤 冠层骤开、长期湿滞、矿物不足或叶背受损会造成光氧化/腐败 通过
    维瑟 Viser 贫瘠分舱基质中以小面积活性皮层分区取光和元素封存 青白—蓝绿为活性皮层与乳浊散射；乳白为隔离壁；赭红、铜紫随元素封存/氧化状态局部变化 隔离壁、修复和元素封存消耗碳与限制元素；不可将异常色当作增能 毒性元素过载、隔离失效、干湿突变或根区竞争会使分舱淘汰 通过
    赫瓦 Heva 湿润光窗内以展开冠膜取光；跨区迁移期卷收、储能和再锚定 钴蓝—青蓝冠膜由辅助色素与多层表皮共同形成；金色为果序成熟信号；深青紫为卷收保护层 移动是低速且高成本的：基础光合只供维护，迁移、再锚定和结果消耗储能、水与矿物 水膜中断、锚点稀少、储能未满、风剪或果序负荷过高时停止迁移并进入保守期 通过；不得画成晒太阳高速行走

    三、跨物种一致性裁决

    • 绿色系不是默认义务：奥兰、塔鲁、鲁玛里、萨维林、霍拉伦、拉维仍以绿/黄绿为主要光合表型，是因其环境中高可见光捕获与组织成本较低；露玛、瓦鲁诺、卡雷迪、阿雷、诺沙里、穆伦、杜纳里、维瑟、赫瓦采用青蓝、蓝灰或深靛，是不同色素与结构散射/光保护组合的结果。
    • 高反射色不能同时承担高吸收：银青、青白、珍珠白主要位于冠面上层、叶缘、蜡层、散热脊或非主光合组织；主要取光区必须保留相应吸收组织。
    • 繁殖强调色只允许局部、阶段性出现；不得将琥珀、铜紫、珊瑚、玫铜或金色铺满全株。
    • 赫瓦的迁移、露玛的储能、阿雷的游生变态均以既有光合—储能—水分账本为前提，不能作为超自然能力处理。

    四、结论与后续

    16 种植物均有可解释的综合色、组织载体与资源代价，未发现需要因“不是绿色”而回退的类群。下一节点 B4-02 应专门检查露玛的生态尺度收支、根际竞争、瑟穆协作与失败条件；视觉重制仅可引用本复核结论，不得反向改写它。
