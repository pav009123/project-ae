    M6-R01｜根脊林缘季湿样本区环境输入基线 V1.0

    版本：V1.0
    状态：现行复审输入基线／准冻结
    用途：为 M5、微生物功能群和 M6 动物统一提供环境考场条件

    0. 裁决摘要

    M6-R01 不再定义为永久湿地，而定义为：

    位于温暖温带—亚热带过渡气候中的根脊林缘季湿区域。常态 P2 温润、通风、地表可自然干燥；P3—P4 脉潮期间，部分低地和林缘短时进入接近热带雨林雨季的高湿、高降水和高生物活性状态。

    本区不是：

    • 永久沼泽；
    • 连续水膜地表；
    • 全球浅雾样板；
    • 果冻状菌毯；
    • 所有生物统一湿亮的软膜世界。

    1. 空间与气候位置

    1.1 区域尺度

    层级 建议范围 用途
    区域范围 直径约 3—12 km 种群连接、邻区交换、脉潮传播
    核心样本带 约 1—3 km 植物分布、动物生态位和维护路径
    图鉴展示区 约 300—800 m 场景、剖面和群落图鉴

    1.2 暂定地理约束

    在全球地理尚未完全冻结前，复审统一采用以下操作区间：

    • 等效纬度：约 24°—38°；
    • 海拔：约 150—900 m；
    • 距大型海洋、内海或高蒸发水体：约 50—250 km；
    • 地貌：低山、缓坡、侵蚀沟、古根脊与地下含水层交错；
    • 气候：温暖温带至湿润亚热带过渡型，具有明确干湿波动，但没有长期严酷干旱。

    这些数值是区域生态复审的操作范围，不等于全球最终地图坐标。

    1.3 临时物理假设

    在行星质量、半径和大气最终冻结前，本轮生物力学统一按以下近地条件审核：

    • 表面重力：0.90—1.05 g；
    • 地表气压：0.95—1.10 个地球标准大气压；
    • 空气密度和氧化剂供应：足以支持地球大型陆生植物和中型动物相近量级的气体交换；
    • 若未来全球参数超出上述区间超过约 10%，巨型植物、飞行生物和大型动物必须重新打开生物力学闸门。

    2. 常态气候基线

    2.1 P2 日常状态

    P2 是 M6-R01 的日常基准，而不是持续雨季。

    建议状态：

    • 日间空气相对湿度通常约 45%—70%；
    • 清晨和背阴处约 65%—85%；
    • 晴天表面可以自然干燥；
    • 有正常风、远景和空气通透度；
    • 林下、腐殖洼地和根际保持稳定土壤水分，但不形成普遍积水；
    • 雨后 exposed surface 通常数小时内干燥，阴影和多孔垫层内部保水更久；
    • 日间常见温度约 18—28°C，夜间约 10—20°C；
    • 季节性低温和高温可以超出该范围，但不以全年闷热为默认。

    2.2 降水与水分

    区域年降水量可暂按 800—1600 mm 的温润森林量级理解，但降水分布受脉潮明显聚集：

    • 常态存在普通阵雨和季节雨；
    • P3—P4 贡献较高比例的集中降水；
    • 地表不依赖持续覆盖水膜储水；
    • 主要储水位置是土壤孔隙、地下含水层、根际交换层和植物储水组织；
    • 低地、沟谷和永久水体是局部湿生环境，不代表整个样本区。

    2.3 风与蒸散

    • P2 常态风可以穿过林缘和根脊通道；
    • 防风脊等植物改变局部风速，但不创造全年无风环境；
    • 晴天蒸发与蒸腾能够使表面恢复干燥；
    • P3—P4 湿度升高时，蒸发散热效率降低，动物和植物必须处理热负荷、低氧根际和病原风险。

    3. 脉潮在本区的落地方式

    3.1 物理链条

    双月及轨道周期
→ 区域水汽输送和地下水势改变
→ 云量、阵雨、土壤含水和根际营养释放上升
→ 植物展开、微生物活化、动物活动集中
→ P3—P4 高生产力和高风险窗口

    M6-R01 的脉潮不是一股可见水墙，也不是覆盖区域的透明膜。

    3.2 时间尺度

    由于全球脉潮周期尚未最终数值化，本区暂只冻结相对持续时间：

    • P0：低活跃期，可持续数日至较长季节段；
    • P1：恢复过渡，通常为数日至数周；
    • P2：常态主阶段；
    • P3：活跃湿化窗口，典型为 2—8 日；
    • P4：极活跃峰值，典型峰值持续约 6—48 小时，嵌入较长的 P3 湿化过程；
    • 退潮：地表水在数小时至数日回落，深层土壤和地下水恢复更慢。

    3.3 空间异步

    同一时刻区域不同微地貌可以处于不同局地响应：

    • Z1 根脊高位可能仍接近 P2；
    • Z5 腐殖洼地可能已达到 P4 水分风险；
    • Z7 凝雾洼地可能出现短时高湿；
    • 地下水响应通常晚于第一轮降雨；
    • 植物繁殖和动物孵化可比降雨峰值延迟数小时至数日。

    4. 七个微环境的现行定义

    编号 现行名称 典型面积占比 P2 状态 P3—P4 状态 主要限制
    Z1 上缘根脊隆起带 20% 干爽、通风、强光 雨水快速排走 水分、附着空间、风剪切
    Z2 根脊侧坡结壳带 18% 半干、矿物输入高 表面短时湿润、渗流增强 矿物毒性、坡面稳定、风蚀
    Z3 基生垫层缓冲低地 28% 表层可干，底层保水 吸水膨胀、局部积水边缘扩大 光、踩踏、根际氧气
    Z4 季节导水与根际分配带 10% 多数水流位于地下或浅层 沟槽和节点出现短时水流 堵塞、冲刷、过量输水
    Z5 季湿腐殖洼地 12% 湿润但非泥潭 可接近饱和并出现浅水 氧气、病原、腐殖过载
    Z6 生命渠支线边缘 7% 稳定水分与维护干预 负荷和分配压力上升 人工干预、接口污染、责任冲突
    Z7 脉潮凝雾洼地 5% 多数时间无雾或仅晨雾 P3—P4 易形成局地雾和高湿 视距、病原气溶胶、低风散热

    面积比例是核心样本带的推荐构图比例，可因具体场景调整，但不得让 Z5、Z7 湿生区域吞没整个样本区。

    5. 地表与土壤水分规则

    5.1 地表湿润持续时间

    • P0—P2：裸露高位表面在雨后约 0.5—4 小时恢复干燥；背阴、垫层底部和腐殖孔隙可保持更久；
    • P3：阴影、低地和植物凹面可连续湿润约 6—24 小时；
    • P4：Z5、Z7 和局部沟谷可连续湿润 12—48 小时，部分出现临时浅水；
    • 湿润持续时间超过上述范围时，应被视为局部水体、排水失败或异常脉潮事件，不是普通地表状态。

    5.2 “膜”的现行限制

    允许：

    • 土壤颗粒间微观水膜；
    • 根表微孔中的水化界面；
    • 雨滴、晨露和短时湿润面；
    • 永久溪流、湖泊和局部湿地中的真实水际生物膜。

    禁止作为区域默认景观：

    • 连续宏观薄水膜；
    • 肉眼可见的大面积菌膜；
    • 行走依赖黏液表面；
    • 所有植物与动物表面长期湿亮。

    6. 生产力与资源限制

    6.1 相对生产力指数

    以 P2 日常生产力记为 1.0：

    阶段 瞬时生产力／活动指数 说明
    P0 0.45—0.65 表层水分和可溶营养较低，许多生物降活性
    P1 0.70—0.90 根际和小型动物逐步恢复
    P2 1.00 区域长期可持续基准
    P3 1.30—1.80 水分和营养上升，繁殖与觅食集中
    P4 1.20—2.00 高峰区活动极强，但水涝、低氧和病原使部分生产者受抑

    P4 不等于“最佳环境”。超过适宜阈值后，部分低地植物会关闭气孔、停止根系吸收或进入防涝状态。

    6.2 不同阶段的主要限制

    • P0：表层水分、可溶营养和幼体建立机会；
    • P1：恢复速度、储能剩余和微生物重启；
    • P2：光照、空间、矿物和长期竞争；
    • P3：安全繁殖点、捕食风险和病原暴露；
    • P4：根际氧气、地表稳定、洪流和热湿散热。

    7. 群落承载原则

    在具体能量数据补齐前，本区采用营养级约束：

    1. 基生植物、根塔和腐殖分解层构成主要生物量；
    2. 小型腐殖动物和植物边缘取食者可较丰富；
    3. 小型捕食者密度必须明显低于猎物；
    4. 中型动物以稀疏、迁入或较大活动域为主；
    5. M6-21—M6-26 不得在 300—800 m 图鉴展示区内同时高密度出现；
    6. P3—P4 的动物聚集是短时事件，不代表全年常住密度；
    7. 大型根塔和巨型根塔数量受成熟时间、锚定位点和地貌稳定性限制。

    8. 主要扰动与恢复

    8.1 常见扰动

    • P0 延长导致表层干燥；
    • P4 暴雨导致沟谷冲刷、坡面滑移和根际缺氧；
    • 动物踩踏或掘食造成垫层破损；
    • 病原在 Z5、Z7 短时扩张；
    • 根塔老化组织坍落；
    • 生命渠支线分配错误；
    • 矿物结壳过度封闭土壤孔隙；
    • 局部火灾或高温事件在较干年份发生。

    8.2 恢复路径

    恢复主要依靠：

    • 基生垫层的边缘再生；
    • 根际微生物恢复；
    • 储根丘和休眠鳞片释放储备；
    • 根塔锚定模块保留并重新萌发；
    • 邻区繁殖体迁入；
    • 水文恢复后腐殖和矿物重新分配。

    恢复不是埃纳单方面修复的结果。埃纳可以减少干预错误、疏导水文和控制病原，但自然群落必须具有自主恢复能力。

    9. 综合色与视觉基线

    P2 日常外观

    • 空气清透；
    • 有蓝色、青色或淡暖色天空；
    • 地表多为干燥哑光、粗糙矿物和有机质纹理；
    • 植物可呈绿色、蓝绿、红紫、黄色、白色等清楚色相；
    • 腐殖只占局部低地，不统治整个画面；
    • 不出现全景湿亮和灰褐滤镜。

    P3—P4 外观

    • 植物综合色因水合而加深；
    • 雨滴、叶面反光和局部雾增加；
    • 沟谷出现真实浅流；
    • 色彩更饱满，但不出现荧光液体或黏液膜；
    • 视觉可接近热带雨林雨季，但必须保留根脊、坡地和排水层级。

    10. 环境闸门结论

    项目 裁决
    区域定位 通过
    常态湿度与干湿循环 通过
    P3—P4 短时高湿化 通过
    七微环境迁移 通过
    生产力与承载原则 条件通过，待植物复审后量化

    总状态：条件通过，可作为第一轮全生物复审的统一环境输入。
