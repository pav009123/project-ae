    M5-04D 基生垫层植物｜生物光学性状闸门｜全文已通过

    版本：V0.7.24 工作检查点
    审核对象：M5-04D 基生垫层植物
    用户确认状态：用户已于 2026-07-10 批准
    归档性质：完整判断正文，不得以摘要替代

    一、审查目标

    本闸门验证 M5-04D 的综合色、反射、透光、湿化变化和繁殖结构是否具有生物学来源，并确保它在视觉上：

    • 显示为干触、哑光、活体光合组织；
    • 颜色可以丰富但具有功能分区；
    • 不依赖荧光、主动发光或金属涂层；
    • 不被画成普通草坪、苔藓、地衣、菌膜、橡胶垫或彩色装饰地毯；
    • P0—P4 的变化符合色素、含水和组织年龄的时间尺度。

    二、原始设定与历史输入

    历史色彩线索包括：

    • 深蓝绿色；
    • 铜褐色；
    • 紫灰色；
    • 暗银白色；
    • 低反光、偏干、粗糙；
    • 浅沟、微皱褶和气体交换带。

    这些可以作为可能的综合色输出，但不能冻结成一套无机制的固定色盘。现行综合色必须从 K2V 暖光谱、光合色素、防晒物质、耐磨表层、组织含水和年龄差异推导。

    三、问题诊断

    1. 综合色过于灰暗

    若全部组织都使用灰绿、褐灰和暗银，会削弱活体感和光合作用可读性。

    2. 颜色过度丰富

    若每个模块随机出现高饱和彩色，会破坏同种组织逻辑，并滑向魔法地毯或珊瑚。

    3. 湿化等于发光或湿亮

    P3—P4 只能造成含水加深、局部雨滴反光和组织展开，不能让整个斑块像透明凝胶一样发亮。

    4. 银白色易被误读为金属或矿物壳

    耐磨低脊可以因蜡质和微粗糙呈浅灰银，但不能具有镜面金属反射，以免与 M5-04G 混淆。

    5. 变色速度不合理

    综合色变化主要来自含水、色素积累和组织老化，不可在秒级整片同步切换。

    四、综合色机制

    M5-04D 的综合色由四类机制叠加：

    1. 光合色素：提供青绿、蓝绿、橄榄绿和黄绿色基础；
    2. 防晒与防食色素：在强光、失水和损伤区形成铜红、紫褐、酒红褐或暗赭色；
    3. 耐磨表层与蜡质微结构：使低脊呈灰绿、浅银灰、米灰或低饱和青灰；
    4. 年龄和营养回收：使老化组织转为草金、铜褐、灰紫褐和暗灰。

    颜色不需要在每株中全部出现。不同基因型、受光方向、年龄和微地形可以形成有限差异。

    五、组织分区的视觉逻辑

    1. 新生边缘

    可呈：

    • 较明亮的黄绿；
    • 清晰青绿；
    • 浅橄榄；
    • 局部暖金绿色。

    特征：组织较薄、活性较高、边缘略有透光，但仍是实体植物，不呈果冻透明。

    2. 成熟光合皱褶

    可呈：

    • 蓝绿色；
    • 青绿色；
    • 深橄榄绿；
    • 带铜调的成熟绿。

    这是斑块主要生产面，综合色应比耐磨低脊更深、更有生命感。

    3. 耐磨低脊

    可呈：

    • 灰青绿；
    • 浅银灰绿；
    • 暖米灰；
    • 低饱和紫灰。

    低脊依靠漫反射和低亮度高光显示坚韧，不出现镜面金属线。

    4. 强光与风蚀区

    综合色可向：

    • 铜绿；
    • 赭绿；
    • 紫褐；
    • 灰金褐；

    偏移，显示保护色素和表层老化。

    5. 老化与退出模块

    可呈：

    • 草金；
    • 铜褐；
    • 灰紫褐；
    • 暗褐灰。

    应能与活体光合区区分，但不画成腐烂黏液或焦黑死地。

    6. 繁殖结构

    M5-04D 为风媒植物，不需要鲜艳大花。短繁殖梗与小型花器可使用：

    • 浅草金；
    • 暖米白；
    • 淡琥珀；
    • 低饱和赤褐；
    • 灰金色花粉团。

    综合色作用是区分成熟阶段和提高结构可读性，不是吸引大型视觉授粉者。

    六、反射与表面质感

    常态 P2

    • 整体以哑光和半哑光为主；
    • 耐磨低脊呈宽而柔和的漫反射；
    • 光合浅沟更暗；
    • 只有极薄蜡质边缘出现低亮度高光；
    • 不产生塑料、硅胶或湿皮革质感。

    降雨和 P3—P4

    允许：

    • 雨滴和局部水珠的真实高光；
    • 综合色因水合而加深；
    • 皱褶展开后青绿色面积增加；
    • 凹沟短时出现微小湿润反光。

    禁止：

    • 整片持续镜面湿亮；
    • 内部发光；
    • 半透明黏液覆盖；
    • 彩虹油膜。

    七、透光与结构色

    • 新生皱褶边缘可有轻微透光，显示薄层活体组织；
    • 成熟低脊和中层不透明；
    • 微粗糙蜡质可形成轻微角度相关的灰银变化，但不形成虹彩；
    • 不冻结强烈紫外花纹，因为当前为风媒且没有证据需要动物视觉信号；
    • 不存在主动生物发光和可见荧光液体。

    八、P0—P4 光学变化

    P0

    • 含水下降，综合色变浅、偏灰或偏铜；
    • 皱褶收拢，暗色沟槽面积减少；
    • 表面保持哑光；
    • 边缘出现有限草金和紫褐老化色。

    P1

    • 从根区开始恢复含水；
    • 综合色在数小时到数日内逐步加深；
    • 不是整片瞬间变色。

    P2

    • 新旧组织形成稳定综合色层级；
    • 青绿、橄榄、灰银低脊和少量铜紫防护色共同出现；
    • 这是标准图鉴主状态。

    P3

    • 新生青绿和黄绿色面积增加；
    • 繁殖梗的草金、米白和琥珀结构更清楚；
    • 雨滴产生局部高光；
    • 综合色更饱满，但仍不荧光。

    P4

    • 低洼模块因过湿和泥沙变暗；
    • 局部出现褐化、失活或病斑；
    • 水退后可留下不规则老化区；
    • 不把 P4 画成全景宝石色高潮。

    九、斑块与个体差异

    视觉上应表现：

    • 同一克隆内部综合色连续但有年龄梯度；
    • 不同遗传个体可在青绿—橄榄—铜紫防护比例上有轻微差异；
    • 模块接缝和遗传边界由纹理、色差和生长方向共同显示；
    • 色差不能强到像多个完全不同物种拼贴。

    十、与相邻植物的光学区分

    与 M5-04G

    • D：柔韧、哑光、连续皱褶和模块接缝；
    • G：硬质矿物壳片、裂隙光合带和矿物晶体感。

    D 的银灰是蜡质漫反射，不是矿物护甲。

    与 M5-04I

    • D：开放地表、清楚光合面、干触表层；
    • I：腐殖边缘、深色根帘、半埋吸收结构。

    与 M5-04J

    • D：低幅皱褶和模块化宽片；
    • J：厚重重叠鳞片、明确收拢核心和休眠结构。

    十一、优化方案与现行视觉设定

    视觉综合色采用：

    活性青绿层 + 灰银耐磨脊 + 铜紫防护区 + 草金老化与繁殖结构

    但该公式描述功能层级，不是每张图必须平均分配的固定调色板。标准 P2 主图应保证：

    • 活体光合组织面积足够；
    • 综合色比旧版更有生命力；
    • 耐磨、老化和新生区域清楚；
    • 斑块仍然克制、自然、非装饰化。

    十二、通过依据

    • 所有颜色均可由光合、防晒、防食、蜡质、含水和老化机制解释；
    • 颜色丰富度与组织功能分区一致；
    • P0—P4 的变化符合生理时间尺度；
    • 风媒繁殖结构不依赖艳丽花冠；
    • 光学特征与 G、I、J 有明确区分；
    • 未引入主动发光、荧光液体、金属表皮或魔法变色。

    十三、成本与代价

    • 防晒和防食色素需要碳、氮及微量元素；
    • 蜡质和耐磨表层可能降低局部透光和气体交换；
    • 深色保护区在强光下可能增加热吸收；
    • 新生高活性综合色会提高植食者发现概率；
    • 综合色差异过大会增加视觉暴露，过小则降低组织分区效率；
    • 繁殖梗颜色清楚也会增加种子消费者定位机会。

    十四、外部依赖

    • K2V 地表光谱和紫外比例最终冻结；
    • 区域温度和强光时段；
    • 主要植食动物的综合色视觉范围；
    • 表层蜡质和纤维材料的折射率；
    • 最终图鉴渲染对综合色和微纹理的还原能力。

    十五、本闸门冻结项

    1. P2 常态为哑光或半哑光，不长期湿亮；
    2. 活性光合组织以青绿、蓝绿、橄榄和黄绿为主要综合色来源；
    3. 耐磨低脊可呈灰银绿、米灰和低饱和紫灰，但不得金属化；
    4. 强光、失水和损伤区可形成铜、赭、紫褐和酒红褐防护色；
    5. 老化模块转为草金、铜褐、灰紫褐和暗灰；
    6. 短繁殖梗和花器采用草金、暖米白、淡琥珀等低饱和综合色；
    7. 新生边缘允许轻微透光，成熟结构不透明；
    8. P3 综合色加深和活性绿增加，P4 可出现暗化与病斑；
    9. 综合色变化发生在小时至周尺度，不出现整片秒级快速变色；
    10. 不存在主动发光、可见荧光液体、强虹彩和镜面金属表皮；
    11. 不使用统一灰褐滤镜，也不使用无机制的彩虹拼贴；
    12. 综合色和纹理必须帮助识别模块、年龄和功能分区。

    十六、未决项

    1. 各综合色的具体色值和饱和度；
    2. K2V 紫外比例对防护色素的影响；
    3. 不同生态型的综合色差异；
    4. 新生边缘透光厚度；
    5. 耐磨低脊的灰银角度变化幅度；
    6. 繁殖梗和花粉的最终综合色；
    7. 病斑和正常老化色的区分；
    8. 植食动物综合色视觉是否促进伪装或警戒；
    9. P0 长期干燥后的综合色恢复时间；
    10. 最终图鉴是否需要单独 P0/P3 色彩对照特写。

    十七、回退条件

    以下任一情况触发本闸门重新审核：

    • 整株被改成单一灰褐而看不出活体光合组织；
    • 使用高饱和彩虹综合色但没有组织机制；
    • P3—P4 变成全株发光、透明或持续镜面湿亮；
    • 暗银低脊被画成金属、陶瓷或矿物装甲；
    • 秒级同步变色却没有专项触发和执行结构；
    • 风媒植物出现巨型艳丽花冠；
    • 不同基因型色差大到像不同物种；
    • D 与 G、I、J 在材质和综合色上无法区分；
    • 综合色只为装饰，不对应功能、年龄或环境。

    十八、裁决

    生物光学性状闸门：通过

    通过条件

    1. 最终视觉 Prompt 必须使用功能分区综合色，而不是固定平均调色板；
    2. 标准图鉴以 P2 为主，P0/P3/P4 只能作为对照状态；
    3. 图像审核必须检查是否误画为金属矿物壳、苔藓草坪或湿亮胶质膜；
    4. 若后续需要秒级变色、主动发光或强虹彩，必须重新触发专项闸门。
