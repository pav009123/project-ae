    M5-04D 基生垫层植物｜最终科学图鉴输出审核闸门｜出图前全文已通过

    版本：V0.7.25 工作检查点
    审核对象：M5-04D 基生垫层植物｜鲁拉纳 / Rulana
    用户确认状态：用户已确认通过（2026-07-10）
    归档性质：出图前输出规范与准入判断；实际成图尚未生成，不能以本文件替代成图验收

    一、审查目标

    本闸门判断现有生物学设定是否已经足以进入科学图鉴 Prompt 和候选图生成，并冻结首张图鉴必须传达的内容、版式和禁区。

    必须明确：

    • 图鉴主标题和命名状态；
    • 主图展示哪个脉潮阶段；
    • 必须出现哪些结构和生命周期信息；
    • 哪些未确认生态接口不得进入图像；
    • 如何避免文字、版式和材质错误；
    • 实际成图需要接受哪些复核。

    二、命名状态

    首张科学图鉴建议使用：

    基生垫层植物｜鲁拉纳 / Rulana

    其中：

    • “基生垫层植物”作为现行中文正式工作名；
    • “鲁拉纳”作为埃纳语汉语音译；
    • “Rulana”作为英文转写；
    • 历史“基膜垫植物”只保留在迁移记录，不进入当前主标题。

    如果后续命名专项提出更优正式名，可更新标题，但不得恢复“连续膜”语义。

    三、图鉴状态选择

    首张标准图鉴以：

    P2 常态成熟斑块为主体，局部展示 P3 繁殖状态。

    原因：

    • P2 最能展示自然干爽、稳定光合和模块结构；
    • P3 短繁殖梗可作为局部特写，证明有性繁殖；
    • P4 过湿不代表最佳状态；
    • P0 退缩状态不适合作为物种第一标准形象。

    四、建议版式

    采用横向宽屏科学图鉴页，建议 16:9 或接近 16:9，最高可用分辨率。

    中央—左侧主图

    展示一片成熟多基因型镶嵌群落，视角采用中低位斜俯视，使观者同时看见：

    • 不规则斑块外缘；
    • 模块接缝；
    • 新生边缘；
    • 成熟光合区；
    • 老中心退出空缺；
    • 稳定矿物—腐殖混合基质；
    • 少量短繁殖梗。

    右侧结构特写区

    至少包含：

    1. 表面耐磨低脊与光合浅沟；
    2. 三层剖面与下方锚定根；
    3. 模块接缝和受保护生长节点；
    4. 皱褶繁殖芽室、短繁殖梗、花器和蒴果；
    5. 幼体从窄轴到宽化模块的发育序列。

    下方状态与尺度区

    可包含：

    • P0、P2、P3、P4 简化状态带；
    • 单模块尺寸；
    • 总厚度；
    • 繁殖梗高度；
    • 克隆斑块与遗传个体边界示意。

    五、主图必须证明的内容

    主图不只是“漂亮地表”，必须能证明：

    1. 不是连续生命膜；
    2. 不是单一遗传个体铺满区域；
    3. 具有模块和接缝；
    4. 表面有真实光合面积；
    5. 表层常态干爽；
    6. 老中心会退出；
    7. 新生边缘更活跃；
    8. 斑块之间有空缺和其他基质；
    9. 繁殖结构短暂且风媒化；
    10. 下层根系把结构锚定在基质中。

    六、标签内容

    图中中文标签建议控制在高价值术语，避免伪科学小字堆叠。

    建议标签：

    • 耐磨低脊；
    • 光合浅沟；
    • 模块接缝；
    • 受保护生长节点；
    • 柔韧纤维支撑层；
    • 短程输导束；
    • 锚定根；
    • 根际交换层；
    • 皱褶繁殖芽室；
    • 短繁殖梗；
    • 干性蒴果；
    • 初生根—窄轴幼体；
    • 宽化模块；
    • 老中心退出空缺；
    • 多基因型镶嵌边界。

    禁止英文伪标签、拉丁学名和无法辨认的装饰文字。

    七、综合色与光照

    图鉴使用 K2V 晴天暖光谱模板。

    综合色必须包括：

    • 活性青绿、蓝绿和橄榄；
    • 灰银绿或暖米灰耐磨低脊；
    • 铜绿、赭绿、紫褐防护区；
    • 草金、铜褐老化区；
    • 暖米白、淡琥珀繁殖结构。

    光照要求：

    • 柔和暖日光；
    • 表面低反光；
    • 浅沟可较暗；
    • 雨滴仅在 P3/P4 对照特写出现；
    • 不发光、不荧光、不使用蓝紫灰统一滤镜。

    八、比例与尺度

    图鉴采用视觉差异闸门提出的工作尺度：

    • 单模块长 12—45 厘米；
    • 宽 8—30 厘米；
    • 常态总厚 8—28 毫米；
    • 局部老节点或低脊可达约 35 毫米；
    • 繁殖梗高 6—18 厘米；
    • 常见成熟克隆斑块直径 0.5—4 米。

    图中必须明确区分：

    • 单模块；
    • 单克隆；
    • 多基因型群落。

    九、允许出现的生态环境

    允许：

    • 排水良好的矿物—腐殖混合浅层；
    • 根脊缓坡和低地高点；
    • 斑驳光；
    • 少量落叶和矿物颗粒；
    • 轻度扰动痕迹；
    • 空缺中的幼体。

    不允许：

    • 永久积水中心；
    • 深泥沼；
    • 连续可见菌膜；
    • 浓雾笼罩；
    • 海洋、潮间带或水下场景；
    • 无确认动物群的大规模互动。

    十、跨物种展示边界

    首张标准图鉴不将 M6-16、M6-19、M6-20 作为稳定伙伴放入主图。

    M6-03 也暂不作为主互动对象，除非其复审完成。最多可使用：

    • 无具体物种辨识的微小足迹；
    • 简单比例尺；
    • 非叙事性的环境扰动痕迹。

    首张图鉴应优先证明植物自身成立。

    十一、生命周期展示

    生命周期至少包括：

    1. 干性蒴果释放种子；
    2. 种子进入稳定空缺；
    3. 初生根形成；
    4. 窄轴幼体；
    5. 节点生根；
    6. 初级宽化模块；
    7. 多模块亚成体；
    8. 性成熟斑块；
    9. 老中心退出并产生新空缺。

    不能只展示克隆扩展，必须展示有性种子起点。

    十二、Prompt 准入检查

    当前已经具备：

    • 物种成立；
    • 环境；
    • 能量；
    • 生物力学；
    • 竞争；
    • 演化；
    • 繁殖；
    • 种群；
    • 感知；
    • 生态网络；
    • 光学；
    • 病原与生物地理；
    • 视觉差异；
    • 生态审美。

    因此在本批获得用户批准后，可以编写 科学图鉴 Prompt V0.1 并生成候选图。

    十三、实际成图审核清单

    候选图生成后必须逐项检查：

    • 名称与标签是否正确；
    • 主体是否像苔藓、地衣、草坪或菌膜；
    • 是否存在模块接缝和年龄差异；
    • 光合面积是否足够；
    • 表面是否误成湿亮胶质；
    • 三层剖面和锚定根是否成立；
    • 繁殖梗是否过高或花器过艳；
    • 生命周期是否包括有性种子；
    • 是否误画未确认动物共生；
    • 综合色是否功能化而非随机；
    • 比例尺是否与工作尺度一致；
    • 中文文字是否可读；
    • 是否预留或生成无意义伪标签；
    • 整体是否符合“沉静坚韧、持续更新”。

    任何核心项失败，都不能进入确认视觉资产目录。

    十四、成本与风险

    • 一页同时展示群落、剖面、繁殖和生命周期，信息密度较高；
    • 生成模型容易把接缝画成瓷砖；
    • 低伏结构容易被误画成苔藓或地衣；
    • 中文标签可能出现错字；
    • 丰富综合色可能导致珊瑚或魔法地毯联想；
    • 根系剖面容易与主图尺度不一致；
    • 繁殖梗容易普通草本化。

    十五、外部依赖

    • 图像生成模型的分辨率和文字能力；
    • 用户对第一版候选图的审美裁决；
    • 后续可能修订的尺度参数；
    • M6-03、16、19、20 的复审结果；
    • 最终命名专项。

    十六、冻结项

    1. 当前图鉴标题使用“基生垫层植物｜鲁拉纳 / Rulana”；
    2. 主状态为 P2，局部展示 P3 繁殖；
    3. 采用横向宽屏科学图鉴页；
    4. 主图必须显示多基因型斑块、模块接缝、年龄梯度和空缺；
    5. 右侧必须包含表面、剖面、节点、繁殖和幼体发育特写；
    6. 标签使用中文高价值术语；
    7. 生命周期必须从有性种子开始；
    8. 不展示未确认稳定共生动物；
    9. 使用工作尺度范围；
    10. 候选图通过实际成图审核后才能最终冻结和归档。

    十七、未决项

    • 最终 Prompt 的措辞和权重；
    • 具体版面比例；
    • 中文标签数量；
    • 是否将 P0—P4 全部放入首图；
    • 是否对接缝和根系制作第二张标准件；
    • 生成后是否需要无文字底图与文字终稿双版本。

    十八、回退条件

    • 在未生成实际图像前宣称最终图鉴已通过；
    • 候选图未通过结构和文字检查却进入确认资产目录；
    • 主图只展示漂亮地毯而没有生物学证据；
    • 删除有性生命周期；
    • 加入未确认动物互利关系；
    • 使用历史“连续基膜”视觉；
    • 标签错误、伪文字严重或比例失真；
    • 图像无法与 G、I、J 区分。

    十九、裁决

    最终科学图鉴输出审核闸门：出图前条件通过

    本裁决仅表示设定已足以进入 Prompt 和候选图生成，不表示最终图鉴已经通过。实际成图必须接受本文件第十三节的完整审核，并由用户明确确认后，才能进入“用户确认与归档闸门”。

    二十、归档字段映射补充

    原始输出设定

    Project AE 植物图鉴要求直接生成可用的横向科学图鉴页，使用中文高价值标注，展示主体、结构、剖面、繁殖、生命周期和比例，同时遵守 K2V 晴天光谱、无伪文字和仅确认视觉资产入包等总规则。

    问题诊断

    在实际图像生成前不能宣称“最终图鉴已通过”；若信息密度过高，容易出现伪文字、比例不一致和结构混乱；若只追求漂亮主图，会遗漏模块接缝、锚定根、有性生命周期和群落空缺；若加入未确认动物，会把待定接口错误冻结。

    优化方案与判断逻辑

    将本闸门明确限定为“出图前条件通过”，冻结 P2 主状态、P3 局部繁殖、横向宽屏版式、主图十项证明目标、剖面和生命周期必备内容，以及实际成图后的逐项复核清单。只有候选图通过该清单并获得用户确认，才进入最终归档。
