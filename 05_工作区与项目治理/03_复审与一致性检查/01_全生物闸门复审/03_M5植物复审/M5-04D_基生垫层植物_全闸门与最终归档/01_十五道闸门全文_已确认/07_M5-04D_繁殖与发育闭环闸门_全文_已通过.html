    M5-04D 基生垫层植物｜繁殖与发育闭环闸门｜全文已通过

    版本：V0.7.23 已通过归档
    审核对象：M5-04D 基生垫层植物｜历史名“基膜垫植物｜鲁拉纳 / Rulana”
    用户确认状态：已确认通过（2026-07-10）
    归档性质：完整判断正文，不得以摘要替代

    一、审查目标

    本闸门验证 M5-04D 是否具备从成熟遗传个体、配子形成、异体遗传交换、受精、胚与种子发育、传播、萌发、幼体建立、模块化成长到再次性成熟的完整生命周期。

    同时必须解决：

    • 历史“皱褶微囊”到底是什么；
    • 克隆扩展是否会取代有性繁殖；
    • 低伏植物如何把花粉或等效配子送出近地边界层；
    • 种子如何进入适合建立的微型空缺；
    • 幼体为什么不能直接是缩小版成熟垫层；
    • P0—P4 如何分别影响繁殖和发育；
    • 成熟垫层对自身后代的竞争如何处理。

    二、原始设定与历史输入

    历史材料提供了以下线索：

    • 表面存在皱褶与“微囊”；
    • 可从边缘扩展；
    • 特定断片可能再生；
    • 大面积垫层可以长期存在；
    • 繁殖可能与湿化阶段有关。

    但历史版本没有完成：

    • 配子形成；
    • 异体受精；
    • 胚胎营养；
    • 种子或等效繁殖体结构；
    • 幼体发育顺序；
    • 性成熟条件；
    • 有性与无性繁殖的资源分配。

    因此“皱褶微囊”不能继续作为未解释的万能繁殖器官。

    三、主要问题诊断

    1. 低伏位置不利于直接风媒

    如果配子释放口始终贴在地表：

    • 花粉容易被边界层困住；
    • 湿化时容易黏附在表面；
    • 泥沙和踩踏会堵塞繁殖结构；
    • 同一克隆斑块内近距离自花粉过多。

    2. 克隆扩展容易压制有性更新

    成熟斑块已经占据光照、根区和锚定面。若没有专门空缺机制：

    • 种子无法建立；
    • 大斑块由少数基因型长期垄断；
    • 病原、近交和环境变化风险上升。

    3. 幼体不能直接形成成熟三层垫层

    成熟模块需要耐磨低脊、光合浅沟、纤维中层、根区和节点。幼体若萌发后立即建设完整结构，单粒种子的储备不足。

    4. 断片传播不能替代遗传重组

    节点断片只复制原基因型，适合局地恢复，但不能长期承担种群遗传更新。

    四、繁殖模式总裁决

    M5-04D 采用：

    以克隆模块扩展维持成熟斑块，以周期性有性繁殖完成遗传重组和跨斑块建立的混合繁殖体系。

    两种途径功能分开：

    • 克隆扩展：成功率较高、距离短、维持现有基因型；
    • 节点断片：低频、偶发、依赖完整节点和稳定落地；
    • 有性繁殖：成本较高、幼体死亡率高，但产生新基因型并连接斑块。

    有性繁殖不能被删除，也不能只在灾害后偶然发生。

    五、“皱褶微囊”的现行解释

    历史“皱褶微囊”建议保留为视觉与结构母题，但重新定义为：

    嵌在光合皱褶基部、由保护性组织包围的微型繁殖芽室

    它不是成熟种子，也不是孢子本身，而是繁殖器官的休眠起始结构。

    其位置优势：

    • 低于耐磨脊顶，不易被擦伤；
    • 靠近中下层输导和储备组织；
    • P0 可保持关闭；
    • 条件合适时可伸出短暂的繁殖梗；
    • 发育失败时可回收部分资源。

    正式中文器官名暂不冻结，继续使用“皱褶微囊”作为历史兼容称呼，待命名复审时统一。

    六、性别与配子系统

    建议采用：

    同一个遗传个体可形成雌、雄两类微型花器，但以时间错开和自交不亲和降低自交。

    具体方式：

    • 单个短繁殖梗上先进入雄性释放期；
    • 雄性阶段结束后，部分花器进入雌性可受期；
    • 同一克隆斑块内各模块并非完全同步；
    • 自交不亲和系统阻止多数同基因型花粉完成受精；
    • 不同遗传个体之间的兼容花粉才是主要成功来源。

    选择该方案的理由：

    • 不需要长期维持独立雄株和雌株；
    • 低密度斑块仍可同时提供两类花器；
    • 时间错开减少同一花器自交；
    • 自交不亲和维持遗传多样性；
    • 不要求尚未建立的专性授粉动物作为唯一依赖。

    七、繁殖触发

    M5-04D 不直接“感知 P3”这个抽象阶段，而是综合以下实际信号：

    • 前期 P2 已积累足够碳储备；
    • 根区水势持续回升；
    • 基质仍保持含氧；
    • 日照达到最低阈值；
    • 温度处于可发育范围；
    • 模块没有处于严重损伤或病原状态。

    典型时序为：

    1. P2 后段在皱褶基部形成繁殖芽室；
    2. P3 初段水分改善后伸出繁殖梗；
    3. P3 中段完成花粉释放、受精和早期胚发育；
    4. P3 后段至回落阶段形成干性小蒴果；
    5. 表面重新趋干后释放种子。

    若 P4 过湿、缺氧或连续阴暗，植物可以中止部分繁殖梗并回收资源。

    八、繁殖器官结构

    1. 短暂直立繁殖梗

    • 从皱褶芽室伸出；
    • 高于主表面，但只达到足以越过近地边界层的高度；
    • 细、柔韧、可随风摆动；
    • 不形成普通草本的大型花茎；
    • 成熟后枯萎并从基部脱落。

    其作用是把花粉和种子释放位置暂时抬高，而不是长期争夺光照。

    2. 雄性花器

    • 体型小；
    • 花被退化或仅保留保护片；
    • 释放干燥、轻质花粉；
    • 不产生强烈香味、蜜液或高成本鲜艳花瓣；
    • 以风媒为主。

    3. 雌性花器

    • 具有可捕获花粉的分枝或粗糙受粉面；
    • 受粉面在雄性阶段结束后展开；
    • 受精后形成小型干性蒴果；
    • 每个蒴果含有限数量的种子，而非极大量粉尘状繁殖体。

    九、花粉传播与受精

    主要方式：近至中距离风媒

    短繁殖梗将花粉抬出表面边界层。风振动促进释放，不要求强风。

    花粉传播仍受以下限制：

    • 雨滴和高湿降低有效飞行；
    • 连续高密度同克隆斑块产生大量不兼容花粉；
    • 地形屏障限制远距交换；
    • 长期无风阶段降低受精率。

    次要方式：小型动物偶然携带

    经过繁殖梗的小型低位动物可能携带少量花粉，但：

    • 目前不冻结专性授粉关系；
    • 植物不提供高成本蜜液作为必要奖励；
    • 即使动物缺席，风媒仍能完成基本繁殖。

    受精与防错

    兼容花粉萌发后形成短花粉管，完成配子融合。自交不亲和、花粉活力和雌性组织状态共同过滤无效花粉。

    十、胚与种子发育

    受精后的母体模块负责：

    • 提供碳水化合物；
    • 提供氮、磷和微量元素；
    • 维持蒴果的气体交换；
    • 在 P4 风险上升时减少低成功率胚的投入。

    成熟种子建议具有：

    • 坚韧但不厚重的种皮；
    • 中等偏小的胚乳或储备组织；
    • 扁平或低凸轮廓；
    • 粗糙边缘或短吸湿芒；
    • 表面不黏滑；
    • 能在地表短距离滑移、滚动或被风拖行。

    种子不是粉尘状孢子，也不具大型伞毛。

    十一、种子释放与传播

    干性蒴果在成熟后由以下组合触发开裂：

    • 含水率下降；
    • 昼夜干湿变化；
    • 轻风摆动；
    • 小型动物或颗粒造成的局部振动。

    开裂后种子以短至中距离传播为主：

    1. 风沿地表推动；
    2. 顺缓坡和浅沟移动；
    3. 降雨初期被短距离搬运；
    4. 少数附着于动物足部或体表后远移；
    5. 极少节点断片在扰动中传播。

    强径流通常造成死亡，不应被描述为高效水播。

    十二、休眠与萌发条件

    种子需要经历：

    1. 成熟后的短期干燥后熟；
    2. 进入稳定、受光、未被成熟垫层封闭的微型空缺；
    3. 获得连续而非瞬时的中等湿润；
    4. 基质含氧且未长期水饱和；
    5. 温度和光照进入允许范围。

    萌发受到以下抑制：

    • 完整成熟垫层释放的遮阴和资源竞争；
    • 深埋；
    • 永久湿泥；
    • 光滑无裂隙裸岩；
    • 一次短雨后立即恢复干旱；
    • P4 强冲刷。

    种子可在浅层基质中形成跨越多个脉潮周期的短—中期种子库，具体寿命后定。

    十三、幼体发育闭环

    幼体不得直接成为缩小版成熟垫层，建议分为五个阶段。

    阶段1｜初生根—窄轴幼体

    • 胚根先进入裂隙或颗粒间隙；
    • 地上只形成狭窄光合轴；
    • 储备主要用于固定和建立第一吸收界面；
    • 耐磨能力很低。

    阶段2｜二至三节点匍匐幼体

    • 形成短匍匐轴；
    • 第二、第三节点开始生根；
    • 可以在母种子储备耗尽后独立维持；
    • 仍不形成宽大垫层。

    阶段3｜初级宽化模块

    • 节间缩短；
    • 光合枝段逐渐展宽；
    • 形成简单低脊和浅沟；
    • 中层纤维仍较薄；
    • 对踩踏和 P0 的耐受有限。

    阶段4｜模块群亚成体

    • 多个模块形成局部根区；
    • 接缝和短程输导建立；
    • 开始出现老模块退出与边缘更新；
    • 具备稳定克隆扩展能力。

    阶段5｜性成熟遗传个体

    达到以下条件后才可大量形成皱褶繁殖芽室：

    • 具有若干成熟模块；
    • P2 储备稳定；
    • 根区未处于长期缺氧；
    • 斑块拥有至少部分开放受光边缘；
    • 近期损伤负荷较低。

    具体年龄不冻结，以生理规模和资源状态为主要门槛。

    十四、节点断片发育

    节点断片成功建立的顺序为：

    1. 落入稳定微凹或裂隙；
    2. 保持正确朝向并停止移动；
    3. 根原基接触湿润含氧基质；
    4. 储备支持初期生根；
    5. 原有光合面恢复；
    6. 形成新模块。

    节点断片比种子更快形成成熟模块，但：

    • 数量少；
    • 运输距离通常短；
    • 遗传上与母体相同；
    • 大多数撕裂碎屑不具再生能力。

    十五、后代数量与亲代投入

    M5-04D 采取：

    • 每次形成较多小型繁殖梗；
    • 单个蒴果种子数有限；
    • 单粒种子投入中等偏低；
    • 幼体总体死亡率高；
    • 不提供萌发后的亲代照护。

    亲代投入集中在：

    • 种皮；
    • 初生根建立所需储备；
    • 早期狭窄光合轴；
    • 休眠和环境筛选能力。

    不同时具备“极高种子数、极高单粒储备、极高幼体存活率”。

    十六、P0—P4 繁殖响应

    P0

    • 繁殖芽室关闭；
    • 不新建高成本繁殖梗；
    • 成熟干蒴果可继续释放种子；
    • 种子保持休眠；
    • 幼体死亡风险最高。

    P1

    • 母体恢复储备；
    • 部分种子开始吸水，但若湿润不持续则停止萌发；
    • 幼体优先修复根系。

    P2

    • 主要储备积累期；
    • 形成繁殖芽室；
    • 稳定幼体继续增加节点；
    • 常态必须能完成部分生长，不依赖 P3 才存活。

    P3

    • 主要开花、受精、胚发育和幼体建立窗口；
    • 克隆扩展与有性繁殖发生资源竞争；
    • 资源不足的斑块应减少其中一种投入。

    P4

    • 长期过湿会降低花粉释放和根区含氧；
    • 未成熟蒴果易感染或败育；
    • 幼体易被冲刷和掩埋；
    • 排水高点可能保留少量成功建立。

    十七、遗传多样性与近交控制

    维持遗传多样性的机制为：

    • 自交不亲和；
    • 雄性与雌性阶段时间错开；
    • 不同遗传个体的繁殖期部分重叠；
    • 风媒连接邻近斑块；
    • 少量动物附着与地表搬运形成较远传播；
    • 老中心和边界空缺允许新基因型进入。

    风险包括：

    • 单一克隆覆盖过大；
    • 邻近斑块兼容基因型不足；
    • 连续阴湿导致多年繁殖失败；
    • 繁殖窗口与强风或暴雨错配。

    十八、原始设定优化结果

    保留

    • 皱褶微囊视觉母题；
    • 边缘克隆扩展；
    • 节点断片有限再生；
    • 湿化阶段繁殖增强；
    • 低伏地表生命周期。

    修订

    • 微囊不再直接等同种子或孢子；
    • 任意碎片再生改为节点断片；
    • 繁殖不依赖永久水膜；
    • 幼体不直接复制成熟垫层结构；
    • 成熟斑块不允许所有种子在其表面无竞争萌发。

    新增

    • 短暂直立繁殖梗；
    • 先雄后雌与自交不亲和；
    • 风媒主通道和动物偶然备份；
    • 干性蒴果与扁平种子；
    • 后熟、休眠和空缺萌发；
    • 五阶段幼体发育；
    • P0—P4 完整繁殖时序。

    十九、成本与代价

    • 繁殖梗暂时暴露于踩踏和风雨；
    • 自交不亲和会使孤立基因型繁殖失败；
    • 风媒在近地环境效率有限；
    • 蒴果和种子消耗 P2—P3 储备；
    • 幼体耐磨和耐旱能力弱；
    • 成熟垫层抑制自身后代；
    • 克隆扩展和有性繁殖不能同时最大化；
    • P4 过湿可造成整季繁殖失败。

    二十、外部依赖

    1. K2V 光谱下的花粉活力；
    2. M6-R01 近地风速和湍流；
    3. P3 持续时间；
    4. 自交不亲和基因型数量；
    5. 种子后熟和休眠时长；
    6. 幼体建立空缺的典型尺寸；
    7. 主要种子消费者；
    8. 动物附着传播的实际概率；
    9. 性成熟所需模块数；
    10. 单次繁殖的碳、氮和磷预算。

    二十一、本闸门冻结项

    1. M5-04D 保留有性繁殖，并与克隆扩展共同组成混合繁殖体系；
    2. “皱褶微囊”现解释为受保护的微型繁殖芽室，不是成熟种子或孢子；
    3. 繁殖芽室在条件合适时伸出短暂直立繁殖梗；
    4. 同一遗传个体可形成雌、雄花器，以先雄后雌和自交不亲和减少自交；
    5. 风媒为主要配子交换方式，小型动物携粉仅为非必要备份；
    6. 受精后形成小型干性蒴果和扁平、粗糙、可休眠种子；
    7. 种子主要短至中距离传播，强径流通常是风险而非稳定传播机制；
    8. 萌发需要干燥后熟、连续中等湿润、含氧基质、开放光照和稳定微空缺；
    9. 幼体依次经历初生根—窄轴、少节点匍匐、初级宽化模块、模块群亚成体和性成熟斑块；
    10. 节点断片是低频克隆传播，不能替代有性遗传更新；
    11. P2 为储备和芽室形成期，P3 为主要开花受精和幼体建立窗口，P4 过湿可能导致繁殖失败；
    12. 不存在永久水膜授精、无成本碎片再生或直接缩小版成体幼体。

    二十二、未决项

    1. “皱褶微囊”的最终正式器官名称；
    2. 花器精确形态与颜色；
    3. 繁殖梗典型高度；
    4. 花粉粒大小和传播距离；
    5. 自交不亲和的严格程度；
    6. 每蒴果种子数量；
    7. 种子寿命；
    8. 性成熟所需年限或模块规模；
    9. 幼体各阶段持续时间；
    10. 是否存在专化种子传播动物。

    二十三、回退条件

    出现以下任一情况，本闸门必须回退：

    • 完全取消有性遗传重组；
    • 微囊被重新定义为无需配子和胚发育即可产生无限后代的万能结构；
    • 授精依赖永久水膜；
    • 低伏花器不抬升却仍实现高效远距风媒；
    • 自交不亲和严格，但局地只有一个兼容基因型仍能稳定结实；
    • 种子同时极小、无储备，却直接形成成熟三层模块；
    • 幼体没有明确根系、光合和死亡瓶颈；
    • 节点断片成为主要远距遗传更新方式；
    • P4 长期水饱和被设定为最佳繁殖条件；
    • 成熟垫层上所有种子都能无竞争建立。

    二十四、裁决

    繁殖与发育闭环闸门：条件通过

    通过依据

    • 有性与无性繁殖功能已经分开；
    • “皱褶微囊”获得了明确发育来源和结构位置；
    • 配子形成、传播、受精、胚、种子、休眠、萌发和性成熟形成完整闭环；
    • 幼体发育遵循演化闸门冻结的“匍匐轴—节点生根—宽化模块”路径；
    • P0—P4 各阶段具有不同且有成本的繁殖响应；
    • 成熟垫层对幼体的排斥与空缺更新机制一致；
    • 没有永久水膜、无成本再生或目的论授粉关系。

    通过条件

    1. 种群持续闸门必须证明兼容基因型、种子库和空缺更新足以维持长期遗传多样性；
    2. 生态网络闸门需回填主要种子消费者和动物偶然传播接口；
    3. 光学与视觉闸门必须让繁殖梗看起来是短暂植物器官，而不是普通草花或大型装饰花穗；
    4. 后续定量不得让单次繁殖投入超过 P2—P3 的净生产能力。
