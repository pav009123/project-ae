    AE-Ena Project 总包

    当前版本：V1.4.19｜创作总则与纯恶反派硬规则建立版

    本包基于 V1.4.18 完整项目总包继续增量归档，完整保留 M87、G05、CL8 界序理论、长生主体、玛娜/侍序文明、仙境奖域共生体等既有设定。本轮新增全项目创作总则级硬规则，正式纠正“复杂反派自动合理化/去纯恶化”倾向；允许并要求保留真正纯恶主体、恶性文明和埃纳内部隐藏恶人，同时严格区分因果解释与道德辩护。既有角色不因本规则自动重分类。

    Project AE

    V1.4.19 创作总则与纯恶反派硬规则建立版

    • 新增全项目 00_Project_AE_创作总则_V1.0.md，并提升为人物、反派、战争责任相关任务的强制前置读取项。
    • 冻结“复杂不等于可原谅；因果解释不等于道德辩护”。
    • AE宇宙正式允许真正纯恶的主体与恶性文明，包括清醒、理性、长期隐藏的埃纳内部恶性主体。
    • 反派设计必须先区分悲剧型、异质型、纯恶型，不得默认将纯恶改写为“其实有苦衷/只是价值观不同”。
    • 高级文明、高智能和长寿不自动推出道德高级；高级恶意应体现长期规划、制度利用、主体工程和隐藏能力。
    • 建立反派设计审计清单，作为后续冻结前的强制检查。
    • 本版不自动重分类玛娜、G03地球线相关埃纳、瓦赫、黑化埃纳等既有人物/谱系。
    • 同步落盘M87第一位受伤光之守护者人物骨架；“迪迦”仅作者侧临时代号；M87线当前主动暂停。

    V1.4.18 M87双CL6终极战争与本征文明主体机制建立版

    • M87正式进入CL8初期第一次超远距自主改界主线；埃纳第一次远征核心冻结为5名成熟埃纳。
    • M87本土两大文明统一校准为CL6终极：能有限出系，但尚不能脱离M87建立第二个完整文明母节点。
    • M87*成为三方真实利益核心：光之国与本征文明为生存/文明上限级依赖；埃纳为CL8首航、超级深域和未来河外布局级战略价值。
    • 五人组冻结：A行动型主体埃纳、B高神族性主体巨构化埃纳、C界序型、D主体生命型、E深域型；B不需要界舟，其路线在埃纳内部并非孤例。
    • M87敌对文明正式定名本征文明；旧“范型/恒范/恒型”工作名退出现行。
    • 本征文明冻结A0唯一主连续体、成熟本征核、分枝核K_i、多实例人生、经验回流—A0同化—共同基态再同步的完整机制。
    • A0死亡不导致分枝自动死亡；遗枝进入失核状态。重新育核必须从幼核长期生长，不能无限瞬时复活。
    • 本征科研优势冻结为“并行人生总吞吐与纵深迭代”，埃纳共思优势冻结为“异质主体碰撞与范式跃迁”。
    • M87战争史按“物理工程冲突→安全困境→主体伤亡→有限战争→强制本征化保存→毁灭战争”建立。
    • 第一次三方接触冻结：受伤守护者作为最近合格接触使者，主动离开埃纳安全区；本征追击恢复；守护者为保护无关生命放弃最佳反击；A以最低必要干预救下其生命；本征文明停止升级并正式接触。
    • 新建 05_工作区与项目治理/14_M87文明战争与第一次CL8远征/，包含换对话读取顺序与TODO。
    • 当前阶段明确：不制作视觉资产。

    V1.4.17 奖域共生体与仙境“魔戒式”遗产支线建立版

    • 奖域共生体正式进入现行设定：埃纳成熟奖励空间工程的日常化共生生命应用，普及到“人手一份也不足为奇”；
    • 冻结其起源逻辑：保护主体在长期自我修改中仍拥有可逆、可退出和价值参照，而不是从精神控制器起步；
    • 建立复衡、远志、开感、共律、权衡、誓衡、战律、主权八类功能谱系（支系名称暂可调整）；
    • 正常祖型为高复杂度非主体生命，主体化后必须重新定义关系；
    • 后埃纳仙境遗迹中，普通智慧种可获得旧奖域共生体；其“神器”效果主要来自仙境权限与文明器官，而非小体积共生体凭空供能；
    • “魔戒式腐化”来自长期奖励空间耦合、责任—控制反馈和权限错配，不等于共生体天生邪恶；
    • 纠正本土生命称谓：应为“智慧种族”，不是“指挥种族”；
    • 若未来展开，该支线首选终局为真正埃纳归来，重新处理宿主—共生体—仙境—文明之间已经形成的主体关系；
    • 具体宿主、星球、原主人和终局暂不展开。

    V1.4.16 长生主体、科学—艺术观与玛娜文明建立版

    • CL7+ 埃纳正式取消自然寿命上限；长生是能力，不是义务；休眠、隐退、退出公共责任与自主终止纳入主体权利。
    • 冻结埃纳“科学=认知的流动、艺术=体验的流动”的长寿文明观，以及对异文明艺术的强兴趣。
    • 建立黑化埃纳通则：价值反转不等于精神损坏、神族化或必然敌对。
    • 玛娜与索恩同属 CL7 远岸时代；现行形态再次确认为双足四臂。
    • 玛娜不喜欢艺术、崇尚单一最高主权，但不以征服其他埃纳为默认目标。
    • 侍序文明（工作名）在银河侧已由多名高级埃纳共同设计并真实育生运行，是有拒绝/退出能力的主体文明。
    • 玛娜远岸本质为带着既有主体文明寻找小星系根据地；目标星系含多个低级本土文明，具体故事暂缓。
