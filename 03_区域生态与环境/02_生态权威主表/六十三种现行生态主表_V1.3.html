    六十六个现行生态代表类群主表 V1.6

    本表自 V0.7.94 起为生态网络、区域地图、文明接口和故事开发的最高优先级生态权威层。旧文字卡与本表冲突时，以本表为准。

    植物

    编号 名称 功能层 现行生态定位 主要栖息环境 P0—P5节律
    M5-04A/B 奥兰 / Oran 初级生产者 长寿命巨型承力植物，以根塔体系长期重塑地表、地下空间与周边生物分布。 稳定陆地区域；标准巨体与条件性超巨体共享同一谱系。 以多年尺度维持主体，仅在脉潮变化中调整局部生长与更新。
    M5-04C 塔鲁 / Taru 初级生产者 将短时资源脉冲分散储存在地下结构中的重要农作物。 季节湿化、资源脉冲明显的低地与可管理种植区。 随脉潮完成萌发、积累、储藏与地上组织替换。
    M5-04D 鲁玛里 / Lumari 初级生产者 低位连续覆盖与受损后恢复。 温润低地和季节湿化地表。 P1—P4湿润窗口扩展，P5回缩或局部休止。
    M5-04E 萨维林 / Savelin 初级生产者 随斑光窗口重构受光冠面。 林缘与冠层间歇光照区。 P1—P4随斑光移动反复换冠。
    M5-04F 瓦鲁诺 / Varuno 初级生产者 顺应持续风场的低冠植物。 迎风根脊与高风暴露带。 P1—P4生长，强风期压低或回缩。
    M5-04G 卡雷迪 / Karedi 初级生产者 矿岩裂隙中的楔根先锋植物。 矿岩裂隙与贫瘠硬质界面。 P1—P3湿润裂隙期扩展，干期休止。
    M5-04H 霍拉伦 / Holaren 初级生产者 洪退窗口快速锚定的新生基质植物。 退水滩地和短时暴露沉积层。 P3—P5洪退窗口萌发与锚定。
    M5-04I 梅拉苏 / Merasu 初级生产者 腐殖边缘周期性更换吸收根扇。 湿润腐殖边缘和高病原负荷界面。 P1—P4轮换吸收，P5封闭与重建。
    M5-04J 阿雷 / Arel 初级生产者 早期游生、定植后发生不可逆变态并形成巨大长期主体的植物。 早期依赖可迁移介质；定植阶段要求满足稳定资源与支撑条件。 生命周期阶段转换比单一季节变化更关键，定植失败不可逆。
    M5-04K 诺沙里 / Noshari 初级生产者 根塔高位表面的叠瓦附生植物。 奥兰高位表面和风湿交替带。 P1—P4湿润与光照窗口生长。
    M5-04L 拉维 / Ravel 初级生产者 以多个稀疏锚点建立高空弧形连接，并通过活体结构扩展可达空间。 高位冠层、根塔之间或具备稳定锚点的开阔高空区域。 在适宜风载与生长窗口扩展，扰动期收紧或暂停高成本延伸。
    M5-04M 穆伦 / Muren 初级生产者 利用短时凝雾窗口，以槽叶束收集并保留可利用水分的重要植物。 雾频较高但持续水源不稳定的迎雾面与局部汇雾带。 活动强度随凝雾窗口变化，不等同固定季节性水生植物。
    M5-04N 杜纳里 / Dunari 初级生产者 深阴错层空间中的分散受光植物。 根塔内部深阴和多层遮挡区。 P0—P4低速维持，光窗出现时短促增生。
    M5-04O 维瑟 / Vesel 初级生产者 通过分舱根系与受控交换处理稀缺或高风险限制元素的重要植物。 限制元素分布不均、局部富集可能造成毒害的贫瘠基质。 按资源窗口开放部分交换区，其余分舱维持隔离。
    ENERGY-FLORA-01 露玛 / Luma 初级生产者 大型固定式冠盘型高储能植物，通过多色素捕光、分仓储能和根际交换跨越长低资源期。 脉潮高能平原—湿旱交替边缘带。 高能窗口集中捕光与分仓储能，低资源期缓释；冠盘姿态、蒸腾和散热随光热负荷调整。
    ## 陆生动物
    编号 名称 功能层 现行生态定位 主要栖息环境 P0—P5节律
    --- --- --- --- --- ---
    M6-01 莫拉库 / Molaku 腐食/碎屑食者 腐殖层颗粒扰动与微通道活动者。 湿润腐殖层和表层碎屑区。 P1—P4湿润期活跃。
    M6-02 贝萨鲁 / Besaru 捕食者 贴地隐蔽接近的小型捕食者。 低位遮蔽物和植物边缘。 P1—P4猎物活跃期活动。
    M6-03 凯拉尔 / Kelar 植食/滤食者 低位植物边缘连续取食动物。 垫层和低位植物边界。 P1—P4植物生长窗口活跃。
    M6-04 塔莱基 / Taleki 捕食者 低枝附近短跃伏击捕食者。 低枝、根脊和垫层上缘。 P1—P4低枝猎物密集时活跃。
    M6-05 加雷达 / Gareda 腐食/碎屑食者 利用楔头扩大残体裂口的清残动物。 湿润残体与腐殖边缘。 P3—P5残体增加时活跃。
    M6-06 尼亚鲁 / Neyaru 植食/滤食者 湿膜表面滑移并附带携殖的动物。 湿膜、浅渠和新生湿润基质。 P1—P4湿膜连通期活跃。
    M6-07 沙维恩 / Shavien 杂食/功能待细分 浅雾通道中的高速掠行动物。 细长湿润通道和浅雾层。 P2—P4浅雾稳定期活跃。
    M6-08 内什 / Nesh 腐食/碎屑食者 活动于腐雾环境并传播病原，其密度可反映局部病原压力的重要小型动物。 腐殖层、湿膜边缘及高密度动物活动区。 在腐雾增强和宿主接触机会增加的阶段扩散风险上升。
    M6-09 雷拉尼 / Relani 杂食/功能待细分 随微栖位季节痕迹迁移的动物。 休眠鳞片、湿点和膜垫交界。 P0—P5随微环境转换分段迁移。
    M6-10 尤瓦里 / Yovari 杂食/功能待细分 模拟自然背景振动以扰乱定位的动物。 湿膜、根丝和滴水背景复杂区。 P1—P4背景信号丰富时有效。
    M6-11 拉诺基 / Ranoki 植食/滤食者 根隙与裂缝中的连续攀行动物。 根脊缝隙和多面支撑结构。 P0—P4根隙湿度适宜时活动。
    M6-12 瓦米鲁 / Vamiru 杂食/功能待细分 沿脉露薄液痕迹舔食的动物。 植物表面、根脊和短时凝露区。 P1—P3凝露窗口活跃。
    M6-13 特拉努 / Telanu 杂食/功能待细分 将卵囊固定于硬壳裂隙的动物。 季节鳞片、膜垫裂口和硬化微壳。 P2—P4繁殖窗口集中活动。
    M6-14 科维塔 / Kovita 捕食者 裂隙边缘使用钩面伏击的微型捕食者。 细小裂隙和膜面边界。 P1—P4猎物通行期活跃。
    M6-15 舍纳维 / Shenavi 杂食/功能待细分 浅雾中短距切向掠食的翼行者。 低位浅雾和湿润空隙。 P2—P4浅雾和飞虫同步时活跃。
    M6-16 洛图恩 / Lotun 杂食/功能待细分 贴伏薄垫层探取微型资源的动物。 低位垫层和薄膜表面。 P1—P4垫层湿润时活跃。
    M6-17 维雷卡 / Vireka 杂食/功能待细分 沿脉缘边界持续巡猎的动物。 湿润边界和资源分界线。 P1—P4边界资源稳定时活跃。
    M6-18 杜玛罗 / Dumaro 腐食/碎屑食者 沉积腐殖中的软化裂食动物。 沉腐层和软化残体区。 P3—P5沉腐资源增加时活跃。
    M6-19 米达克 / Midak 植食/滤食者 沿湿膜边界刮取微生物层的动物。 湿膜与干面交界。 P1—P4膜界稳定时活跃。
    M6-20 索雷穆 / Soremu 植食/滤食者 静缓潮膜中构建局部封闭层的动物。 静水膜面和缓慢潮间微水体。 P3—P5静缓和收缩期活跃。
    M6-27 沃雷恩 / Vorain 捕食者 岸膜交界利用失衡瞬间截击的捕食者。 湿岸、浅水和岸膜转换带。 P1—P4岸缘猎物转换频繁时活跃。
    M6-28 科拉杜 / Koradu 捕食者 以身体楔入并封堵狭道的捕食者。 洞隙、根道和低位狭窄通路。 P0—P4狭道猎物活跃时活动。
    M6-29 梅洛鲁 / Meloru 植食/滤食者 垫原上持续摄取低质量植物资源的缓食者。 开阔垫原和低植被带。 P1—P4垫层生产期持续活动。
    M6-30 达洛 / Daro 植食/滤食者 定位并浅掘高能地下储根，与塔鲁种植体系形成长期资源竞争的重要动物。 储根植物分布区、种植边缘和季节性地下资源富集地。 在储根成熟、气味或基质信号明显的阶段活动增强。
    M6-31 法舒恩 / Fashun 植食/滤食者 裂取新鲜含液植物组织的机会型取食者。 新生枝叶和受损植物边缘。 P1—P3新生组织丰富时活跃。
    M6-32 鲁德米 / Rudemi 杂食/功能待细分 随资源序列分段迁食的中型动物。 多片资源带和脉潮过渡区。 P1—P4随资源波分段移动。
    ## 鸟类
    编号 名称 功能层 现行生态定位 主要栖息环境 P0—P5节律
    --- --- --- --- --- ---
    B-01 维洛安 / Viloan 杂食者 高空膜翼滑巡型观察—捡食鸟。 根塔上层、冠顶与开阔高空之间。 P1—P3高空滑巡最活跃；P4风扰增大；P5转入保守巡飞。
    B-02 塔科恩 / Takoen 杂食者 冠层裂取型果荚—组织取食鸟。 根塔与大型植物冠层中高位。 P2—P4资源最适合裂取；P5转向混合取食。
    B-03 佩鲁达 / Peruda 捕食者 短距急扑型小型主动捕食鸟。 中高枝观察位、低层枝隙与湿膜边缘。 P1—P4猎物密度较高；P5更多依赖伏击。
    B-04 希雷沃 / Hirevo 杂食者 极小型悬停探采鸟。 花状结构、细枝端部、冠层边缘与林缘低空。 P1—P3资源窗口最好；P4风扰降低悬停收益；P5转向微型动物。
    B-05 莫沙恩 / Moshaen 捕食者 低照度湿膜上方的低速静翔感知型捕食鸟。 浅雾膜层、湿膜低地与低矮植物上方。 P2—P3湿膜连续时最活跃；P4降低飞行高度；P5范围收缩。
    B-06 加鲁莫 / Garumo 腐食/碎屑食者 退水滩地与腐殖残体边缘的重型裂食机会鸟。 退水滩、腐殖堆和大型残体已有裂口周边。 P2—P3资源暴露增加；P4病原风险上升；P5转向低风险软组织。
    B-07 内瓦里 / Nevari 杂食/功能待细分 翼腕足化的密丛四点攀附鸟。 高密度枝叶、根丝和附生植物丛。 P0—P2范围较小；P3资源高峰；P4重建通道；P5增加短距飞跃。
    B-08 图塞拉 / Tusera 杂食/功能待细分 沿脉潮资源成熟顺序进行分段迁食的中型鸟。 浅滩、湿地、低位资源带和中继停驻地。 P0集群；P1—P2分段迁移；P3繁殖停驻；P4分散；P5返回越季区。
    B-09 瓦杜恩 / Vadun 杂食者 软滩步涉—筛食型中型鸟。 浅滩、水膜边缘和退水湿地。 P1—P2资源高峰；P3转向滩脊；P4迁入新浅滩；P5利用残留湿地。
    B-10 杜维克 / Duvik 杂食者 漂浮基质轻体守育鸟。 漂浮植物垫、薄膜水面和低扰动湿地。 P1—P3漂巢与资源高峰；P4基质破碎后短程转移；P5利用残留静水。
